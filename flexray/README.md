# flexray：FlexRay 式总线周期仲裁器

`flexray` 包实现一个 FlexRay 风格通信周期的静态段/动态段仲裁器，
相同操作序列重放得到完全相同的发送清单与计数；所有方法可并发调用，
内部以互斥锁保证结果等价于某个串行顺序。

## 构造与帧编号

`New(Ns, Nm, Lt)`：

- `Ns`：静态时隙数，`1 <= Ns <= 64`；
- `Nm`：动态小时隙数，`0 <= Nm <= 256`；
- `Lt`：迟发上限（latest-start 界限），`0 <= Lt <= Nm`。

编号 `1..Ns` 为静态帧，`Ns+1..Ns+Nm` 为动态帧。

## 登记与投递

- `Assign(id, base, rep)`：`rep` 取 1/2/4/8/16/32/64，`0 <= base < rep`；
  周期计数 `c`（0..63，初值 0）满足 `c mod rep == base` 时该帧激活；
  每个编号至多登记一次。
- `Post(id, L, tag)`：
  - 静态帧只有一个缓冲，新消息覆盖旧消息并使覆盖计数加一；`L` 不校验也不使用；
  - 动态帧按编号各有 FIFO，消息占 `L` 个小时隙（`1 <= L <= Nm`），每队列最多 8 条。

## Cycle() 的处理次序

`Cycle()` 运行当前周期 `c`，并把 `c` 推进为 `(c+1) mod 64`。

1. 静态段：按编号 `1..Ns` 逐个处理。
   - 已登记、激活且缓冲非空：发送并清空缓冲；
   - 已登记、激活但缓冲为空：记一次空帧，未用时隙数 `u` 加一；
   - 未登记或未激活：静默，缓冲消息原样保留到下个激活周期。
2. 动态段：令 `N = Nm + u`（回收未用静态时隙），`k = Ns+1`，`i = 1`，
   当 `i <= N` 循环：
   - 若帧 `k` 已登记、激活、队列非空，且 `i <= Lt`，
     且队首满足 `i + L - 1 <= N`：发送队首并记录起始小时隙 `i`，
     之后 `i += L`、`k += 1`；
   - 否则 `i += 1`、`k += 1`（空过一个小时隙）。

   要点：同一动态帧每周期至多发送队首一条；无论发送还是空过，`k` 每步只
   加 1，高编号帧起始位置天然靠后；`k > Ns+Nm` 后剩余小时隙一律空过；
   被 `Lt` 或区间上界 `N` 挡下的消息不弹出，留到后续周期。
3. 周期回绕：`c = (c+1) mod 64`，63 的下一个周期为 0。

## 未用时隙回收规则

静态段空帧不产生总线流量，其数量 `u` 被并入动态段，实际可调度小时隙数为
`N = Nm + u`。长消息可能在 `u` 较大的周期恰好满足 `i + L - 1 <= N` 而发出，
在 `u = 0` 的周期则因越界推迟；但起始小时隙仍必须满足 `i <= Lt`。

## 返回值与查询

- `Cycle() CycleResult`：`C`（运行时的 c）、按发送次序的 `Sent`
  （静态项填 `Slot=时隙号`，动态项填 `Start=起始小时隙`）、`Unused`（u）、
  `EmptyFrame`（本周期空帧数）。
- `Pending(id)`：返回动态 FIFO 中消息的标记（队首在前）。
- `Stats()`：累计发送数、空帧数、覆盖计数。
- `C()`：当前周期计数。

## 拒绝原因（按此顺序只报第一个）

1. `ErrInvalidParam`：构造/参数越界、base 与 rep 不合法、动态长度越界；
2. `ErrInvalidID`：编号超出 `1..Ns+Nm`；
3. `ErrDuplicate`：Assign 编号重复；
4. `ErrNotAssigned`：Post 的编号未登记；
5. `ErrQueueFull`：动态队列已满（8 条）。

被拒绝的操作不改变登记、缓冲、队列、覆盖计数与 `c`；`Cycle` 恒成功。

## 本地验证

```bash
# 全部测试
go test ./...

# 竞态检测 + 详细日志（含 2000 组随机序列逐条输入/输出/[MATCH] 判定）
go test -race -v ./flexray/

# 仅跑随机对拍（日志打印每条输入、双方输出与判定依据）
go test -v -run TestNaiveDifferential ./flexray/

go vet ./...
gofmt -l .
```

测试覆盖：rep/base 激活周期、c 在 63 后回绕、静态缓冲覆盖、未激活消息
保留、u 并入 N 后长帧得以发送、`i+L-1` 恰等于 N 允许而大 1 推迟、
`i` 恰等于 Lt 允许而大 1 挡下、k 空过同步前进、长帧发送后 k 只加 1、
`Nm=0` 与 `Lt=0` 退化、同周期多帧区间不重叠、拒绝码次序、并发安全、
确定性重放，以及与逐步朴素模拟器的 2000 组随机操作序列对拍。
