# regbank — 带访问类型的寄存器位域模拟器

`regbank` 模拟一组 32 位寄存器，每个寄存器由若干带访问类型的位域组成。
所有访问可并发调用，内部用单把锁串行化，结果等价于某个串行执行顺序。

## 构造与布局校验

`NewBank([]RegSpec)` 一次性登记全部寄存器并整体校验，任何布局问题都返回同一个
`ErrLayout`，且不会产生半成品 bank：

- 寄存器名为空或重名；
- 位域名为空或在同一寄存器内重名；
- `lo < 0`、`w < 1`、`lo + w > 32`；
- 位域互相重叠（按位检查）；
- 访问类型不是 `RW/RO/WO/W1C/W1S/RC`；
- 复位值不满足 `reset < 2^w`。

未被任何位域覆盖的位：读为 0，写被忽略。位域存值初始为复位值。

## 访问类型语义

| 类型 | 总线写 | 总线读 |
|------|--------|--------|
| `RW` | 写入即存值 | 返回当前存值 |
| `RO` | 写被忽略（仅 `HwSet`/`Reset` 能改） | 返回当前存值 |
| `WO` | 写入即存值 | 恒返回 0（`Raw` 仍可见存值） |
| `W1C` | 写入位为 1 才清对应位，写 0 不变 | 返回当前存值 |
| `W1S` | 写入位为 1 才置对应位，写 0 不变 | 返回当前存值 |
| `RC` | 写被忽略 | 返回当前存值，随后整个位域清零 |

所有位域存值始终满足 `< 2^w`，越出位域的写入位自然落在掩码之外。

## API

- `Write(reg, val, be)`：按 4 位字节使能（bit i 使能第 i 字节，`0..15`）写。
  位域覆盖 `[lo, lo+w)`，对应字节 `lo/8 .. (lo+w-1)/8`；只有这些字节**全部**
  使能时，才用 `val` 中属于该位域的片段按访问类型处理，否则该位域整体不变。
  `be=0` 没有任何效果。
- `Read(reg)`：先按位域（`WO` 读 0、未覆盖位读 0）组装返回值，再把该寄存器
  内所有 `RC` 位域清零。非 RC 位域不会因读改变。
- `ReadModifyWrite(reg, mask, value)`：等价于
  `r = Read(reg)`；`w = (r &^ mask) | (value & mask)`；`Write(reg, w, 15)`，
  返回 `r` 与写后的原始存值。注意语义陷阱：
  - `W1C`：读出为 1 且不在 mask 内的位会被回写的 1 清掉；在 mask 内且 value
    为 0 的位写 0，不会被清；
  - `WO`：不在 mask 内时读出的 0 被回写，存值被覆盖为 0；在 mask 内则取
    `value` 的对应位；
  - `RC`：内部 Read 仍先返回旧值并清零，随后的写对 RC 无效。
- `HwSet(reg, field, v)`：硬件侧直接把位域存值设为 `v`，不受访问类型约束，
  要求 `v < 2^w`。
- `Raw(reg)`：无副作用地返回各位域存值拼成的字（`WO` 可见、`RC` 不清零）。
- `Reset()`：把所有位域恢复为复位值。

## 错误原因与顺序

运行时错误彼此可区分，按「寄存器不存在 → be 非法 → 位域不存在 → v 越界」
只报第一个：

- `ErrUnknownReg`：访问的寄存器不存在；
- `ErrBadBE`：`Write` 的 `be < 0` 或 `be > 15`；
- `ErrUnknownFld`：`HwSet` 的位域不存在；
- `ErrValueRange`：`HwSet` 的 `v >= 2^w`。

被拒绝的操作不改变任何存值；被拒绝的 `Read` 不触发 RC 清零。

## 本地验证

```bash
go test -v ./regbank                 # 打印每条用例的输入/输出与判定依据
go test -race ./regbank              # 并发等价串行 + 竞态检测
go test -cover ./regbank             # 语句覆盖率
go vet ./... && gofmt -l .           # 静态检查与格式
```

`TestDifferentialNaive` 用 4 组随机种子各重放 300 次随机访问（Write/Read/
ReadModifyWrite/HwSet/Raw/Reset），与一个逐位实现的朴素参考模型逐次比对
返回值、写后存值与最终状态，并再重放一次确认结果完全可复现。
