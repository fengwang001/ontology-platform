# fsck — 块文件系统映像一致性检查与修复器

`fsck` 包扫描块文件系统映像的索引节点表、块位图与目录项，检测各类
不一致，并按固定顺序修复，使修复后的映像满足全部结构不变量（再检查
一次零发现）。

## 映像格式

块大小 512 字节，布局为：

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| 超级块 | 块 0 | magic `ONTOFS01`、版本、节点数、块数、根节点号、标志位（bit0 = 写挂载） |
| 索引节点表 | 块 1 起 | 每节点 32 字节：类型（空闲/文件/目录）、链接计数、最多 5 个直接块 |
| 块位图 | 节点表之后 | 每数据块 1 位，1 = 已使用 |
| 数据区 | 位图之后 | 数据块；目录的数据块存放 32 字节定长目录项（节点号 + 名称） |

恢复目录名固定为 `lost+found`，挂在根目录下。

## 不一致的判定

发现项按类别、再按节点号排序，类别顺序即下表顺序：

| 类别 | 判定依据 |
| --- | --- |
| `shared-block` | 同一数据块被多个已分配节点的块列表引用（最小节点号为属主，其余引用各报一条） |
| `dangling-dir-entry` | 目录项指向未分配或越界的节点 |
| `multi-parent-dir` | 同一子目录被多个目录的目录项收录（最小父节点号之外的每条收录各报一条） |
| `unreachable-inode` | 已分配节点从根节点沿目录项不可达（遍历带访问标记，环安全） |
| `link-count-mismatch` | 节点链接计数不等于全映像目录项的实际收录数 |
| `bitmap-mismatch` | 位图位与节点块列表的实际引用不一致 |

## 修复顺序（固定，不可变更）

修复在映像的内存副本上按以下顺序执行：

1. **共享块**：块归引用它的最小节点号节点；其余节点各取最低号空闲块
并复制原块内容；无空闲块则从该节点块列表中截除该引用，并记
`shared-block-truncate`（数据丢失，`RepairResult.DataLoss = true`）。
2. **悬空目录项**：删除指向未分配/越界节点的目录项。
3. **多父目录**：子目录只保留父目录节点号最小的收录项，其余删除。
4. **不可达节点**：有内容（文件有块 / 目录有项）的挂到恢复目录下、以
节点号命名；恢复目录不存在则在根目录下新建。不可达目录子树只挂
顶层（未被其他不可达节点引用的节点）；剩余互成环的组件挂环中
最小节点号，并断开环内指向被挂目录的反向边，保证挂载不产生第二
个父目录。无内容的不可达节点直接释放。
5. **链接计数**：改为全映像目录项的实际收录数。
6. **块位图**：按节点块列表的实际引用整体重建。

## 整体拒绝（可区分的原因）

以下情况拒绝整个操作并返回可 `errors.Is` 区分的错误，原映像逐字节
不变：

| 错误 | 条件 |
| --- | --- |
| `ErrCorruptHeader` | magic/版本/几何尺寸/根节点号损坏或映像截断 |
| `ErrRootNotDir` | 根节点不是目录 |
| `ErrMounted` | 映像标志位显示正被写挂载 |
| `ErrRecoveryNameTaken` | 需要挂载不可达节点，但 `lost+found` 名被非目录占用 |
| `ErrNoFreeInode` | 需要新建恢复目录但已无空闲节点 |

## 原子性与并发

- 修复结果先完整写入同目录临时文件并 fsync，再 `rename` 原子替换；
拒绝或注入中断（`Checker.FailBeforeCommit`）时删除临时文件，原映像
逐字节不变。
- 多个只读 `Check` 可并发（读锁）；`Repair` 与 `MountWrite` 互斥
（写锁），挂载期间修复与第二个挂载都会阻塞至卸载。
- 检查与修复均为确定性：同一映像反复检查/修复得到逐字节相同的发现
清单与结果映像。

## 本地验证

```bash
# 全部测试（含共享块、截除、目录环、多父目录、悬空项、位图、
# 修复后零发现、中断注入、整体拒绝、并发与互斥）
go test ./fsck

# 详细日志：每个用例打印输入映像、修复动作与判定依据
go test -v ./fsck

# 竞态检测（并发只读检查、修复与写挂载互斥）
go test -race ./fsck

# 代码检查
gofmt -l fsck
go vet ./fsck
```
