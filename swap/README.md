# swap：交换区槽位账本

`swap` 包实现交换区（swap area）槽位账本：为换出的页分配槽位，
用引用计数与交换缓存标志共同决定槽位何时回收，并按
「簇优先、下一适应、整簇空闲队列」的次序分配槽位。

## 槽位状态与回收条件

- 槽位编号 `0..N-1`，`0` 号为交换区头部不可用，可用槽位为 `1..N-1`。
- 每个槽位有计数 `count`（`0..Max`）与交换缓存标志 `cache`。
- **槽位空闲当且仅当 `count == 0` 且 `cache == false`**；
  `count > 0` 或 `cache` 为真时槽位在用。两者必须各自归零才回收：
  先 `CacheDrop` 后 `Free`，或先 `Free` 后 `CacheDrop`，均可。
- 新分配的槽位 `count = 0`、`cache = true`。
- 第 `c` 簇是编号落在 `[c*K, (c+1)*K)` 内的可用槽位；没有可用槽位的簇
  不存在（如 `K=1` 时的第 0 簇），首簇与末簇可能不足 `K` 个。
  一簇的所有可用槽位都空闲时称**整簇空闲**。

## 三步分配次序与游标语义

`Alloc()` 依次尝试，第一个可行的生效：

1. `cur` 非空且 `cur` 簇内存在编号不小于 `cursor` 的空闲槽位：
   取其中编号最小者 `s`；
2. 旧 `cur` 若此刻整簇空闲则追加到队尾，`cur` 置空；队列非空则取
   **队首簇**为 `cur`，取其编号最小的可用槽位 `s`；
3. 队列为空时取**全部空闲槽位中编号最小者** `s`，`cur` 置为 `s` 所在簇。

三种情况都将 `cursor` 置为 `s+1`。**游标之前空出的槽位在 `cur` 内不会被
重用**，只有走到第 3 步才可能被取到。`cur` 整簇空闲但游标已到末尾时，
该簇在第 2 步出队再入队后被重新选中，从首槽开始。

## 整簇空闲队列的入队与离队时机

队列保存「整簇空闲且不是 `cur`」的簇，先进先出，初始为全部簇按编号
升序：

- **入队**：一个簇在条件成立的那一刻追加到队尾——某槽位回收
  （`Free`/`CacheDrop`/批量释放）使其簇整簇空闲且不是 `cur`；
  或 `Alloc` 第 2 步替换 `cur` 时旧 `cur` 整簇空闲。
  `cur` 自己变整簇空闲时**不**入队，在被替换时才入队。
- **离队**：簇在 `Alloc` 第 2 步成为 `cur` 时从队首离开。

## 批量操作的原子推演

`Fork(slots)`/`Release(slots)` 等价于按给定次序依次 `Dup`/`Free`，
但整批原子：先按次序在副本上推演，遇到第一个失败的元素就返回
`（下标, 错误）` 且整批不生效；同一槽位出现多次时按推演中的累计状态
判定。批量释放成功时，簇入队次序等于元素释放次序。

## 错误

`Dup`/`Free`/`CacheAdd`/`CacheDrop` 依次判定：`ErrRange`（槽位不在
`1..N-1`）、`ErrNotInUse`（槽位空闲），再按操作：`Dup` 为
`ErrOverflow`，`Free` 为 `ErrUnderflow`，`CacheAdd` 为 `ErrExists`，
`CacheDrop` 为 `ErrNoCache`。`Alloc` 只可能报 `ErrNoSpace`。
被拒绝的操作不改变任何槽位、`cur`、`cursor` 与队列。

## 复杂度计数器

非导出字段 `probes` 记录最近一次 `Alloc` 的考察量：

- 非回退路径（第 1 步）：考察的槽位数，不超过 `K`；
- 回退路径（第 3 步）：借助按簇空闲计数的线段树考察的簇数，
  不超过 `2*ceil(log2(簇数))+2`。

`Free`、`CacheDrop` 与队列维护为 O(1) 摊还（队列用切片加头指针，
定期压缩）。所有操作与查询都可并发调用，效果等价于某个串行顺序。

## 本地验证

```bash
# 全量测试（含 2000 组随机序列对照朴素模拟、并发、probes 上界）
go test ./swap/

# 带竞态检测
go test -race ./swap/

# 查看随机对照日志（输入、输出与判定依据）
go test ./swap/ -run TestRandomAgainstNaive -v

# 单项：题目示例走查 / 回退路径 / probes 上界
go test ./swap/ -run 'TestSpecExample|TestFallbackExample|TestProbesBound' -v
```
