# swap — 交换区槽位账本

`swap` 包实现一个交换区（swap area）槽位账本：为换出的页分配槽位，用
引用计数与交换缓存标志共同决定槽位何时回收，并按「簇优先 + 下一适应
游标 + 整簇空闲队列」的次序分配槽位。

## 槽位状态与回收条件

- 槽位编号 `0..N-1`，其中 0 号为交换区头部，永不被分配；可用槽位为
  `1..N-1`。
- 每个槽位有计数 `count`（`0..Max`）与交换缓存标志 `cache`。
- **在用** ⟺ `count > 0 || cache == true`；**空闲** ⟺ `count == 0 &&
  cache == false`。两者各自归零缺一不可：先 `CacheDrop` 后 `Free` 或
 反过来，只有第二次操作才真正回收槽位。
- 新分配的槽位 `count = 0`、`cache = true`（仅由缓存持有）。
- 第 c 簇是编号在 `[c*K, (c+1)*K)` 内的可用槽位；没有可用槽位的簇不
 存在（如 `K=1` 时的 0 号簇），首簇与末簇可能不足 K 个。

## 三步分配次序与游标语义

`Alloc()` 依次尝试，第一个可行的生效：

1. **簇内下一适应**：`cur` 非空且 `cur` 簇内存在编号 `>= cursor` 的空闲
   槽位时，取其中编号最小者 `s`，`cursor = s+1`。游标之前空出的槽位在
   `cur` 内不会被重用。
2. **取队首簇**：`cur` 卸任（若此刻整簇空闲则追加到队尾），`cur` 置空；
   队列非空则取队首簇为 `cur`，取其编号最小的可用槽位 `s`，
   `cursor = s+1`。
3. **全局回退**：队列为空时取全部空闲槽位中编号最小者 `s`，`cur` 置为
   `s` 所在簇，`cursor = s+1`。只有走到这一步，游标之前空出的槽位才
   可能被取到。

全部可用槽位都在用时报 `ErrNoSpace`，且不改变任何状态。

## 整簇空闲队列的入队与离队

- 队列先进先出，初始为全部簇按编号升序。
- **入队**：某簇在「整簇空闲且不是 `cur`」成立的那一刻追加到队尾。`cur`
  自己变整簇空闲时不入队，而是在被替换（`Alloc` 第 2 步卸任）时入队；
  若此时队列为空，它会立即被重新选中并从首槽开始分配。
- **离队**：簇被取为 `cur`（第 2 步弹出队首）时离队。不变量：队列中的
  簇互不相同、都整簇空闲且都不是 `cur`；反之整簇空闲且不是 `cur` 的簇
  必在队列中。

## 批量操作的原子推演

`Fork(slots)` / `Release(slots)` 等价于按给定次序依次 `Dup` / `Free`，
但整批原子：先在副本上按次序推演（同一槽位出现多次时按累计状态判定），
遇到第一个失败的元素就返回 `(下标, 错误)` 且整批不生效；全部成功才一次
性落盘。批量释放时簇入队次序等于元素释放次序。

## 错误与先后次序

`Dup` / `Free` / `CacheAdd` / `CacheDrop` 依次判定：

1. `ErrRange`：槽位不在 `1..N-1`；
2. `ErrNotInUse`：槽位空闲；
3. 按操作：`Dup` → `ErrOverflow`（`count == Max`），`Free` →
   `ErrUnderflow`（`count == 0`，仅由缓存持有），`CacheAdd` →
   `ErrExists`，`CacheDrop` → `ErrNoCache`。

`Alloc` 只可能报 `ErrNoSpace`。任何被拒绝的操作都不改变槽位、`cur`、
`cursor` 与队列。

## 复杂度与计数器

- `Alloc` 非回退路径（第 1、2 步）考察的槽位数不超过 `K`；回退路径
 （第 3 步）借助按簇空闲计数的线段树，考察的簇数不超过
  `2*ceil(log2(簇数)) + 2`。
- `Free`、`CacheDrop` 与队列维护为 O(1) 摊还（环形缓冲队列 + 线段树
  单点更新）。
- 非导出计数器 `probes` 记录考察的槽位/簇节点数，`lastPath` 记录上一
  次 `Alloc` 生效的步骤；`TestProbesBound` 在 `N=10^6, K=8` 下验证上界。

## 并发与可复现性

所有操作与查询均可并发调用，内部由同一把互斥锁串行化，结果等价于某个
串行顺序；批量操作与 `Alloc` 的各步各自是一个原子步骤。相同的操作序列
重放得到完全相同的分配序列与队列（`TestDeterminism`）。
