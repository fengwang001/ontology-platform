# certcache — 证书吊销状态响应缓存

缓存 OCSP 风格的证书状态响应（序号、状态、生效时刻 `a`、下次更新时刻 `b`，`a < b`），
将乱序到达的响应合并为每个证书一条记录，并据此判定证书当前时刻是否可信。

实现位于 `cache.go`，无第三方依赖；时钟可注入（`NewWithClock`），测试结果确定。

## 合并规则（与到达顺序无关）

对同一证书，新响应 `R` 与已有记录 `E` 按下列规则合并；该规则定义了响应之间的
**全序优选关系**，同时具备交换律与结合律，因此任意乱序、任意分批提交都收敛到同一条记录：

- `E` 为吊销（终态）：
  - `R` 非吊销 → 一律忽略。已吊销证书永远不会被任何较旧或较新的正常/暂扣响应恢复信任。
  - `R` 吊销 → 仅当 `R.a < E.a` 时采用 `R`（生效时刻只允许被更早的吊销改小）；
    `a` 相等时取较小 `b`（补全全序、保证顺序无关；`b` 始终取自胜出响应自身）。
- 双方均非吊销（正常/暂扣）：
  - `a` 较大者胜出（更新的响应覆盖较旧响应）；
  - `a` 相等时暂扣胜正常（暂扣是更保守的不可信状态）；
  - 状态与 `a` 都相同时取较小 `b`。
- 收到吊销响应时直接覆盖此前的正常/暂扣记录（吊销对非吊销恒为"更优"）。

顺序无关性的关键在于：规则不是"后来者覆盖"，而是对候选记录做与顺序无关的归约
（吊销集取 `min(a)`，非吊销集按 `(a, 状态权重, -b)` 取最大，且吊销集非空则整体取吊销）。
`TestPermutationIndependence` 对同一批响应的全部 8! 个排列验证结果完全相同。

## 有效区间与信任判定

`Trust(serial)` 以当前时刻 `now` 判定：

| 情况 | 结论 | 可信 |
| --- | --- | --- |
| 无记录 | 未知 `unknown` | 否 |
| 吊销 | 已吊销 `revoked` | 否 |
| 暂扣 | 已暂扣 `suspended` | 否 |
| 正常且 `now < b` | 可信 `good` | 是 |
| 正常且 `now >= b` | 状态已过期 `expired` | 否 |

正常记录的有效区间为左闭右开 `[a, b)`：恰在 `b` 时刻判定即过期。

**全局吊销闩锁**：任一次 `Trust` 判定一旦报出「已吊销」，闩锁置位且不可逆；
此后所有证书的所有判定（包括无记录、其他正常证书）一律不可信并报「已吊销」。
闩锁只在判定观察到吊销时触发（而非吊销响应入库时），配合单锁线性化，
相同输入序列在相同时钟下得到完全相同的判定序列。

## 拒绝原因（按此顺序只报第一个）

1. 证书序号为空 → `empty_serial`
2. 状态非法（非 good/suspended/revoked）→ `bad_status`
3. `a >= b` → `bad_interval`
4. `a` 晚于当前时刻（来自未来）→ `future_response`
5. 容量已满且无可淘汰记录 → `cache_full`

被拒绝的响应不改变任何记录（测试对拒绝前后快照做比对）。

## 容量与淘汰

- 缓存最多保留 `M` 个证书的记录。
- 仅当**新证书**到来且已满时触发淘汰：从「当前时刻 `now >= b` 的正常记录」中
  选 `b` 最小者；`b` 并列取序号字典序最小者。
- 吊销、暂扣、未过期的正常记录均不可淘汰；无受害者时拒绝新证书（`cache_full`）。
- 已满时**已有证书**的响应仍照常合并（不占新名额）。

## 并发

所有 `Submit` / `Trust` 在同一把互斥锁下完成，天然线性化，可被任意并发调用；
`go test -race` 下通过 8 goroutine × 200 次混合提交/判定的压力用例。

## 日志

每次提交与判定均打印「输入、输出、判定依据」（默认 stderr，可 `SetLogOutput` 重定向/静默）。
用 `go test -v` 可在测试输出中看到完整决策依据。

## 本地验证

```bash
go test -v ./certcache/            # 全部用例（含输入/输出/依据日志）
go test -race -count=1 ./...       # 竞态检测
go vet ./...
gofmt -l .
```

快速试用：

```go
now := time.Date(2026, 1, 1, 0, 0, 0, 0, time.UTC)
clock := func() time.Time { return now }
c := certcache.NewWithClock(100, clock)
c.Submit(certcache.Response{Serial: "C1", Status: certcache.StatusGood, A: now.Add(-time.Hour), B: now.Add(time.Hour)})
v := c.Trust("C1") // v.Trusted == true, v.Reason == certcache.TrustGood
```
