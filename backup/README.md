# backup — 块级增量备份链管理器

`backup` 包管理一个由定长块组成的卷的备份链，支持全量备份、增量备份、
从任一保留备份还原，以及删除中间备份时的自动合并与剔除。

代码入口：`backup/manager.go`、`backup/session.go`、`backup/errors.go`。

## 数据模型

- 卷：`blockCount` 个块，每块固定 `blockSize` 字节，初始全部为零。
- 备份：链上的一个节点，只保存一个稀疏块表 `块号 -> 块内容`，
  表中没有的块在还原时向父备份回溯。
- 全量备份（`full=true`）终结回溯；链上第一个备份必为全量。
- 增量备份的父固定为链上紧邻前驱。
- `maxStoredBlocks` 是所有备份稀疏表中块条目总数的硬上限。

## 增量判定

创建备份时持有全局互斥锁，对卷做时间点快照：

- 链为空：创建全量，存全部块（含与零块相同的块）。
- 链非空：逐块把卷当前内容与**父备份的还原结果**比较，仅存不同的块。
  因此“写过又写回原值”的块（无论在本次备份区间内反复写，还是写回
  更早祖先的值）都不会进入增量。
- 若新增条目后存储总数会超过 `maxStoredBlocks`，备份整体拒绝
  （`ErrStorageLimitExceeded`），卷与链均不变。

## 还原回溯

`OpenRestore(id)` 返回只读 `Session`。`ReadBlock(i)` 从目标备份开始，
沿父链逐份向上，取第一份存有第 `i` 块的内容；到全量备份仍无该块，
则取卷初始零块。还原是逐块独立回溯。

会话打开期间，目标备份及其整条祖先链都被标记为“受保护”，
不允许删除；`Close` 后保护解除。重复关闭安全。

## 删除：合并、后继优先与剔除

删除在同一把锁内原子完成，先做全部校验再改状态，任何拒绝都不留副作用。

- 链尾：直接从链上摘除并丢弃，其余备份一字节不动。
- 链首全量：其全部块补入直接后继中后继缺失的块号，后继升格为新全量；
  全量不做剔除。
- 中间增量：
  1. 把被删备份的块并入直接后继；后继已经存有的同号块**以后继为准**，
     只补入后继缺失的块号。
  2. 以新父（被删者原来的父）的还原结果为基准，逐块检查后继：
     凡与新父还原结果相同的块一律剔除。

合并后后继对每个保留块还原出的值与删除前完全一致；被剔除的块本就与
新父相同，回溯到新父仍得到同值。因此删除前后每个保留备份的还原结果
逐字节不变，且各备份只存必需的块（块内容与父还原结果不同的块）。

## 可区分的错误

| 错误 | 触发条件 |
| --- | --- |
| `ErrBlockIndexOutOfRange` | 块号不在 `[0, blockCount)` |
| `ErrBlockSizeMismatch` | 写入/校验时数据长度不等于 `blockSize` |
| `ErrBackupNotFound` | 还原或删除指定的备份 ID 不存在 |
| `ErrStorageLimitExceeded` | 完成备份后存储块总数超过上限 |
| `ErrBackupInRestorePath` | 删除目标处于未关闭还原会话的回溯路径上 |
| `ErrSessionClosed` | 对已关闭会话执行读取 |

所有被拒绝的操作都在持锁校验阶段返回，不改变卷、链、存储计数与会话。

## 并发与确定性

- 卷写入、备份、还原会话、删除共用一把互斥锁，操作之间线性化。
- 备份在锁内快照，因此并发写入对某次备份要么全部可见、要么全部不可见；
  不会出现半块（块内容以整块字节切片拷贝）。
- 删除在锁内完成“校验 → 合并 → 剔除 → 摘链”，期间任何保留备份的
  还原结果不变。
- 备份 ID 按链顺序生成（`B1`、`B2`……），同号块集合按升序返回，
  同一操作序列必然得到相同的各备份块集合。

## 日志

`New(..., logger)` 的最后一个参数指定日志输出（`nil` 用 stderr，
`io.Discard` 关闭）。每次写入、备份、还原、删除都记录：

- 输入：块号、数据长度、备份 ID 等；
- 输出：成功/拒绝、错误类型、实际存储块集合与计数；
- 判定依据：全量/增量选择、逐块比较结论、合并补入数、剔除数、
  会话保护路径、上限计算等。

## 本地验证

```bash
# 常规测试
go test ./...

# 竞态检测 + 详细用例名
go test -race -v ./backup

# 覆盖率
go test -cover ./backup

# 格式与静态检查
gofmt -l .
go vet ./...
```

测试覆盖：写回原值不入增量、删除中间备份后的并入与剔除、后继块优先、
删全量后继升格、连续删除直到剩一个全量、还原会话打开期间删除被拒、
存储上限拒绝与状态不变、各类可区分错误，以及高并发写入/备份的
时间点一致性与操作序列确定性。
