# cbs — 常带宽服务器带宽账本与零松弛回收器

`cbs` 包实现常带宽服务器（Constant Bandwidth Server）的带宽账本：按服务器的
预算与截止期推进、判定空闲服务器的带宽何时可被回收，并在总带宽约束下接纳
唤醒请求。所有操作与查询均可并发调用，效果等价于某个串行顺序（内部互斥锁
线性化）；相同操作序列重放得到完全相同的 `q`、`d` 与拒绝点。

## 模型

- 每台服务器含编号（非空字符串）、预算 `Q` 与周期 `P`（`1 ≤ Q ≤ P ≤ 10^6`），
  带宽为 `Q/P`；最多 32 台，总带宽上限为 1。
- 每台服务器保存剩余预算 `q`、截止期 `d`、待处理工作量 `w`（初始 `w=0`，
  从未被唤醒）。系统时钟 `now` 单调不减（初值 0，上限 `10^15`）。
- 服务器状态是 `now` 的**纯函数**，不落盘：
  - `w > 0` → 就绪（Ready）；
  - `w = 0` 且曾被唤醒 → 按零松弛判定式分为已释放（Released）或
    空闲占用（IdleOccupying）；
  - 从未唤醒 → 已释放。

## 零松弛判定式

空闲服务器（`w=0` 且曾被唤醒）在时钟 `now` 满足下式时判定为**已释放**：

```
q·P ≥ (d − now)·Q
```

等号成立即释放（零松弛恰到）；左侧小 1 也仍占用。乘积可达 `10^21`，
判定使用 128 位乘积（`math/bits.Mul64`），不使用浮点。`now ≥ d` 时右端
非正，必然已释放；因此空闲占用者恒有 `d > now`。

## 唤醒与补充规则

- **Wake(编号, now, 工作量)**（工作量 `1..10^9`，累加后 `w` 超 `10^15` 报参数非法）：
  - 就绪者：只累加 `w`；
  - 空闲占用者：保持 `q`、`d` 不变，`w` 置为工作量；
  - 已释放者：先接纳——其余占用带宽加自己不超过 1，才置 `q=Q`、
    `d=now+P`、`w=工作量`，否则拒绝且保留旧 `q`、`d`（之后他人释放带宽，
    同一次 Wake 重试可通过）。
- **Run(编号, now, δ)**（`1 ≤ δ ≤ w`）：该服务器必须是就绪者中 `d` 最小者
  （并列取编号字节序小者）。每消耗 1 单位 `q` 减 1，`q` 归 0 时**立即**补满
  为 `Q` 且 `d` 加 `P`；`δ` 跨越多次补充时 `d` 一次加多个 `P`。结束后时钟为
  `now+δ`，`w` 减 `δ`（`q` 恰在 `w` 归零的同一单位耗尽时也照常补满并后移 `d`）。
- **Remove(编号)**：仅已释放者可删，否则报占用中。
- 被拒绝的操作不改变任何 `q`、`d`、`w` 与系统时钟。

## 带宽占用口径

- 就绪与空闲占用的服务器占用带宽 `Q/P`，已释放者不占用。
- 任意时刻占用带宽之和不超过 1；求和与接纳比较全程使用精确有理数
  （`math/big.Rat`，既约），不使用浮点。
- `Total()` 返回占用带宽之和的既约分数；`Next()` 返回就绪者中 `d` 最小者。
- 就绪者与空闲占用者的 `q` 恒在 `1..Q` 之间。

## 拒绝原因与顺序

同一次调用只报告第一个命中的原因，顺序固定：

```
参数非法 → 编号不存在 → 时钟回退 → 带宽不足(仅 Wake)
        → 不可运行(Run) → 非最早截止(Run) → 占用中(Remove)
```

`Add(编号, Q, P)` 只可能报：参数非法、编号重复、容量已满。

## 本地验证

```bash
# 全部单元测试 + 2000 组随机对拍（逐单位朴素模拟 vs 批量实现）
go test ./cbs

# 打印对拍日志（每步的输入、输出与判定依据）与拒绝类别命中统计
go test ./cbs -run TestDifferentialRandom -v

# 竞态检测
go test -race ./cbs

# 代码检查
gofmt -l .
go vet ./...
```

测试覆盖：零松弛恰等于算已释放、差一仍占用、空闲占用者唤醒不重置 `q/d`、
已释放者唤醒重置、`q` 归 0 恰好补充与 `δ` 跨越多次补充、总带宽恰等于 1
通过、已释放带宽立即被他人使用、非最早截止被拒、乘积溢出 64 位（128 位
路径）、并发不变量，以及与朴素模拟器对拍 2000 组随机操作序列。
