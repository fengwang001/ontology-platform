# 无赔款优惠等级引擎设计说明

1. `PolicyTerm` 表示一个 365 天保单年度；车辆转移只修改该年度车辆，不新建年度。
2. 续保窗口为 `[EndDay-30, EndDay+GraceDays]`；提前续保的新年度仍从 `EndDay` 开始。
3. 年度出险按 `StartDay` 建立 `termClaims` 索引，常规续保只读取最后年度。
4. 事故日定位用年度区间二分；迟报、撤销仅重算事故年度之后的连续年度。
5. 定级函数先按事故日、编号排序，再统计有责次数，保证保护稳定抵扣第一次。
6. 三次及以上有责直接归零；保护不改变总次数，只在一到二次时抵扣第一次。
7. 追补是不可变事件流水；迟报导致已续保等级降低时按“新等级保费-旧等级保费”追加。
8. 等级升高不追加追补；撤销修正后续等级，但不抹除已形成的追补历史。
9. 被保人账户独立保存配置、年度、事故、保护与追补；全局锁串行化所有入口。
10. 全局锁使并发结果等价于某一串行顺序；账户内不再重复加锁，避免锁顺序复杂度。
11. 被放弃方案：每次续保扫描全部事故。该方案简单但违反常规续保 O(1) 要求。
12. 被放弃方案：把车辆转移建成新年度。该方案会错误切割当前年度事故与保护。
13. 被放弃方案：撤销时清空追补。该方案无法重放真实已经发生的追补事件。
14. 拒绝处理先复制校验、再修改状态，确保任何错误不留下等级、事故、保护或时钟痕迹。
15. 固定错误优先级由各入口校验顺序保证，并用逐对错误用例锁定。
16. 朴素模型保存操作后按完整历史重建年度轨迹，与增量引擎做随机差分对照。
17. 本地验证：`go test ./...`、`go test -race ./...`。
18. 复杂度验证：`go test -bench=BenchmarkRenewalGradingWithLongHistory -benchmem ./ncdengine`。
