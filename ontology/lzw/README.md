# lzw — GIF 风格变宽码字 LZW 流式编解码

包路径：`ontology/ontology/lzw`

面向字节流的 LZW：输入符号为字节 `0..255`，清除码 `256`，结束码 `257`，
字典新增条目从 `258` 起连续编号。码宽初始 `9`、最大 `12`，码按低位在先
（LSB-first）打包进字节流。

## 编码规则

1. 流的第一个码固定是清除码 `256`（在 `NewEncoder` 时立即输出）。
2. 维护当前串 `w`（初始为空），逐字节读入 `c`：
   - 若 `w+c` 已在字典中（单字节恒在），令 `w = w+c`；
   - 否则输出 `w` 的码，把 `w+c` 记为新条目 `e`（取下一个空闲编号），
     令 `w = c`。
3. 每次新增后：
   - 若 `e == 2^当前码宽` 且码宽 `< 12`，则**此后输出**的码宽加一
     （触发新增的那个码仍用旧宽）；
   - 若 `e == 4095`，紧接着以当前码宽（12）输出一个清除码，字典复位为
     只含 `0..257`、码宽回到 `9`，`w` 保持为当前的单字节 `c`。
4. `Close` 时：若 `w` 非空先输出 `w` 的码；随后把下一个空闲编号"计为已
   占用"并执行同样的加宽判定（该编号没有内容、永远不会被引用，只可能影响
   结束码的宽度）；再输出结束码 `257`，最后以 `0` 位补齐到整字节。

空输入的码流为 `256, 257`（均 9 位），打包结果为 `00 03 02`。

示例：`AAAAAAA` 的码序列为 `256,65,258,259,65,257`，全部 9 位，
打包结果 `00 83 08 1c 18 24 20`。

## 解码端升宽时机的推导

解码端不另行约定任何时机，完全由编码规则推出：

- 编码器从**第一个数据码**起，每输出一个数据码（最后一个除外）就新增一
  条，编号连续。因此解码端永远**落后一次新增**：处理完第 1 个数据码后不
  新增；从第 2 个数据码起，处理完一个码后补建编码器在该码之前新增的那
  一条。
- 设解码端下一个空闲编号为 `next`（初始 258）。当 `next == 2^width` 时，
  说明编码器此前已新增了编号 `2^width-1` 之后的下一条——即编号 `2^width`
  恰好在"即将读取的这个码"之前落盘，编码器已按 `width+1` 发送它。因此
  **读取每个数据码之前**（首个数据码除外）检查 `next == 2^width`，成立则
  先把读宽加一。
- 自引用（KwKwK）情形：码值恰等于 `next` 时合法，表示"正在新建的条目引
  用自身"，重建串为 `上一输出串 + 上一输出串首字节`；码值大于 `next` 非
  法。512 号自引用码正是按 10 位读取的，与上一条边界规则严丝合缝。
- 清除码按其在流中的实际码宽读取（编码器在 4095 后以 12 位发清除码）；
  读到清除码后字典与码宽复位，其后第一个码必须是 `< 256` 的字面量。
- 结束码读到后，当前字节剩余位必须全为 0，且之后不得再有任何字节。

## 错误原因

所有解码错误均可通过 `errors.Is` 与下列哨兵区分，并包装为 `*CodeError`
携带出错码的 1 基序号（首个清除码为序号 1）：

- `ErrFirstCodeNotClear`：首个码不是清除码；
- `ErrFirstAfterClear`：清除码之后的首个码 `>= 256`；
- `ErrInvalidCode`：码值大于解码端下一个待新增编号（等于它合法）；
- `ErrPaddingNonZero`：结束码之后补齐位非零；
- `ErrTrailingData`：结束码之后还有多余字节；
- `ErrTruncated`：输入在结束码前被 `Close` 截断；
- `ErrWriteAfterClose`：编码器 `Close` 之后再 `Write`。

被拒绝的调用不改变编码器/解码器状态；解码出错后进入粘滞失败态，后续
`Write`/`Close` 返回同一原因。编解码器均可用同一把锁并发调用，其结果等
价于某种串行顺序；同一输入重放以及任意切分（含逐字节）`Write` 产出的
字节逐字节相同。

## 用法

```go
import "ontology/ontology/lzw"

var buf bytes.Buffer
enc := lzw.NewEncoder(&buf)
enc.Write(input)      // 可分任意次调用
enc.Close()

var out bytes.Buffer
dec := lzw.NewDecoder(&out)
dec.Write(buf.Bytes()) // 同样支持流式切分
if err := dec.Close(); err != nil { ... }
```

清除并继续、空输入、Close 时补计编号恰好升宽、各类非法码流（含出错码序

朴素实现的逐字节对照、切分无关性、重放确定性与 `-race` 并发。
