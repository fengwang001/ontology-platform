# LWW-Element-Set（最后写入者胜出元素集合 CRDT）

`lwwset` 实现了一个无冲突复制的 LWW 元素集合：多个副本可独立增删元素，
通过两两合并（state-based）最终收敛到一致结果；当添加与删除时间戳并列时，
**稳定偏向删除**，保证结果确定、可复现。

## 数据模型

每个副本对每个元素保存两条记录：

- `AddTime`：该元素最新一次添加的时间戳（`0` 表示从无添加）。
- `RemoveTime`：该元素最新一次删除（墓碑）的时间戳（`0` 表示从无删除）。

添加与删除各自独立，只保留时间戳的**较大者**；更旧的时间戳晚到
（乱序到达）不会把已有记录改小。

### 成员判定（并列偏删除）

元素在集合中，当且仅当：

```
AddTime > 0 且 RemoveTime < AddTime
```

即必须存在添加记录，且删除记录不存在或**严格小于**添加时间。
`AddTime == RemoveTime` 时一律视为删除；同时间戳的重复添加不能翻案，
只有严格更新的添加时间才能让元素复活。

## 操作

- `NewReplica(id, limit)`：创建副本。`id` 为正整数；`limit` 为记录元素数上限
  （按不同元素的记录条数计数，**含删除墓碑**）。
- `Add(element, ts)` / `Remove(element, ts)`：本地增删，时间戳必须为正整数，
  元素不能为空串。每次被接受的操作都会追加一条本地变更（序号从 1 递增）。
- `Contains(element)`：按上述规则判定是否在集合中。
- `Lookup(element)`：查看单元素两条记录；`Elements()` 返回当前成员（字典序）；
  `Records()` 返回含墓碑的全部记录快照；`Checksum()` 返回记录的稳定摘要（SHA-256），
  用于自检与收敛比对。

## 合并规则

- `Merge(other)`：**只修改接收方**。对每个元素的两条记录分别取两侧较大值：
  `AddTime = max`、`RemoveTime = max`。合并幂等、可交换、满足合并律，
  重复合并结果不变。
- `MergeChanges(other)`：**按变更序号的增量合并**。接收方为每个来源副本记录一个
  合并位置 `mergePos`，只拉取来源端序号大于该位置的变更，按 LWW 应用后推进位置。
  增量合并的结果与一次性整份 `Merge` **完全一致**；交替、乱序、重复调用都等价。
  整份合并会把合并位置推进到来源当前最新序号，之后增量可无缝续传。
- `ChangesSince(since)` + `ApplyChanges(sourceID, changes)`：跨进程/跨网络的
  变更流形态：导出某序号之后的变更，再原子地应用到另一副本。

## 并发与失败原子性

- 所有方法均可用多个 goroutine 并发调用；副本内部使用 `sync.RWMutex`。
- 合并按**副本编号升序加锁**（目标写锁、来源读锁），因此
  `A.Merge(B)` 与 `B.Merge(A)` 互逆方向同时进行不会死锁。
- 任何被拒绝的调用（非法参数、序号不连续、超上限等）都**整体失败、不留痕**：
  记录、本地变更序号、对各来源的合并位置均保持调用前状态。增量合并先在临时
  映射上计算，校验通过后才一次性提交。

## 边界与错误类别

所有错误都是互不相同的哨兵错误，用 `errors.Is` 精确区分：

| 错误 | 触发条件 |
| --- | --- |
| `ErrInvalidReplicaID` | 副本编号 `<= 0`（构造、合并位置查询、变更流来源） |
| `ErrInvalidLimit` | 记录上限 `<= 0` |
| `ErrEmptyElement` | 元素为空字符串 |
| `ErrNonPositiveTimestamp` | 时间戳 `<= 0` |
| `ErrLimitExceeded` | 操作/合并会使不同元素的记录数（含墓碑）超过上限 |
| `ErrNilReplica` | 合并目标或来源为 `nil` |
| `ErrSelfMerge` | 把副本与自身合并 |
| `ErrInvalidSince` | 增量起点序号为负或超过当前序号 |
| `ErrSequenceGap` | 变更流序号与已合并位置不连续 |
| `ErrMissingTimestamp` | 变更没有恰携带一个时间戳（全缺或添加/删除同时存在） |

注意：删除是墓碑语义，删除一个从未添加过的元素也会产生一条记录并占用名额；
名额按“不同元素”计数，对已有元素（含已删除元素）的重复操作不新增名额。

## 本地验证

```bash
# 全量测试
go test ./...

# 竞态检测 + 每步输入/记录/判定依据日志
go test -race -v ./lwwset

# 多轮重复（覆盖并发调度）
go test -race -count=10 ./...

# 静态检查与格式
go vet ./...
gofmt -l .
```

测试覆盖：并列时间戳偏删除、乱序/旧时间戳到达不收缩记录、
增量合并与整份合并等价、合并律与合并顺序无关、
非法参数分类及拒绝后状态（记录/序号/合并位置）不变、
多执行体并发增删与互逆方向合并不死锁且最终收敛，
并通过随机差分测试与逐元素取最大值的朴素参照实现逐项比对。
