# preagg：面向倾斜键的两阶段预聚合器

同一键的连续变更事件先在**本地缓冲**按条数攒批，攒满阈值后作为一条变更
推入**全局累计视图**；全量冲刷后，每个键的累计值与批量分组求和逐键一致
且可复现。

## 缓冲与热键规则

- 每个键在本地缓冲维护 `{待推送增量和 Sum, 已攒条数 Count}`。
- 某键 `Count` 达到阈值（含阈值本身）时，立即把 `Sum` 作为一条变更推给
  全局视图、清空该键缓冲，并把该键标记为**热键**。
- 同一批次内某键出现两次及以上，该键在**该批结束后**成为热键。
- 热键此后每到达一条事件都**立即单独推送**，不再攒批（成为热键之前已
  攒下的缓冲保留，直到显式冲刷）。
- 全局视图始终只包含已推送的变更，不包含本地尚未推送的缓冲。

## 冲刷语义

- `FlushKey(key)`：推送该键的待推送增量（若有），并把该键移出热键集合；
  对其他键无影响，重复调用是幂等空操作。
- `FlushAll()`：把所有尚有待推送增量的键按**字典序**逐个推送，并清空
  热键集合。冲刷后全局视图等于截至当前已喂事件的分组求和。

## 非法输入

四类非法输入整体拒绝，原因互不相同（均为可 `errors.Is` 判定的哨兵错误）：

| 输入 | 错误 |
| --- | --- |
| 阈值非正 | `ErrNonPositiveThreshold` |
| 空批次 | `ErrEmptyBatch` |
| 事件键为空 | `ErrEmptyKey` |
| 事件增量为零 | `ErrZeroDelta` |

批次先整体校验再生效：任一条被拒则整批不生效，不留下任何状态痕迹，
之后实例仍可继续正常使用。

## 并发与自检

- 写操作互斥，读操作（`View` / `Pending` / `HotKeys` / `PushLog` /
  `SelfCheck`）走读锁并返回快照副本；对已喂满的实例并发反复读取，结果
  逐字段一致。
- `SelfCheck()` 校验两条核心不变量：
  1. 推送记录从空开始按序重放，精确重建当前全局视图；
  2. 任意键 `视图值 + 本地待推送增量` 等于截至当前已喂事件的分组求和。
