# changebuffer：带空闲空间估计位图的变更缓冲

`changebuffer` 包对**不在缓冲池中的二级索引页**缓冲插入、删除标记与清除
操作；当页被读入或估计空间不足时，按操作到达序（FIFO）合并回页。

## 构造与范围

`New(S, Kp, G)`：

- `S`：页字节数，范围 `64..1_000_000`。
- `Kp`：每页缓冲操作数上限，范围 `1..1_000_000`。
- `G`：全局缓冲字节上限，范围 `1..1_000_000_000_000`。

页号为 `0..1_000_000` 的整数；所有页初始为空且不在池中。条目为
`(非空字节串键, 尺寸, 删除标记)`，`used = 全部条目尺寸之和`，空闲 `F = S-used`。

## 空闲桶与保证下界

空闲桶 `bucket(F)`（比较均为严格小于，故恰等时归入更高桶）：

| 条件 | bucket | 保证下界 `lb` |
| --- | --- | --- |
| `32F < S` | 0 | `0` |
| 否则 `16F < S` | 1 | `floor(S/32)` |
| `8F  < S` | 2 | `floor(S/16)` |
| 其余 | 3 | `floor(S/8)` |

即 `32F < S → 0`，否则 `16F < S → 1`，否则 `8F < S → 2`，否则 `3`。
例如 `S=1024`：`F=32` 时 `32F == S`（不满足严格小于）落桶 1；
`F=64` 落桶 2；`F=128` 落桶 3。下界均向下取整，如 `S=100` 时
`lb = 0, 3, 6, 12`。

## 条目语义（直接施加与合并共用）

- `Insert(k,e)`：`k` 已存在（无论是否带删除标记）→ 仅清除删除标记，尺寸
  不变、不占新空间；不存在 → 当且仅当 `F >= e` 时加入尺寸为 `e` 的条目，
  否则拒绝（`ErrPageSpace`）。
- `DeleteMark(k)`：存在则置删除标记；不存在无事发生（不受空间限制）。
- `Purge(k)`：存在且带标记则移除并释放其尺寸；存在但未标记或不存在均无事
  发生。

## 缓冲与强制合并判定

`Op(page, kind, key, e)`：`Insert` 的 `e ∈ 1..S`，其余 `kind` 的 `e` 必须为
`0`，否则 `ErrInvalidArgument`。

- 页**在池中**：直接施加；`Insert` 空间不足返回 `ErrPageSpace`。
- 页**不在池中**，当且仅当以下条件全部成立才把操作追加到该页队列尾部：
  - 该页队列长度 `< Kp`；并且
  - `kind` 不是 `Insert`；**或**
  - `kind` 是 `Insert` 且
    `bufBytes + e <= lb(bucket(F))`（页内额度，按队列中**全部 Insert 尺寸
    之和**累计判断，而非逐条）且
    `Σ_all_pages bufBytes + e <= G`（全局额度）。

  `DeleteMark`/`Purge` 不占字节额度，因此不受 `lb` 与 `G` 限制，但仍受
  `Kp` 限制。

- 否则**强制合并**：先把该页读入池——把队列按到达序全部施加到页条目
  （合并本身不会因空间失败），清空队列并把该页的 `bufBytes` 从全局计数中
  释放——再把本次操作直接施加到页上。若直接施加的 `Insert` 因空间不足被
  拒，则**整体拒绝**：页保持不在池中，其条目、队列、`bufBytes` 与全局计数
  全部不变（实现先在工作副本上合并并施加，成功后才提交）。

## 其他操作与不变式

- `Load(page)`：不在池则按序合并并入池；已在池则无操作。
- `Evict(page)`：在池则离开池；不在池返回 `ErrPageNotInPool`。
- `View(page)`：返回队列按序逻辑施加后的条目列表（键升序，含尺寸与标
  记），**不改任何状态**；其结果与随后 `Load` 得到的条目完全一致。
- 错误判定顺序：构造参数/页号/键/kind/e 非法 → `ErrInvalidArgument`；
  `Evict` 页不在池 → `ErrPageNotInPool`；`Op` 空间不足 → `ErrPageSpace`。
- 所有方法经同一把互斥锁串行化，并发调用等价于某个串行顺序；任意时刻
  `used <= S`，在池页队列为空，不在池页队列长度 `<= Kp`、
  `bufBytes <= lb(bucket(F))`，全局 `ΣbufBytes <= G`，合并不因空间失败，
  相同序列重放得到完全相同的状态。

## 本地验证

```bash
# 全部测试（含竞态检测）
GOCACHE=/tmp/gocache go test -race ./...

# 详细查看 2000 组随机差分测试的输入、输出与判定依据日志
GOCACHE=/tmp/gocache go test ./changebuffer/ -run TestRandomDifferential -v

go vet ./...
gofmt -l .
```

测试包含：

- 规格示例（`S=1024,Kp=3,G=150`，页 7/8/9）逐步复现。
- `bufBytes+e` 恰等于 `lb` 缓冲、多 1 强制合并；额度按队列累计。
- 全局额度恰等于 `G` 缓冲、多 1 强制合并；强制合并/`Load` 后额度释放。
- `DeleteMark`/`Purge` 不受 `G` 与空间限制但受 `Kp`；队列恰为 `Kp` 时
  强制合并。
- 桶边界 `32F==S`、`16F==S`、`8F==S` 与 `lb` 取整。
- `Insert` 已存在键（含已标记）清标记不占空间；标记/清除的空操作与释放。
- 同键不同到达序得到不同结果；强制合并拒绝时整体不变；池内直接施加拒
  绝；`Evict` 后再次缓冲；`View` 不改状态且等于 `Load` 结果。
- `TestRandomDifferential`：2000 组确定性随机序列，与独立按规则书写的朴素
  模拟逐步对照（条目、队列、池状态、used/bufBytes/全局计数及每个返回
  值），日志打印输入、输出（direct/buffered/force-merged 或错误）与判定
  依据。
- `TestConcurrentExercises`（`-race`）与重放确定性测试。
