# coordinator：消费组协调者

实现消费组的加入与同步状态机：管理成员加入窗口、代数递增、领导者
选取与分配分发。时钟由调用方以毫秒时间戳传入，初始代数为 0，所有
操作可并发调用（内部串行化，等价于某个串行顺序），相同调用序列重放
得到完全相同的状态序列、领导者与代数。

## 四状态迁移表

| 当前状态 | 操作 | 条件 | 下一状态 | 备注 |
| --- | --- | --- | --- | --- |
| Empty | Join | — | Preparing | 记开始时刻为 now，随后按完成条件判定（单成员立即完成） |
| Preparing | Join | 已知成员未齐 | Preparing | 开始时刻不变；首次加入记入本轮加入序，重复加入幂等 |
| Preparing | Join | 加入后已知成员全部到齐 | AwaitingSync | 完成本轮：代数 +1 |
| Preparing | Tick | now ≥ 开始时刻 + T 且本轮有人加入 | AwaitingSync | 未加入的已知成员被移除，完成本轮：代数 +1 |
| Preparing | Tick | now ≥ 开始时刻 + T 且本轮无人加入 | Empty | 成员全部移除，代数不变 |
| Preparing | Tick | now < 开始时刻 + T | Preparing | 无变化 |
| Preparing | Leave | 剩余已知成员全部已加入 | AwaitingSync | 完成本轮：代数 +1 |
| Preparing | Leave | 本轮无人加入或成员清空 | Empty | 成员全部移除，代数不变 |
| AwaitingSync | Join / Leave | — | Preparing | 开启新一轮，记开始时刻为 now（Leave 致成员清空则为 Empty） |
| AwaitingSync | Sync（领导者提交合法分配表） | 分配表成员集 = 本代成员集 | Stable | 分配表生效 |
| Stable | Join / Leave | — | Preparing | 开启新一轮，记开始时刻为 now（Leave 致成员清空则为 Empty） |
| Stable | Sync | — | Stable | 返回成员自己的分配 |
| 任意 | Tick | 非准备中 | 不变 | 仅推进时钟高水位 |

## 完成条件（准备中 → 等待分配）

满足以下任一条件即完成本轮，完成时**代数加一**，状态变为等待分配：

1. 所有已知成员（含上一代存活成员）都已在本轮加入——在触发它的
   那一次 `Join`/`Leave` 调用内立即完成；
2. `Tick(now)` 满足 `now >= 开始时刻 + T`（恰等于 T 也算超时）——
   未在本轮加入的已知成员被移除后完成。

特例：准备中超时或离开后若**没有任何成员已加入本轮**，则成员全部
移除、组进入空状态且**代数不变**；成员被清空时同样进入空状态、代数
不变。

## 领导者选取

完成本轮时，领导者为**本轮加入序最早的成员**（而非上一代领导者）。
加入序只记录每个成员在本轮的首次加入，重复加入幂等且不改变次序。

## 同步与心跳

- `Sync(成员, 代数, 分配表)`：依次检查未知成员、代数过期；准备中报
  需重新加入；等待分配状态下空分配表表示仅查询（返回尚未就绪），
  非领导者提交非空分配表报非领导者提交，领导者提交时分配表成员集合
  必须恰等于本代成员集合；稳定状态返回成员自己的分配。
- `Heartbeat(成员, 代数)`：按未知成员、代数不等、准备中的顺序检查，
  只报第一个。
- 所有拒绝原因（时钟倒退、未知成员、代数过期、需重新加入、尚未就绪、
  非领导者提交、分配表成员集不符）均可通过 `errors.Is` 区分；被拒绝
  的操作不改变状态、代数、加入序与开始时刻。
- 时钟：`now` 小于此前已接受的最大时刻时报时钟倒退。

## 本地验证

```bash
# 全部测试（含竞态检测）
go test -race ./coordinator/

# 查看逐步朴素模拟对照日志（输入、输出与判定依据）
go test -v -run TestModelReplay ./coordinator/

# 指定用例，如超时恰等于 T 时完成
go test -v -run TestTimeoutExactlyTCompletes ./coordinator/
```

`TestModelReplay` 以固定种子的随机操作序列同时驱动协调者、第二个
协调者（重放确定性）与按规则写成的朴素逐步模拟，逐步对照错误、
状态、代数、领导者、成员集与加入序。
