# seating — 影厅选座登记器

带保留时限与孤座回避的选座登记器：为一组观众在同排内挑选连续座位，
支持保留（Hold）、确认（Confirm）、释放（Release）与座位状态查询（Seats）。
所有方法可并发调用，效果等价于某个串行顺序；相同操作序列重放得到完全相同的结果。

## 模型

- 影厅有 `R` 排（1..R）、每排 `W` 个座位（1..W），保留时限为 `T`。
  构造参数合法范围：`R ∈ [1,26]`、`W ∈ [1,40]`、`T ≥ 1`，否则返回 `ErrInvalidConfig`。
- 时刻由调用方传入的 `now` 给出。三个写操作先检查时钟：
  `now` 小于已被接受操作见过的最大 `now` 时报 `ErrClockRollback`。
  被拒绝的操作不改变座位、保留与已见最大 `now`。
- 座位在 `now` 空闲，当且仅当没有已确认订单占用它，也没有活跃保留占用它。

## 保留过期口径

- 保留成功时 `expiry = now + T`。
- `now >= expiry` 即已过期、不再占座；`now == expiry` 那一刻起座位即可被后续 Hold 选中，
  而对该保留的 Confirm/Release 报 `ErrHoldExpired`。
- `Seats(now)` 只按传入的 `now` 计算视图，不检查也不更新已见最大 `now`，查询不改变任何状态。

## 孤座定义

对候选段 `[s, s+k-1]`（段内全部空闲），考察选定后该段**左侧紧邻的最大空闲连续区**
与**右侧紧邻的最大空闲连续区**：

- 任一侧长度**恰为 1** 即为孤座；
- 长度为 0 或不小于 2 都不算孤座；
- 紧邻墙壁的单个空闲座也算孤座（墙壁不免除孤座判定）。

## 两遍选座与排序规则

1. 候选为**所有排**中全部空闲的连续段 `[s, s+k-1]`（不跨排）。
2. 第一遍：只在全部排的无孤座候选中选；若一个都没有，才退到第二遍在全部候选中选。
3. 选择次序依次为：
   - 排号小者优先；
   - 段中心偏离 `|(2s+k-1) - (W+1)|` 小者优先；
   - 起始座号 `s` 小者优先。
4. 成功时返回自增保留号（从 1 起，只有成功才消耗，严格连续无空洞）、排号与起始座号。
   `k ∉ [1,8]` 报 `ErrInvalidGroupSize`；没有任何排存在 `k` 个连续空闲座报 `ErrNoSeats`。

## Confirm / Release 拒绝原因优先级

按以下顺序判定，四种原因可区分：

1. `ErrHoldNotFound` — 保留号从未发出；
2. `ErrHoldConfirmed` — 已确认（已确认且已过期也报此项）；
3. `ErrHoldReleased` — 已释放（已释放且已过期也报此项）；
4. `ErrHoldExpired` — 已过期（`now >= expiry`）。

全部通过时，Confirm 把活跃保留转为永久占用，Release 把活跃保留释放使座位立即空闲。

## 不变量

- 任一时刻同一座位不被两个活跃保留或确认订单同时占用；
- 空闲、保留与已确认的座位数之和恒等于 `R * W`；
- 过期保留所占座位自 `expiry` 起即可被后续 Hold 选中；
- 保留号严格连续无空洞。
