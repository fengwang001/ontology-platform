# window —— 可在线升级窗口大小的滚动窗口聚合器

`window.Aggregator` 在不停流的前提下把滚动（tumbling）窗口大小从旧值切换到新值：
每个事件恰好落入且仅落入一套窗口划分，已发出的结果永不被改写。

## 核心概念

- **事件**：`Event{Key, Time, V}`，事件时间 `Time` 为任意整数（允许负数）。
- **窗口**：以时间 0 为原点、左闭右开 `[Start, End)`。大小为 `s` 时，时间 `t`
  所属窗口右端为 `(floor(t/s)+1)*s`（数学 floor，负数也正确，例如 `s=4,t=-1 -> End=0`）。
- **输出**：`Result{Key, Start, End, Count, Sum}`，按 `(End, Key)` 升序发出，发出即清除。
- **水位**：初值 `0`；每处理一条被计入的事件后更新为
  `max(当前水位, 已见最大事件时间 - 固定延迟)`，只增不减。
- **到期**：水位 `>= 窗口右端` 时，该窗口输出并清除。

## 迟到与归属规则

每条事件**先按处理前的水位判定迟到，再更新水位**：

1. 确定该事件使用哪套划分（见下）；算出窗口右端 `End`。
2. 若 `End <= 当前水位`，判定为迟到：丢弃、迟到计数加 1，**不更新水位、不改任何状态**。
3. 否则计入对应窗口（条数 +1、和累加），更新水位，输出所有到期窗口。

归属划分：

- 无待完成升级时，事件按当前大小划分。
- 有升级待完成、生效点为 `B` 时：`Time < B` 按旧大小划分，`Time >= B` 按新大小划分。
- 迟到判定使用归属后的那套划分，因此升级前后可能对同一时间给出不同结论
   （例如新大小 6 下 `t=24 -> End=30`，水位 30 时迟到；旧大小 4 下 `End=28` 本会准时）。

## 升级生效点的推导

申请新大小 `S`（当前大小为 `C`）时：

1. `L = lcm(C, S)`。两套划分在 `L` 的整数倍处天然对齐：任何 `L` 的倍数既是
   旧窗口边界也是新窗口边界，因此在该点两侧切换不会产生重叠或缺口。
2. `M = max(申请时水位, 所有持有状态窗口右端的最大值)`。
   - 取水位是为了不再重开任何已可输出的区间；
   - 取在途窗口最大右端是为了不切断任何已接收事件的旧窗口。
3. `B =` `L` 的整数倍中 `>= M` 的最小者，即 `ceil(M/L)*L`（数学 floor/ceil，允许 M<=0）。
4. `[..., B)` 的事件全走旧划分，`[B, ...)` 的事件全走新划分。
   旧划分在 `B` 左侧的最后一个窗口右端恰为 `B`，新划分在 `B` 右侧的第一个窗口
   左端恰为 `B`，两套窗口互不重叠、覆盖整条时间轴。

**升级完成条件**：水位推进到 `>= B` 时（在处理下一条事件、输出到期窗口的同一串行步骤中）
当前大小改为 `S`，清除待完成状态。此刻所有右端 `<= B` 的旧窗口必然已经输出完毕。
若申请时就满足 `水位 >= B`（空闲时 `M=0、B=0`），升级当场完成。

## 拒绝规则（按序，只报第一个可区分错误）

被拒绝的申请不改变水位、窗口状态与迟到计数：

1. 新大小 `<= 0`：`ErrNonPositiveSize`
2. 已有升级待完成：`ErrUpgradePending`
3. 新大小等于当前大小：`ErrSameSize`
4. `lcm(C, S) > 10^9`：`ErrLCMLimitExceeded`（恰为 `10^9` 合法）

## 并发、不变量与确定性

- `Submit` 与 `Resize` 由同一把互斥锁串行化，可被任意并发调用；方法返回即代表
  该操作已在某个全局串行顺序中处理完毕，每个事件只按该顺序下的一套划分归属。
- 恒等式：`总提交数 = 已输出条数 + 迟到数 + 在途窗口内条数`（`Stats` 可随时核对）。
- 同一操作序列（相同调用次序与参数）重放得到完全相同的输出与统计。
- 注意：输出回调 `Sink` 在聚合器锁内被同步调用，回调中不得再次调用聚合器方法；
  聚合器默认向 stderr 打印输入、输出与判定依据，可通过 `SetLogger` 替换。

## 本地验证

```bash
# 全量测试（输入/输出/判定依据日志需 -v）
go test -v ./window/

# 竞态检测 + 重复执行（并发用例）
go test -race -count=5 ./window/

# 只看关键场景
go test -race -v -run 'TestResize4to6|TestLate' ./window/

# 格式化与静态检查
gofmt -l .
go vet ./...
```

关键用例：

- `TestResize4to6_M_Exactly_12_Boundary_12`：M=12 时 B=12。
- `TestResize4to6_M_SlightlyAbove_12_Boundary_24`：M=16（略超 12）时 B=24，
  事件跨 B 两侧归属、旧窗口先输出。
- `TestLateDuringPending_BothPartitions`：升级期间两套划分下的迟到判定。
- `TestResizeRejections`：四类非法输入及拒绝后状态不变。
- `TestConcurrentAndDeterministicReplay`：并发不变量与串行重放确定性。
