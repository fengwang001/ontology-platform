# redolog：重做日志并行回放器

带小事务（MTR）原子性与文件操作屏障的重做日志并行回放器。构造参数为回放
线程数 `W`（1..64）与批次记录上限 `M`（1..10^6）。

## 小事务的暂存与入队时机

- `Page` 记录被接受后先**暂存**在当前未结束的小事务里，不入队、不计
  `pending`，也不会被任何批次看到。
- 对应 `End` 到达时，该小事务的全部暂存记录一次性进入分发队列：记录
  `(space, page)` 进入线程 `w = (space*7 + page) mod W` 的队列，队列内保持
  LSN 升序（全局 LSN 严格递增，按到达顺序追加即有序）。`pending` 为各队列
  记录总数。
- `Finish()` 时仍未 `End` 的小事务的暂存记录被整体丢弃（计入被丢弃数），
  保证小事务原子性：要么全部入队，要么全部丢弃。
- `File` 记录自成单记录小事务，不需要 `End`，且不得出现在未结束的 mtr 之中。

## 批次触发与文件操作屏障

- `End` 使 `pending >= M` 时**立即**做一个批次；一个 `End` 可一次带入多条
  记录使 `pending` 越过 `M`，仍只算一个批次。
- `File` 记录到达时充当屏障：若 `pending > 0` 先做一个批次，再立即执行该
  文件操作；`pending == 0` 时不算批次。
- `Create`：对已存在的表空间无影响，否则新建空表空间。
- `Delete`：对不存在的表空间无影响，否则删除该空间及其全部页状态
  （此后再 `Create` 的空间里所有页都是 `value=0、pageLSN=0`）。
- `Finish()` 先做一个批次（仅 `pending > 0` 时才算批次），再丢弃未结束的
  小事务。批次内按线程号 `0..W-1` 依次处理各队列，队列内按 LSN 升序逐条
  处理；批次后队列清空、`pending` 归零、批次数加一。
- `Finish()` 先做一个批次（仅 `pending > 0` 时才算批次），再丢弃未结束的
  小事务。批次内按线程号 `0..W-1` 依次处理各队列，队列内按 LSN 升序逐条
  处理；批次后队列清空、`pending` 归零、批次数加一。

## 应用 / 跳过 / 丢弃三种判定

批次内对每条页记录依次判定：

1. **空间缺失**：记录所属表空间不存在，丢弃。
2. **已应用**：`lsn <= pageLSN`（恰等也算），跳过。
3. **应用**：`value += delta`，`pageLSN = lsn`。

`ApplyLog()` 按实际处理次序返回 `(lsn, 结果)` 列表。不变式：
已接受的 Page 记录数 = 应用数 + 已应用数 + 空间缺失数 + 被丢弃数 +
暂存或排队中的数。全部结束后，最终页状态与「严格按 LSN 升序逐条处理全部
已 End 的小事务记录」的顺序回放相同，与 `W`、`M` 取值无关；相同输入序列
重放得到完全相同的批次与 `ApplyLog`。

## 拒绝语义

拒绝原因可区分（`Error.Reason`），按此顺序只报第一个：参数非法 →
回放已结束 → 回放已开始 → LSN 不够大 → 小事务错误。被拒绝的记录不改变
任何状态，也不推进已接受的最大 LSN 与最大 mtr 号（同一 lsn 可修正后重投）。

## 并发

所有操作与查询（`Feed` / `LoadPage` / `Finish` / `ApplyLog` / `Pending` /
`Batches` / `Stats` / `PageState`）均可并发调用，内部以互斥锁串行化，
结果等价于某个串行顺序。
