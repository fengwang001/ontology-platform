# frame — 分块流式写出器与校验读取器

类 Snappy 分帧格式，内部使用字节游程压缩，按压缩收益与历史失败自适应
决定每块是否压缩；读取端在任意切分点下严格解码，输出字节、判定与错误
偏移可精确复现。

## 分帧与掩码校验和

流以标识块开头，每个块为 **1 字节类型 + 3 字节小端长度（负载长度）+ 负载**。

| 类型 | 含义 |
| --- | --- |
| `0xFF` | 标识块，负载为 6 字节 `sNaPpY`，可在流中重复出现 |
| `0x00` | 游程压缩数据块 |
| `0x01` | 原样数据块 |
| `0x80`–`0xFE` | 可跳过块，读取端流式丢弃负载 |
| `0x02`–`0x7F` | 保留的不可跳过块，读取端报错 |

数据块负载 = 4 字节小端掩码校验和 + 数据。校验和对**未压缩**数据计算：

```
crc  = CRC-32C（Castagnoli，标准库 hash/crc32）
mask = ((crc>>15) | (crc<<17)) + 0xa282ead8   // uint32 回绕
```

未压缩数据每块至多 65536 字节，故数据块负载长度至多 65540。

## 游程压缩

控制字节 `c < 128`：后接 `c+1` 个字面字节（1–128）；`c >= 128`：把后一个
字节重复 `(c-128)+3` 次（3–130）。压缩算法固定：从左扫描，取当前位置的
极大相同字节段长度 `r`；若 `r >= 3`，先写出待出字面缓冲（非空时），再写
重复令牌，一个令牌至多 130 次，段内余下部分按新的段重新判定；若 `r < 3`，
把这 `r` 个字节逐个放入字面缓冲，缓冲满 128 个立即写出；结束时写出剩余
缓冲。例：70 个 `'a'` → `C3 61`；131 个 → `FF 61 00 61`。

## 自适应跳过规则（NewWriter(F, S)，F、S ≥ 1）

`Write` 缓冲恰满 65536 字节立即成块；`Flush` 把非空缓冲成块；`Close` 先
`Flush` 再封闭。标识块在第一个块之前写出一次；空流 `Close` 只写标识块。
输出只取决于写入字节与 `Flush`/`Close` 位置，与 `Write` 切分无关。

每块（n 字节）按顺序判定：

1. `skip > 0`：原样成块，`skip` 减 1，减到 0 时置探测标记 `probe=真`；
2. 否则 `n < 16`：原样成块，不改变 `f`、`skip`、`probe`、`curS`；
3. 否则压缩得 `comp`：若 `len(comp) < n − n/8`（整数除法，恰等不算收益）
   用压缩块并令 `f=0`、`probe=假`、`curS=S`；否则用原样块：
   - `probe` 为真（探测失败）：`probe=假`、`curS=min(2×curS, 8×S)`、
     `skip=curS`、`f=0`；
   - `probe` 为假：`f` 加 1，`f == F` 时 `skip=curS`、`f=0`。

`curS` 初值为 `S`。

## 读取端错误次序与偏移

`Feed(p)` 返回本次调用内完整且校验通过的块所解出的数据（绝不输出半块；
出错时同时返回出错块之前已解出的数据与错误）；`Close` 判定流是否完整。
错误为带偏移的 `*FrameError`，偏移是出错块头第一个字节在整个流中的位置：

| 错误 | 触发 |
| --- | --- |
| `ErrNoIdentifier` | 首块类型非 `0xFF`（先于其他判定）；空流 `Close`（偏移 0） |
| `ErrBadIdentifier` | `0xFF` 块长度非 6 或负载非 `sNaPpY` |
| `ErrChunkLen` | 数据块负载长度 < 4 或 > 65540（块头收齐即判，不等负载） |
| `ErrReserved` | 类型 `0x02`–`0x7F` |
| `ErrDecode` | 压缩令牌被截断或解出超过 65536 字节（先于校验和） |
| `ErrChecksum` | 掩码校验和不匹配 |
| `ErrTruncated` | `Close` 时停在块头或负载中间 |

出错后读取端粘滞，之后 `Feed` 返回同一错误且无输出。可跳过块按流式丢弃，
读取端缓冲不超过 65544 字节（非导出计数器 `maxBuffered` 记录峰值）。

## 并发与确定性

所有方法可并发调用，结果等价于某个串行顺序；被拒绝的写入不改变状态；
相同操作序列重放得到完全相同的字节与判定。

go test ./frame/                 # 全部单测与 2000 组随机模型对照
