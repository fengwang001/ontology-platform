# lifecycle — 访问期分层对象存储生命周期计费器

按对象的**最近访问日 `la`** 与当前日期 `now` 推导存储层级（层级不物化），在
`Put`（覆盖）/`Delete`/`Get`/`GetMany` 时一次结清：

- 存储费（Storage）
- 早离补费（Exit）
- 检索费（Retriev，含每周期免费检索额度）

所有费用使用 `math/big.Int` 返回：`now` 可达 10⁹、日价与大小可达 10⁶，存储费
理论上可达 10²¹，超出 int64。

## 层级推导

令 `Δ = now − la`（Δ≥0）：

| 条件 | 当前层 | 进入日 |
| --- | --- | --- |
| `Δ < A` | 热层（`LayerHot=0`） | `la` |
| `A ≤ Δ < B` | 凉层（`LayerCool=1`） | `la + A` |
| `Δ ≥ B` | 冷层（`LayerCold=2`） | `la + B` |

辅助函数：

- `Layer(la, now, A, B)`：当前层级。
- `LayerStays(la, now, A, B) (hot, cool, cold)`：各层停留天数。

## 存储费公式（Settle）

```
存储费 = size × ( p0 × min(Δ, A)
                + p1 × max(0, min(Δ, B) − A)
                + p2 × max(0, Δ − B) )
```

即各层停留天数 × 该层日价求和后乘以对象大小。`Settle(cfg, obj, now)` 是不改变
计费器状态的纯查询；操作内部也用同一计算。

## 早离补费：只看当前层

只按 **`now` 所处的当前层** 及其在该层的停留计补费；沿途经过、已被策略转出的
层**不产生**任何补费：

- 热层：`0`
- 凉层：停留 `s = Δ − A`，`补费 = max(0, m1 − s) × p1 × size`
- 冷层：停留 `s = Δ − B`，`补费 = max(0, m2 − s) × p2 × size`

边界：`Δ == A`（凉层停留 0，补费为 `m1·p1·size`）；`Δ == B` 为冷层停留 0；
停留恰等于最短停留（如凉层 `s == m1`）时补费为 0。

## 检索费与免费额度

仅 `Get/GetMany` 在 Settle 之后计检索费：

- 热层：检索费 0，**不消耗**免费额度，也不触发周期切换。
- 凉层：单价 `r1`；冷层：单价 `r2`。

周期号 `period = floor(now / 30)`。计费器保存 `(period, used)`，初始 `(0, 0)`。
凉/冷层检索时：

1. 若当前周期号与保存值不同，切换周期并把 `used` 清零；
2. 本次免费量 `fg = min(size, Q − used)`，然后 `used += fg`；
3. `检索费 = (size − fg) × 该层检索单价`。

不变量：任意时刻 `0 ≤ used ≤ Q`，且 `used` 属于保存中的周期号。

## 操作语义

- `Put(key, size, now)`：键不存在 → 建立对象 `la=now`，费用 0；键存在 → 先对旧
  对象 Settle（只收存储费与补费），再以 `la=now` 建立新对象。Put 不因键存在而
  拒绝。
- `Delete(key, now)`：Settle 后移除对象，返回存储费 + 补费（检索费 0）。
- `Get(key, now)`：Settle → 计检索费 → `la=now`（对象立刻回到热层）。
- `GetMany(keys, now)`：先校验，**全部键存在才执行**；随后严格按给定次序逐个
  Get。同一键重复出现时，后一次看到前一次已重置的 `la`，因此费用可能不同。
  结果与按同样次序逐个调用 `Get` 完全一致；任一键不存在则整体拒绝、状态不变。

时钟要求：`now` 必须 ≥ 已接受的最大 `now`（初始 0）。

## 拒绝顺序与原子性

按以下顺序只报第一个错误：

1. `ErrInvalidArgs`：键为空串或超过 64 字节、`size∉[1,10⁶]`、`now∉[0,10⁹]`；
2. `ErrClockRollback`：`now` 小于已接受的最大 now；
3. `ErrNotFound`：`Get`/`Delete`/`GetMany` 的键不存在（GetMany 报第一个）。

构造参数越界返回 `ErrInvalidConfig`（要求 `0≤p,m,r≤10⁶`，`1≤A<B≤10⁶`，
`0≤Q≤10¹²`）。被拒绝的操作不改变对象、额度状态与最大 now。

所有方法以互斥锁串行化，可被并发调用，结果等价于某个串行顺序；相同操作序列
重放得到完全相同的费用明细。

## 示例（与规则一致）

`p0=10, p1=4, p2=1, A=30, B=90, m1=30, m2=90, r1=2, r2=5, Q=5`：

- `Put(k,10,0)` → 费用 0。
- `Get(k,40)`：Δ=40，存储费 `10×(10×30+4×10)=3400`；凉层停留 10，补费
  `(30−10)×4×10=800`；周期 1 与初始周期 0 不同，清零，`fg=min(10,5)=5`，
  检索费 `(10−5)×2=10`；之后 `la=40`。
- `Delete(k,200)`：Δ=160，存储费 `10×(10×30+4×60+1×70)=6100`；冷层停留 70，
  补费 `(90−70)×1×10=200`，合计 6300。
