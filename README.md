# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## mv2pl：多版本两阶段锁认证锁管理器

`mv2pl` 包实现了一个 MV2PL（多版本两阶段锁）认证锁管理器：读者只读已提交值，
写者先在事务本地缓冲上持 X 锁，提交时把 X 锁转换为与一切冲突的 C（认证）锁，
等持锁读者退出后才落盘。构造参数为键数 `K`（`1..64`，越界整体拒绝），键编号
`0..K-1`，每键已提交值初值为 0；`Begin()` 返回从 1 起递增的事务号。

### 相容矩阵（不同事务之间）

|       | S    | X    | C    |
|-------|------|------|------|
| **S** | 相容 | 相容 | 冲突 |
| **X** | 相容 | 冲突 | 冲突 |
| **C** | 冲突 | 冲突 | 冲突 |

同一事务持有的锁互不冲突。因此读者（S）与写者（X）可以共存于同一键：
读者读已提交值，写者改自己的缓冲；只有 X/X 与含 C 的组合会互斥。

### 普通申请与转换队列位置

- 普通申请（Read 的 S、Write 的 X）：当且仅当该键**等待队列为空**且与他事务
  已授予锁相容时立即授予，否则追加队尾，事务转等待态。持有 S 再写不算转换，
  按普通 X 申请处理。
- 提交转换（Commit 的 C）：按键升序逐键申请。与他事务已授予锁相容则**不看
  队列**立即授予并取代该键上的 X；否则插入该键队列中**最后一个转换请求之后、
  全部普通请求之前**，事务转提交中态。因此新读者无法越过排队的 C，认证不会
  被饿死；提交中途已拿到的 C 在等待期间继续持有。
- 事务的全部写键都拿到 C 后，各键已提交值置为缓冲值（提交事件按键升序携带
  写入集合），随后释放全部锁。

### 严格先进先出的级联处理

每次释放（提交、Abort、死锁中止）后维护待处理键集合，反复取**最小编号**的键，
从队首起逐个授予相容请求，遇第一个不相容的即停；授予造成的提交或释放把新键
并入集合。处理完毕后每个非空队列的队首必与某个他事务已授予锁冲突。

### 死锁判定

每次有请求入队（Commit 逐键入队则逐键判定）即对**当前全部队列条目**建边：
每个条目指向

1. 与其冲突的他事务**已授予锁**的持有者；
2. 排在它**前面的所有他事务条目**（队列前序边）。

若本次入队的请求者沿这些边可回到自己，则**请求者**被中止（移除其全部队列
条目、释放其全部锁、丢弃缓冲），调用返回 `Deadlock=true`；其余事务不受影响。
`Abort(t)` 做同样的清理但不做死锁判定。

### 拒绝语义

Read/Write/Commit/Abort 的拒绝原因按序只报第一个：事务号不存在
（`RejectNoSuchTxn`）→ 状态不符（`RejectBadState`；Read/Write/Commit 须活跃，
Abort 须活跃/等待/提交中）→ 键越界（`RejectBadKey`，仅 Read/Write）。被拒绝的
调用不改变任何状态；死锁中止与提交不属于拒绝。所有方法可并发调用，效果等价于
某个串行顺序；相同调用序列重放得到完全相同的结果与事件序列。

### 本地验证

```bash
# 场景测试 + 2000 组随机序列与朴素模拟逐步对照（日志打印每次调用的
# 输入、输出；不一致时打印分叉点与两侧结果作为判定依据）
go test ./mv2pl/
go test -v -run TestRandomAgainstNaive ./mv2pl/

# 竞态检测（含并发冒烟测试）
go test -race ./mv2pl/

# 不变式：随机序列每步调用后校验——同键已授予锁两两相容、转换请求排在
# 普通请求之前、非空队列队首必与某已授予锁冲突，并按提交事件顺序串行
# 重放校验每个读到的值。
```

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```
