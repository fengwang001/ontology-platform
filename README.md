# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 生成树协议（STP）网桥端口角色计算器

`stp` 包实现了一个简化的生成树协议计算器：保存各端口最近收到的配置消息，
并在任意查询时刻计算根桥与每个端口的角色（根端口 / 指定端口 / 阻塞端口）。

### 数据模型

- 网桥：正整数编号（越小越优），若干端口。
- 端口：正的、网桥上不重复的编号与正的路径开销；构造时即校验，否则拒绝构造。
- 配置消息为四元组 `(根桥编号, 到根开销, 发送桥编号, 发送端口编号)`，
  四项依次比较，数值小者更优。
- 每个端口只保存最近一条收到的消息及其到达时刻：新消息直接替换旧消息。
- 消息有效期为最大寿命 `A`；当 `now - 到达时刻 >= A` 时消息失效，不参与计算。

### 判定规则

1. **候选生成**：对每条未失效消息，本桥经该接收端口到根的开销为
   `消息.到根开销 + 接收端口.开销`，候选五元组为
   `(消息.根桥编号, 该开销, 发送桥编号, 发送端口编号, 本地端口编号)`。
2. **根桥与根端口**：只考虑候选中 `消息.根桥编号 < 本桥编号` 的项，
   按五元组字典序取最小者；其本地端口即**根端口**（转发），
   本桥根桥为该候选的根桥、到根开销为该候选开销。
   不存在这样的候选时，本桥**自认根桥**，到根开销为 0，且没有根端口。
   因此根桥永远没有根端口，每个非根桥恰有一个根端口。
3. **其余端口**：本桥在该端口通告
   `(根桥, 本桥到根开销, 本桥编号, 该端口编号)`：
   - 该端口无未失效消息，或通告向量**严格优于**（四项依次严格更小）
     端口保存的消息向量时，为**指定端口**（转发）；
   - 否则为**阻塞端口**。
4. 根桥的所有端口一律为指定端口。

### 操作与拒绝顺序

- `Receive(now, 本地端口, 消息)`：保存消息。按以下顺序只报第一个错误，
  被拒绝的操作不改变任何已保存消息：
  时钟回拨（`now` 早于此前任何已接受操作的时刻）→ 端口不存在 →
  消息中任一桥编号非正或开销为负 → 发送桥就是本桥 → 发送端口编号非正。
- `LinkDown(本地端口)`：清除该端口保存的消息；端口不存在则拒绝。
- `Roles(now)`：返回 `(根桥编号, 到根开销, 每个端口的角色)`。
- 收消息、断链、角色查询可并发调用：所有操作经同一把互斥锁串行化，
  任一时刻每个端口恰有一种角色、根端口至多一个；
  相同的带时间戳操作序列重放结果完全一致。

### 快速上手

```go
bridge, err := stp.NewBridge(
    5,                       // 网桥编号
    []int{1, 2},             // 端口编号（必须唯一且为正）
    []int{3, 7},             // 各端口路径开销（必须为正）
    10*time.Second,          // 最大寿命 A
)

// 端口 1 收到桥 2 转发的消息：根桥 1，对方到根开销 4。
err = bridge.Receive(now, 1, stp.ConfigMessage{RootID: 1, Cost: 4, SenderID: 2, SenderPort: 9})

rootID, costToRoot, roles := bridge.Roles(now)
// rootID=1, costToRoot=7（4 + 端口1开销 3），端口1=root，其余端口按规则判定

_ = bridge.LinkDown(1) // 断链：清除端口 1 保存的消息
```

### 本地验证

`stp` 包测试覆盖以下场景，并在日志中打印输入、输出与判定依据
（`go test -v` 可见）：

- 到根开销取消息开销加接收端口开销；
- 候选并列时依次取较小的发送桥编号、发送端口编号、本地端口编号；
- 指定端口要求通告向量严格优于端口消息（相等/更差均阻塞），
  无消息端口恒为指定端口；
- 根桥消息达到最大寿命失效后，网桥重新自认根桥且端口全部为指定端口；
- 三个网桥成环，收敛后根桥无根端口、每个非根桥恰有一个根端口、
  全环恰有一个阻塞端口；
- 拒绝顺序（时钟回拨、端口不存在、非法编号/负开销、发送桥为本桥等）、
  断链语义、并发竞态与相同序列重放的确定性。

```bash
# 带竞态检测运行全部 STP 用例并查看判定日志
go test -race -v ./stp

# 只跑三环收敛用例
go test -race -v -run TestThreeBridgeRing ./stp
```
