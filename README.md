# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

当前包提供整数列谓词等价类推导器，所有列均取 int64 值。

## API

使用 `NewEngine()` 创建并发安全的推导器：

- `Add(Cmp(column, op, value))`：录入 `=`、`!=`、`<`、`<=`、`>`、`>=` 比较。
- `Add(Eq(a, b))`：把两列合并到同一等价类。
- `Add(Ne(a, b))`：记录两个等价类必须取不同值。
- `Range(column)`：返回闭区间 `(lo, hi)`。
- `Pinned(column)`：返回 `(value, pinned)`。
- `Excluded(column)`：返回严格位于区间内部、升序排列的被排除值。
- `Same(a, b)`：返回两列是否属于同一等价类。
- `Implies(predicate)`：只接受 `Cmp` 与 `Eq`。

列名必须是非空字符串。列只在谓词被接受后登记，初始区间为 `[MinInt64, MaxInt64]`。

## 规整规则

每个等价类持有闭区间 `[lo,hi]` 与一组被排除值：

- `= c`：令 `lo=hi=c`，若 `c` 在当前区间外则矛盾。
- `< c`：令 `hi=min(hi,c-1)`；`c=MinInt64` 时 `c-1` 越界，直接矛盾。
- `<= c`：令 `hi=min(hi,c)`。
- `> c`：令 `lo=max(lo,c+1)`；`c=MaxInt64` 时 `c+1` 越界，直接矛盾。
- `>= c`：令 `lo=max(lo,c)`。
- `!= c`：当 `c` 位于当前区间内时加入被排除值集合。

每次变化后重复规整直到稳定：

- `lo` 被排除则 `lo++`；若 `lo=MaxInt64` 仍被排除则矛盾。
- `hi` 被排除则 `hi--`；若 `hi=MinInt64` 仍被排除则矛盾。
- 丢弃所有落在 `[lo,hi]` 外的被排除值。
- `lo>hi` 即矛盾。
- `lo==hi` 即等价类被钉死，唯一取值为 `lo`。

`Eq(a,b)` 合并两个等价类：区间取交、被排除值取并，然后执行上述规整。`Ne(a,b)` 在两端为同一等价类时矛盾；每次变化后会重新检查所有不同对。若两类都被钉死且同值则矛盾；若只有一类被钉死，则把该值加入另一类的排除集合并继续规整。这里不做多个不同对之间的鸽巢式不可满足推导。

## 矛盾与非法录入

`Add` 返回可区分的哨兵错误：

- `ErrInvalidPredicate`：列名为空、比较运算符非法；对 `Add` 而言谓词类型也必须合法。
- `ErrContradiction`：谓词通过合法性检查但与已有约束矛盾。
- 非法检查优先于矛盾检查。

所有录入先在深拷贝的候选状态中执行；只有完整成功后才原子提交。因此矛盾或非法录入不会改变区间、排除集合、不同对、等价类，也不会登记新列。

查询中的列未登记返回 `ErrColumnNotFound`。`Implies` 的错误顺序为：谓词非法（包括传入 `Ne`）优先，其次列未登记。

## Implies 条件

- `= c`：当前类被钉死且钉死值等于 `c`。
- `!= c`：`c<lo`、`c>hi` 或 `c` 在被排除值集合中。
- `< c`：`hi<c`。
- `<= c`：`hi<=c`。
- `> c`：`lo>c`。
- `>= c`：`lo>=c`。
- `Eq(a,b)`：两列同类，或两个等价类都被钉死且值相同。

## 并发性与可复现性

`Engine` 使用互斥保护，录入和查询可以并发调用，结果等价于某个合法的串行顺序。录入在候选状态上计算，成功后一次性发布，因此被拒绝的谓词不会产生部分副作用。

同一组全部可接受谓词无论以何种顺序录入，都会得到相同的区间、钉死值、排除值集合与等价类划分；相同录入序列重放会得到相同结果和错误。

## 本地验证

```bash
# 全量测试（-v 会打印关键输入、输出与判定依据）
go test -v ./...

# 竞态检测
go test -race ./...

# 2000 组随机录入序列与朴素逐步实现对拍，并在 [-9,9] 上暴力枚举
go test -v -run TestRandomNaiveDifferentialAndBruteForce ./...

# 静态检查与格式化
go vet ./...
gofmt -w .
```

随机对拍常量取 `[-3,3]`、最多 3 列；暴力枚举每列在 `[-9,9]` 内的取值，检查被拒绝的矛盾集合无整数解，并确认被钉死的等价类在所有枚举解中取同一值。
