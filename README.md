# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 多列有序索引（`index` 包）

`index` 包提供按列序字典序排列的多列有序索引，支持访问路径推导与快照扫描：
把各列条件推导成最少的键区间，只扫描区间内的条目，结果恒等于全表逐行过滤。

### 区间推导规则

- 索引按列序字典序排列，**空值排在每列最前**。
- 条件运算：等于（`Eq`）、属于集合（`In`）、小于（`Lt`）、小于等于（`Le`）、
  大于（`Gt`）、大于等于（`Ge`）、为空（`IsNull`）。
- 同列多条件取交集：`IS NULL` 与取交后只剩单点的条件视为等值；
  集合与范围取交后仍为集合（按范围过滤集合成员）。
- 首列无条件时，整个索引为一个区间，其余列条件全部残余过滤。
- 从首列起，连续的等值/集合列组成前缀组合（笛卡尔积，每组合一个区间）；
  遇到第一个范围列时把它并入区间边界后停止，其后各列只作残余过滤。
- 区间按索引序排列、互不重叠；矛盾条件得到空区间集合，考察零条。

### 空值处理

- 比较条件（含等于、集合、范围）对空值永不成立，只有 `IS NULL` 能匹配空值。
- 范围列并入区间时，若下界无界，则下界取 `(NULL)` 开区间，把空值排除在考察范围外。
- `IS NULL` 归约为空值单点等值，可参与前缀组合。

### 退化规则

前缀组合数超过上限 `L` 时，从使组合数首次超限的那一列起，该列及其后各列
改作残余过滤，区间只覆盖已确定的前缀。退化不影响结果正确性，只影响考察条目数。

### 整体验证

以下错误整体拒绝查询且原因可区分（`errors.Is`），被拒绝的查询不改变任何统计：

- `ErrUnknownColumn`：引用未知列
- `ErrTypeMismatch`：值类型与列类型不符（含把空值用作比较值）
- `ErrEmptySet`：空集合
- `ErrInvalidLimit`：组合数上限 `L` 不为正

### 并发与快照

扫描与插入、删除可并发调用。每次扫描看到其开始时的一致快照，
考察条目数恰等于该快照中落在推导区间内的条目数；结果按索引序输出；
同一快照与条件反复扫描结果完全相同。统计（`Stats`）只累计成功执行的扫描。

### 本地验证

```bash
# 全部单测（含 1000 组随机条件与全表过滤对拍，-v 可见输入/区间/输出/判定依据日志）
go test -v ./index/

# 竞态检测（覆盖扫描与插入、删除并发）
go test -race ./index/
```

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```
