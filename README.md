# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 地址租约服务器（`lease` 包）

`lease` 包从整数地址池闭区间 `[Lo, Hi]` 向客户端分配地址，参数为
租期 `L`、暂留时长 `H`、拒收隔离时长 `Q`。同一地址任一时刻至多
存在一份有效租约，且有效租约不与其他客户端的有效暂留并存。
所有操作显式携带时间戳、可并发调用，相同操作序列重放结果完全相同。

### 时间规则（均为左闭右开区间）

- 租约：`[确认时刻, 确认时刻+L)`，恰在终点失效；续租从续租时刻起算，
  不叠加剩余租期。
- 暂留：`[发现时刻, 发现时刻+H)`；已有有效暂留时再次发现沿用原暂留，
  不刷新起点。
- 隔离：`[拒收时刻, 拒收时刻+Q)`，由拒收触发。
- 地址空闲：无有效租约、无有效暂留、不在隔离期内。
- 租约终止时刻：过期取租约终点，释放取释放时刻，持有者拒收取拒收
  时刻，暂留者拒收不改变它。

### 发现（选址）优先次序

1. 客户端已有有效租约或暂留的地址（租约优先）；
2. 客户端最近一次持有过的地址且空闲；
3. 请求地址在池内且空闲；
4. 空闲地址中租约终止时刻最早者（从未有过租约者视为最早），
   并列取地址小者。

### 操作与拒绝顺序

- 发现：时钟回拨、客户端为空、请求地址不在池内、池已耗尽。
- 确认：时钟回拨、地址不在池内、地址被他人持有或暂留、
  该客户端无有效暂留或租约。成功后租约终点为现在加 `L` 并清除暂留。
- 释放：时钟回拨、地址不在池内、非持有者（仅限持有者）。
- 拒收：时钟回拨、地址不在池内、非持有者（含暂留者）。清除其租约
  或暂留并使地址进入隔离期。
- 被拒绝的操作不改变任何状态。

### 本地验证

```bash
# 运行租约服务器全部测试（日志打印每步输入、输出与判定依据）
go test -v ./lease/

# 带竞态检测
go test -race -v ./lease/

# 单个用例，例如续租不叠加剩余
go test -run TestRenewDoesNotStack -v ./lease/
```

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```
