# 链式 MAC 注记令牌

本包实现带前缀撤销、撤销记录到期回收与全局单调时钟的 macaroon 服务。

## 构造与令牌

`NewService(K, mac, Cm, Lc, Rm)` 的配置必须满足：

- `K`：非空根密钥字节串。
- `mac(key, data)`：可注入的确定性 MAC 函数，输出非空字节串。
- `Cm`：注记个数上限，范围 `1..32`。
- `Lc`：单条注记字节数上限，范围 `1..256`。
- `Rm`：逻辑有效撤销记录上限，范围 `1..1_000_000`。

令牌包含 `ID`（1..64 字节）、有序注记列表与非空 `Sig`。签名链固定为：

```text
s0 = mac(K, ID)
sj = mac(s(j-1), 第 j 条注记)
Sig = sn
```

因此追加注记的次序不可交换。`Attenuate` 是不读取服务撤销状态、也不验证旧令牌真伪的纯函数：复制旧令牌，在末尾追加注记并计算 `Sig = mac(旧 Sig, 注记)`。它先检查参数，再检查 `Cm`。

## 注记文法

- `exp:N`：`N` 为 `0..10^15` 的无前导零十进制数；当且仅当 `now < N` 满足。
- `ops:a,b,c`：一个或多个仅含小写字母、数字、连字符的非空项；请求 `Op` 命中其一即满足。
- `res:P`：`P` 以 `/` 开头；除 `/` 外不以 `/` 结尾且不包含 `//`。请求路径等于 `P` 或以 `P + "/"` 开头才满足，所以 `res:/a` 不满足 `/ab`；`res:/` 满足所有以 `/` 开头的路径。
- `amt:N`：`N` 为 `0..10^12` 的无前导零十进制数；当且仅当请求 `Amount <= N`。

前缀不属于上述四类是未知注记；前缀已知但值不合文法是畸形注记。`Mint` 只接受已知且合文法的注记；`Attenuate` 不检查文法，后续 `Verify` 会按真实签名继续检查注记。

## 校验与时钟

请求必须包含非空 `Op`、以 `/` 开头的 `Res` 和 `0..10^12` 的 `Amount`。所有带 `now` 的操作共享同一全局时钟；`now` 小于此前被接受操作见过的最大时刻是时钟回退。

`Verify` 的判定只返回第一处失败，次序为：

1. 参数非法。
2. 时钟回退。
3. 重算 `s0..sn`，与 `Sig` 不符则签名失败。
4. 按长度 `j=0..n` 查询 `(ID, j, sj)`，命中即已撤销，并报告最小 `j`。
5. 按序号 `1..n` 检查注记，第一条未知、畸形或不满足者即失败。

通过参数与时钟检查的 `Verify` 就会被接受并推进时钟、执行回收；之后即使签名失败也不撤销该状态推进。

## 前缀撤销与回收

`Revoke(token, k, now)` 撤销长度为 `k` 的前缀，范围为 `0..n`。判定次序为：参数非法（含 `k` 越界）、时钟回退、签名不符、撤销记录超限。

记录为 `(ID, k, sk)`。其保留期界 `b` 是该令牌前 `k` 条注记中、文法合法的 `exp:N` 的最小 `N`；没有合法 `exp` 时 `b` 为无穷。只有未知、畸形或非 `exp` 注记不影响该最小值。

- `b <= now`：记录不入表，只返回 `Expired: true`。
- 表中已有完全相同的 `(ID, k, sk)` 且仍有效：幂等成功。
- 同键但该层签名不同：不是同一记录。
- 新记录需要入表且当前有效记录数已等于 `Rm`：返回超限，不推进时钟、不回收。
- 其余情况入表。

每个被接受的 `Mint`、`Verify`、`Revoke` 都把时钟推进到 `now`，并弹出所有 `b <= now` 的有限记录。已到期但尚未物理弹出的记录在查询和计数时同样视同不存在，因此结果不依赖物理回收时机。

撤销长度为 `k` 的记录覆盖所有以该前缀为签名前缀的后代；不同签名链的兄弟令牌不受影响，长度为 `0` 的根撤销不影响未撤销祖先。

## 并发、指标与复现

服务内部使用互斥锁串行化状态操作，因此并发调用等价于某个合法串行顺序。确定性 `mac` 与固定随机种子测试保证相同操作序列产生相同令牌字节、判定结果、时钟、有效记录数与回收次序。

非导出计数器记录：

- MAC 调用次数：通过参数和时钟检查的 `Mint`、`Verify`、`Revoke` 恰为 `n+1`；`Attenuate` 恰为 1；参数非法或时钟回退为 0。
- 撤销表查询次数：签名相符的 `Verify` 最多查询 `n+1` 次，命中即停；签名不符为 0。
- 回收堆弹出次数：每次回收只沿最小堆顶弹出，不扫描表中其余记录。
