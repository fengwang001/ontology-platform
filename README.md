# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```

## 活期存款积数计息器（`interest` 包）

按日记录存取与年利率调整，在结息日按积数法累计利息并结转余数，
支持对已结息区间内某一天的存取做冲正并沿结息链逐区间重算。

### 积数公式与余数结转

- 年利率 `r` 以万分比整数记（如 365 表示 3.65%），按 360 天计，令 `D = 3600000`。
- 结息区间**左闭右开** `[prev, d)`：覆盖第 `prev` 天到第 `d−1` 天，
  结息日 `d` 当天不属于本次区间，当日的存取款与本次贷记的利息均自第 `d` 天起计入下次。
- 对覆盖区间内每一天累计 `日终余额 B_k × 当日年利率 r_k`，加上上次结息余数 `R` 得 `N`：
  - 利息 `i = ⌊N / D⌋`，新余数 `R = N mod D`（恒满足 `0 ≤ R < D`）；
  - 余额增加 `i`，`prev` 改为 `d`，并记录 `(区间起点, 结息日 d, i, 结息后的 R)`。

### 日终余额口径

第 `k` 天的日终余额 `B_k` = 该日及之前全部已接受存取与冲正的净额
+ 结息日不超过 `k` 的各次结息贷记利息之和。
第 `k` 天的年利率 `r_k` = 日期不超过 `k` 的最后一次 `SetRate` 的值（没有则为 0），
即 `SetRate` 当日起即用新利率；同日多次存取只按日终余额计一次。

### 冲正的重算链

`Correct(d, delta)`（`start ≤ d < prev`，`delta` 非零且 `|delta| ≤ 1e9`）令第 `d` 天起
每日日终余额增加 `delta`，随后对**结息日严格大于 `d`** 的结息记录按先后次序逐条重算：
每条记录取前一条记录重算后的余数（首条取其原有前一条记录的余数，没有则为 0）作为 `R`，
按改变后的 `B_k`（含前序记录重算后贷记的新利息）与不变的 `r_k` 重新累计 `N`，
得新利息 `i′` 与新余数 `R′` 并更新记录；后续记录因贷记利息与余数变化而继续重算。
重算与校验是一个原子步骤：若第 `d` 天到最大已接受操作日期 `m` 间任一日日终余额
小于 0（报"冲正后余额为负"）或大于 `1e11`（报"冲正后余额越限"），整个冲正不生效。
`Correct` 不改变 `m` 与 `prev`，不受时序倒退限制。

### 不变式

- 任意时刻 `0 ≤ R < D`；
- 已结息总额（各条记录当前的 `i` 之和）`× D + R` 恒等于全部已结息区间按当前 `B_k` 计得的积数之和；
- 余额恒等于 存入总额 − 取出总额 + 冲正总额 + 已贷记利息总额；
- 所有操作可并发调用（内部互斥串行化），相同操作序列重放得到完全相同的结果。
