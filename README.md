# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## heap：确定性堆回收模型

`heap` 包实现了一个支持软引用、弱引用、虚引用与终结化的堆回收模型。
所有操作可并发调用，结果等价于某个串行顺序；一次 `Collect` 是一个原子
步骤，观察者看不到只完成部分阶段的状态。

### 基本概念

- 构造参数：堆容量 `C`（1..10^12）、软引用单位 `U`（1..10^9）、每单位
  保留时长 `M`（0..10^9）。
- 普通对象与引用对象共用从 1 递增的编号序列；队列号从 1 独立递增。
- 已用量 = 全部未回收对象（含引用对象自身）的大小之和，永不超过 `C`。
- 时钟：`Collect`、`NewRef`、`Get` 携带 `now`；`now` 小于已被接受操作
  见过的最大 `now`（初 0）即按时钟回退拒绝。被拒绝的操作不改变任何
  状态（编号、队列号、时钟均不推进）。
- 拒绝原因按固定顺序只报第一个：参数非法 → 对象或队列不存在 →
  类别不符 → 时钟回退 → 堆已满（见 `heap.ErrInvalidParam` 等哨兵错误）。

### Collect 的六个阶段

同一阶段内多个引用对象按编号升序处理；"入队"指引用对象有队列时按处理
次序追加到该队列（无队列则只清除不入队）。

1. **强标记**：以根集合与终结队列中尚未终结的对象为起点，沿普通对象的
   字段传递标记。引用对象自身可被标记，但不沿其目标传递。记 `used0` 为
   此刻已标记对象的大小之和。
2. **软引用**：`free = C − used0` 在本阶段开始时一次算定，不随本阶段新
   标记重算。对每个在阶段 ① 结束时已被标记的软引用 `r`，若其目标非空
   且未标记：当 `now − r.timestamp ≤ ⌊free/U⌋ × M` 时保留（从目标起沿
   字段传递标记），否则清除目标并入队。`M = 0` 时仅当 `now` 等于时间戳
   才保留。`Get` 会刷新软引用时间戳，弱/虚引用不受影响。
3. **弱引用**：对每个此刻已被标记的弱引用，若目标非空且未标记，则清除
   目标并入队。弱引用先于终结阶段清除，因此即使目标随后被复活，弱引用
   仍保持已清除。
4. **终结**：一次性选定此刻"未被标记、可终结标志为真、且不在终结队列
   中"的全部普通对象（选定集合在此刻确定，不随后续标记变化），按编号
   升序追加到终结队列，并把它们连同字段可达的全部对象标记为存活
   （复活）。因此同一轮中一个可终结对象引用另一个可终结对象时，两者
   同轮入队。
5. **兜底**：对每个此刻已被标记的引用对象（任何种类，包括阶段 ④ 复活
   带回的引用对象），若目标非空且仍未标记，则清除目标并入队。
6. **清扫**：回收全部未标记对象，已用量相应减少。返回被回收对象编号
   升序列表、②③⑤ 各自清除的引用序列、④ 新选定的终结序列与回收后
   已用量。

### 终结化规则

- `Finalize(n)` 从终结队列 FIFO 取出至多 `n` 个对象，清除其"可终结"
  标志并返回编号；对象只进入终结队列一次。
- 终结队列中尚未执行终结的对象是强标记的起点（根），不会被回收。
- 复活对象的虚引用本轮不入队；待 `Finalize` 执行、对象再次被回收的
  下一轮，虚引用由阶段 ⑤ 清除并入队。

### 不变量

- 任意时刻已用量等于未回收对象大小之和且不超过 `C`；对象编号严格递增。
- `Collect` 返回后没有任何非空的引用目标指向已回收对象；队列严格 FIFO。
- 每次 `Collect` 中每个对象至多被标记一次（内部非导出计数器 `visits`
  等于最终存活对象数，测试逐次验证）。
- 相同操作序列重放得到完全相同的回收结果、入队次序与已用量。

### 本地验证

```bash
# 全部单测（规格示例、边界语义、拒绝顺序、状态不变性）
go test ./heap -v

# 2000 组随机堆与操作序列：真实实现双开（重放确定性）+ 朴素集合模拟
# 逐操作对照，日志打印输入、输出与判定依据
go test ./heap -run TestRandomDifferential -v

# 并发冒烟（需竞态检测）
go test -race ./heap -run TestConcurrentSmoke -v
```

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
```
