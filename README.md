# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 目录式缓存一致性协议模拟器（`directory` 包）

`directory/` 实现一个目录式（directory-based）缓存一致性协议模拟器：
`N` 个带容量 `C` 的私有缓存读写共享块，由目录逐块记录持有关系，
保证任一块至多一个缓存可写，且每次读都返回该块最近一次写入的值。
块号为非负整数，块初值 0；内存保存各块最近一次写回的值。

### 目录记录

- 缓存行状态仅两种：`Shared`（共享只读）、`Modified`（独占可写、相对内存为脏）。
- 目录对每块记录：持有者集合 `holders` 与修改者 `modifier`（无则为 -1）。
  - 共享行被淘汰时**不通知**目录，因此 `holders` 是实际持有者的超集，可残留已不持有者；发给残留成员的失效记为“空失效”。
  - 修改行淘汰必须通知目录，因此“修改者必在集合中、且集合仅含修改者”是严格不变量。
- 每次操作返回 `Result{Value, Hit, Invalidations, EmptyInvalidations, Writebacks}`。

### 读 `Read(c, b)`

1. 命中（本地持有）：返回本地值、无任何消息，刷新 LRU。
2. 缺失：若缓存已满先按 LRU 淘汰（见下）；随后查目录：
   - 有修改者 `o`：`o` 把脏值写回内存（+1 写回）并降为共享；`c` 以共享取得内存值；持有者集合变为 `{o, c}`。
   - 无修改者：`c` 直接以共享取得内存值，并加入持有者集合。

### 写 `Write(c, b, v)`

1. 修改命中：本地写入，无消息，刷新 LRU。
2. 否则（冷缺失或从共享行升级，升级不算命中）：必要时先淘汰；目录向集合中**除 `c` 外的每个成员**发一条失效，其中修改者先写回内存再失效（修改者排第一条）；`c` 自己不收失效；随后 `c` 以修改状态持有 `v`，集合变为仅 `{c}`。
   - 发给已静默淘汰者的失效计入 `EmptyInvalidations`。

### 淘汰规则（LRU，容量 C）

- 当且仅当 `c` 不持有 `b` 且已有 `C` 行时，无论读写先淘汰最近最少使用的行：
  - 修改行：写回内存（+1 写回）并从目录持有者集合移除、清除修改者；
  - 共享行：静默淘汰，不通知目录（这是空失效的来源）。
- 读命中与写命中都会把该行刷新为最近使用；升级写（缺失）也刷新该行顺序。

### 参数校验（按顺序只报第一个）

1. 创建时 `N <= 0`；2. 创建时 `C <= 0`；3. 操作时缓存编号越界；4. 块号为负。
被拒绝的操作不改变任何缓存、目录、内存与 LRU 顺序。

### 并发语义

`Read`/`Write` 可被多协程并发调用；模拟器用单一互斥量把每次操作整体串行化，
因此目录对同一块的处理必然与某个全局先后顺序等价（线性一致、无死锁、结果确定）。
不变量：任一块至多一个修改行；有修改行时没有共享行；无修改行时内存值等于最近写入值；
每个缓存行数不超过 `C`；相同操作序列重放结果完全相同。

### 本地验证

```bash
# 全量测试（含竞态检测与逐条输入/输出/判定日志）
go test -race -v ./directory/

# 全工程测试、静态检查、格式检查
go test -race ./...
go vet ./...
gofmt -l .
```

测试覆盖：修改者被读降级写回、升级写不给自己发失效、静默淘汰引发空失效、
淘汰修改行写回、命中刷新 LRU、参数拒绝无副作用、
200 个随机种子 × 300 步与独立单一内存参照模型对拍（并校验读值=最近写入值）、
相同序列重放确定性、8×200 并发操作的竞态与不变量检查。

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```
