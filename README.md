# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 定额月供贷款引擎

根包提供线程安全的贷款还款计划引擎，所有操作均通过互斥锁串行化，因此并发调用的结果等价于某种合法串行顺序。

- `New(P, r, A)`：创建本金 `P`、初始月利率 `r`、月供 `A` 的贷款。金额单位为分；利率单位为百万分之一，即 `r / 1_000_000`。
- `Pay()`：执行下一期，返回期序号、还款额、利息、本金和还款后余额。
- `Prepay(x)`：两期之间提前还本 `x`，月供不变，只缩短期限，并返回提前还款额、违约金和余额。
- `SetRate(r2, k0)`：登记从绝对期序号 `k0` 起生效的新月利率；同一 `k0` 再次登记会覆盖旧值。
- `Holiday(c)`：登记接下来 `c` 期为只还息宽限期。
- `Remaining()`：不改变状态，模拟当前状态到结清所需期数；已结清返回 `0`。

### 计息、末期与宽限期

下一期序号为 `n = k + 1`。利率取变更表中满足 `k0 <= n` 的最大 `k0` 对应利率；不存在时使用初始利率。

每期利息按整数分计算并四舍五入、恰半入：

```text
i_n = floor((bal × r_n + 500000) / 1000000)
```

普通期先判断 `bal + i_n <= A`。满足时该期为末期，只还 `bal + i_n`，余额变为 `0`；否则还款 `A`，本金为 `A - i_n`。因此 `bal + i_n == A` 算末期，比 `A` 大 `1` 不是末期。

宽限期只还利息，不还本金，余额不变，并且不判断末期、不要求 `A > i_n`。宽限期仍按绝对期序号占用期数，利率变更也仍按绝对期序号生效。

### 登记校验与期限上限

`New`、`SetRate`、`Holiday` 在提交前会复制当前候选状态，并从当前状态逐期模拟未来至多 `601` 期：

- 任一非宽限、非末期期出现 `A <= i_n`，返回不可摊还。
- 第 `601` 期才结清，或模拟满 `601` 期仍未结清，返回期限超限。
- 必须在第 `600` 期或之前结清，登记才会生效。

校验只在候选快照上执行；被拒绝的操作不会修改余额、已还期数、利率变更表或剩余宽限期数。

### 提前还款与违约金

`Prepay(x)` 只能在两期之间调用，要求 `1 <= x <= 10^12`，且满足以下之一：

- `x >= A`；
- `x == bal`，即一次性结清，即使金额小于月供也允许。

违约金按操作发生时已还期数 `k` 分档，并对分向下取整：

- `k < 12`：`floor(x × 300 / 10000)`，即 `3%`。
- `12 <= k < 36`：`floor(x × 100 / 10000)`，即 `1%`。
- `k >= 36`：`0`。

### 错误顺序

各操作只返回第一个命中的错误：

- `New`：参数非法、不可摊还、期限超限。
- `Prepay`：参数非法、已结清、超额、低于最小额。
- `SetRate`：参数非法、已结清、生效期已过、不可摊还、期限超限。
- `Holiday`：参数非法、已结清、已有宽限、不可摊还、期限超限。
- `Pay`：已结清。

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 贷款引擎：示例和边界测试
go test -v

# 贷款引擎：2000 组随机操作序列与朴素模拟器对照；失败时日志含输入、输出和判定依据
go test -run TestRandomOperationSequences -v

# 竞态检测
go test -race ./...

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

gofmt -l .
