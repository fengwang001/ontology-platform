# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 逐仓保证金与强平引擎（`margin` 包）

`margin/engine.go` 实现并发安全的逐仓合约保证金与强平引擎，管理单向持仓，
在标记价格推进时按固定顺序原子地判定并执行强平：保险基金先吸收亏空，
不足部分按盈利率排序自动减仓（ADL）对手方，仍不足记入坏账。

构造参数均为万分比整数：初始保证金率 `I`、维持保证金率 `Mm`、强平费率 `F`，
要求 `1 ≤ Mm < I ≤ 10000` 且 `0 ≤ F ≤ 10000`。

### 权益与维持要求

- 持仓量 `q` 带符号（多正空负），成本 `C = Σ 带符号数量 × 成交价`。
- 标记价格 `P` 下权益：`E = M + q×P − C`。
- 维持要求（向上取整）：`R = ceil(|q|×P×Mm / 10000)`，恰等不强平，仅 `E < R` 入选。
- 开仓初始要求：`M ≥ ceil(|C|×I / 10000)`（以累加后的当前 `C` 计算，恰等通过）。

### Mark 的三个原子步骤

1. **定 Λ**：按 Mark 开始时的快照逐户计算 `E`、`R`，强平集合 `Λ` 一次定出，
   此后不再改变；减仓不会让本次候选再入选强平。
2. **逐户执行**：按账户编号字节序升序，`Z` 与对手方状态逐步演化：
   - `E ≥ 0`：罚金 `f = min(E, floor(|q|×P×F / 10000))`（罚金向下取整），
     `M = E − f`，`Z += f`，无亏空。
   - `E < 0`：`M = 0`、`f = 0`，亏空 `d = −E`，先由保险基金吸收
     `u = min(Z, d)`（此刻 `Z` 已含前面账户的罚金、不含后面账户）；
     余额 `s = d − u > 0` 触发 ADL。
3. **返回清单**：按执行次序返回每项 `(账户, E, f, u, 减仓明细, 记入B金额)`，
   并记录本次标记价格。三步在同一把互斥锁内完成，观察者看不到中间状态。

### 自动减仓（ADL）规则

- 候选：当前有仓位、方向与被强平账户相反、不属于 `Λ`、且浮盈
  `pnl = q×P − C > 0`（恰为 0 不入选）的账户。
- 排序：按盈利率 `pnl/|C|` 从大到小；以整数交叉相乘比较
  `pnl_i×|C_j|` 与 `pnl_j×|C_i|`（乘积可达 `10^24`，实现用 `math/big`），
  相等时账户编号字节序小者在前。
- 取走：`take = min(s 剩余, 候选当前 pnl)`，令候选 `C += take`
  （其权益恰好减少 `take`，`M`、`q` 不变；`take ≤ pnl` 保证 `C` 不翻号），
  依次直到 `s` 为 0 或候选用尽；排序依据的 `pnl` 取排序当时的 `C`，
  即前一个亏空账户改写过的 `C` 对后一个亏空账户生效。候选用尽的剩余记入 `B`。

### 平仓与其他操作

- `Close(a, p)` 全部平仓：`E = M + q×p − C`，`M = max(E,0)`；`E<0` 的亏空
  由 `Z` 吸收 `min(Z,d)` 后余额记 `B`，不触发 ADL、不收平仓费，随后 `q=C=0`。
- `Withdraw` 仅无仓位时可取；`Open` 不收费、不检查强平；被拒绝的操作
  （参数非法 / 账户不存在 / 持仓冲突或无仓位 / 资金不足）不改任何状态。

### 守恒式（任何时刻成立）

- `Z = Σ 已扣罚金 − Σ Z 吸收额`，且 `Z ≥ 0`。
- `Σ 全部亏空（含 Close 产生）= Σ Z 吸收额 + Σ ADL 取走额 + B`。
- 所有账户 `M ≥ 0`；被强平账户随即 `q = C = 0`；相同操作序列重放结果完全一致。

### 本地验证

```bash
# 全部测试（确定性用例 + 2000 组随机朴素模拟对照 + 并发串行化）
go test ./margin/ -v

# 竞态检测
go test -race ./...

# 随机对照日志（输入操作、接受/拒绝原因、Mark 清单与判定依据）
go test ./margin/ -run TestRandomAgainstNaive -v -count=1

# 代码检查
gofmt -l .
go vet ./...
```

随机对照测试中的朴素模拟器（`margin/naive_test.go`）与引擎实现完全独立，
按题面规则用大整数做交叉比较，逐步复算每一步的账户、`Z`、`B` 与强平清单，
并在每条序列上校验上述守恒式。

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```
