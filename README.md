# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 数据批次质量门禁（`gate` 包）

对乱序到达的数据批次按规则与历史基线裁决**放行 / 告警放行 / 阻断**。
批次包含正整数序号 `seq`、行数 `rows` 与空值行数 `nullRows`。

### 裁决规则

按规则次序评估，结论中按本次序列出**全部未满足**的规则：

1. **规则一（阻断）**：`rows < MinRows`（行数低于下限）。
2. **规则二（阻断）**：`nullRows / rows` 严格大于上限 `MaxNullRate`；
   使用交叉相乘 `nullRows * Den > Num * rows` 比较（`math/big` 防溢出），
   **恰等边界不算**；`rows == 0` 时不评估本规则。
3. **规则三（告警）**：存在基线时，`rows` 低于基线中位数的 `lo%` 或高于 `hi%`；
   恰等边界不算（严格小于 / 严格大于）。

任一阻断规则未满足即**阻断并入隔离区**；否则**放行**，仅规则三未满足时附带告警。
规则三即使在批次已被阻断时也照常评估并列入结论。

### 基线取法

- 候选：**序号严格小于本批次**且已放行的批次（含告警放行与人工放行），
  按序号位置而非到达次序选取；已裁决批次不会因之后到达的较小序号批次而重算。
- 取其中序号最大的至多 `K` 个，行数升序后取下标 `(c-1)/2` 的值
  （`c` 为实际个数，整除）：奇数个取中位数，偶数个取**下中位数**。
- 没有候选批次时不评估规则三。

### 隔离区语义

- **重投 `Resubmit`**：同序号、新的行数与空值数，按该序号位置重新裁决与计数；
  基线仍按序号小于它的已放行批次计算。
- **人工放行 `ManuallyRelease`**：进入基线。
- **丢弃 `Discard`**：此后该序号拒绝一切后续操作。

### 暂停语义

- 连续阻断数按**裁决顺序**累计，重投裁决同样计入；任何放行（含告警放行）清零。
- 人工放行与丢弃**既不计入也不清零**。
- 连续阻断达到 `M` 时通道暂停：暂停期间提交与重投**一律拒绝且不裁决、不落状态**；
  人工放行与丢弃不受影响。`Resume()` 恢复通道并清零计数。

### 拒绝原因（整体拒绝、状态不变，可区分）

| 哨兵错误 | 含义 |
| --- | --- |
| `ErrPaused` | 通道已暂停（提交/重投的最先校验项） |
| `ErrInvalidBatch` | 序号非正、行数为负、空值数为负或大于行数 |
| `ErrSeqExists` | 提交时序号已存在 |
| `ErrSeqNotFound` | 重投/放行/丢弃时序号不存在 |
| `ErrAlreadyRel` | 序号已放行（含人工放行），不在隔离区 |
| `ErrAlreadyDisc` | 序号已丢弃 |
| `ErrNotQuarantin` | 序号存在但不在隔离区 |

校验次序：提交为 暂停 → 非法 → 序号已存在；重投/放行/丢弃为
暂停（仅重投）→ 非法（仅重投）→ 不存在 → 已放行/已丢弃/不在隔离区。

### 并发与日志

所有方法以单一互斥锁保护，可并发调用且效果等价于某个串行顺序；
连续阻断计数无丢失更新。每次操作通过标准 `log` 打印输入、输出与判定依据
（命中的规则、阻断计数、暂停状态、拒绝原因），可用 `SetLogger` 重定向或关闭。

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out

# 仅验证质量门禁（竞态检测 + 覆盖率）
go test -race -v ./gate/
go test -cover ./gate/
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```
