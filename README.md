# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```

## LET 端到端时延分析器（`let` 包）

`let` 包实现周期任务链在逻辑执行时间（LET）语义下的端到端时延分析。

### 模型

- 任务：编号（非空、不超过 32 字节）、周期 `T`（1..1000）、相位 `φ`
  （`0 ≤ φ < T`）、写延迟 `w`（`1 ≤ w ≤ T`）。最多 16 个任务。
  第 `j` 个作业（`j` 自 0 起）在 `r = φ + j·T` 释放并读取输入，在
  `r + w` 写出输出。`w = T` 即标准 LET 语义；较小的 `w` 相当于固定
  响应时间的隐式通信。
- 同刻可见：在时刻 `u` 写出的值，对释放时刻 `r ≥ u` 的读取可见；
  同一时刻 `r = u` 也可读到，差 1 个时间单位则不可见。
- 链：2 到 6 个互不相同的任务 `τ1 → … → τn`，`τ1` 读取外部采样。
  记 `Φ` 为链上最大相位，`H` 为链上周期的最小公倍数。

### 反应时间（Reaction）

对整数 `x`：`τ1` 取释放时刻不小于 `x` 的第一个作业（释放恰好在 `x`
上算本次采样），得 `r1`，`t1 = r1 + w1`；对 `k ≥ 2`，`τk` 取释放时刻
不小于 `t_{k−1}` 的第一个作业，`t_k = r_k + w_k`。
`Reaction(x) = t_n − x`。

`Reaction(x)` 关于 `x` 以 `H` 为周期（全体释放/写出事件随 `x` 平移
`H`），因此 `MaxReaction`/`MinReaction` 只需取 `x` 遍历
`[Φ, Φ+H)` 内的整数；区间左端点从 `Φ` 起是因为更小的 `x` 与某个
`x' ∈ [Φ, Φ+H)` 同余（模 `H`）。

### 数据年龄（Age）

对整数 `x`：取 `τn` 满足 `r + w ≤ x` 的最后一个作业，再对
`k = n−1 … 1` 取 `τk` 满足 `r + w ≤`（`τ_{k+1}` 所取作业的 `r`）的
最后一个作业，得 `τ1` 的 `r1`，`Age(x) = x − r1`。

`Age(x)` 同样以 `H` 为周期。`MaxAge` 取 `x` 遍历 `[W, W+H)`，
其中 `W = Φ + 2·ΣT`：该下界保证沿链回溯时每一级都能找到真实存在
的作业（远离时间原点，不受“还没有任何写出”的边界影响）。在该模型
下恒有 `MaxAge = MaxReaction`（测试中对每条随机链校验该等式）。

### Tune

`Tune(链)` 只允许调整 `τ2 … τn` 的相位（`τ1` 固定），枚举所有相位
组合，取 `MaxReaction` 最小者；并列时取相位向量 `(φ2, …, φn)` 字典
序最小者。仅当最优值严格小于当前 `MaxReaction` 时才提交，否则任务
相位不变，返回的“调整后”值等于调整前。`Tune` 不改变写延迟与链的
组成；提交后与逐个 `SetPhase` 到同一组相位完全等价。

### 拒绝原因

按以下顺序只报告第一个适用的原因，被拒绝的操作不改变任何状态：

1. `ErrInvalidArgument`：参数非法（编号为空或越界数值、链长不在
   2..6、链名为空）；
2. `ErrNotFound`：任务或链不存在；
3. `ErrDuplicate`：编号重复、链内任务重复或链名重复；
4. `ErrCapacity`：容量已满（任务超过 16 个）；
5. `ErrTooLarge`：规模过大（`H > 5000`；`Tune` 另要求 `τ2…τn` 的
   周期之积不超过 1000）；
6. `ErrInUse`：`RemoveTask` 时任务仍在某条链中；
7. `ErrShared`：`Tune` 时链上任一任务同时出现在另一条链中。

### 并发与可复现性

所有方法与查询可并发调用（内部读写锁），结果等价于某个串行顺序。
`Analyze` 只取决于当前参数，与调用次序无关；相同操作序列重放得到
完全相同的结果。

### 本地验证

```bash
# 单元测试 + 2000 组随机链与朴素模拟对拍（-v 打印每组输入/输出/判定依据）
go test ./let/ -v

# 竞态检测
go test -race ./let/
```

对拍的朴素模拟（`let/sim_test.go`）独立实现：展开若干超周期的全部
作业，按时间顺序传播采样标记（每个作业读取前驱在自身释放时刻之前
或同一时刻写出的最新值），再对区间内每个 `x` 分别求 Reaction 与
Age，与闭式分析逐一比对。
