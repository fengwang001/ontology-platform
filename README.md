# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## layout 包：缩进敏感语言的布局层状态机

`layout` 包逐物理行接收源码（`Feed`，行不含换行符、至多 10^4 字节），
按缩进栈、括号与续行、冒号块期望生成 `INDENT`、`DEDENT`、`NEWLINE`
与 `ENDMARKER` 布局事件；`Close()` 表示输入结束。构造参数为缩进深度
上限 `Dm`（1..100，不含栈底）与括号深度上限 `Bm`（1..200）。所有方法
可并发调用，结果等价于某个串行顺序；相同行序列重放得到完全相同的
事件、错误与状态。

### 缩进栈与制表符一致性

- 缩进栈每项含列宽 `c`、备用列宽 `a` 与该层最近被接受逻辑行起点的
  首词 `h`，初为 `[(0,0,"")]`；栈对 `c` 与 `a` 都严格递增。
- 列宽计算：空格使 `c`、`a` 各加一；制表符使 `c` 增至下一个 8 的倍数
  （已在 8 的倍数处则再进一档）、`a` 加一。
- 与栈顶比较：`c` 相等为同级（`a` 必须相等）；`c` 更大为缩进（`a`
  必须更大）；`c` 更小则在副本上弹栈至栈顶 `c` 不大于当前 `c`，弹出
  `k` 项且栈顶 `c` 必须等于当前 `c`、`a` 必须相等，为缩减 `k` 级。
  违反 `a` 的约束为"制表符不一致"，弹栈后 `c` 不等为"非法缩减"。
- 被接受后：缩进压栈并产生 `INDENT`，缩减产生 `k` 个 `DEDENT`（均
  先于该行的 `NEWLINE`），随后把生效后栈顶项的 `h` 置为本行首词。

### 括号与续行

- 行内扫描只识别字符串（`'`/`"`，反斜杠跳过其后一字节，不支持跨行
  字符串）、注释（引号外 `#` 到行尾）与括号（`()[]{}` 压栈/匹配弹出，
  深度超 `Bm` 为"括号过深"，栈空或不匹配为"括号错误"）。
- 括号栈非空或上一被接受行以续行标记（行内引号与注释之外的最后
  一字节是反斜杠）结束时，本行是延续行：不做缩进判定，只做行内
  扫描。扫描结束时括号栈为空且不以续行标记结束，则逻辑行完成并
  产生 `NEWLINE`。

### 冒号块期望

- 逻辑行完成时，若本逻辑行最后有效字符（引号与注释之外的非空白
  字节；闭合引号算、字符串内部与续行标记不算）是冒号，则置冒号块
  期望；期望为真时下一逻辑行必须缩进（否则"缺少缩进"），为假时
  不得缩进（否则"意外缩进"）。空白行与纯注释行不清除期望。

### 悬垂分支

- 首词（去掉前导空白后首个 `[A-Za-z0-9_]` 最长连续串，整串比较）
  为分支关键字时，要求关系生效后栈顶项的 `h` 属于允许集合：
  `elif` ← `{if, elif}`；`else` ← `{if, elif, for, while, except}`；
  `except` ← `{try, except}`；`finally` ← `{try, except, else}`。
  不满足为"悬垂分支"；`elsewhere`、`else_` 等不算 `else`。

### 拒绝次序

- `Feed` 按"已关闭、行过长、缩进类（制表符不一致/非法缩减 →
  缺少缩进/意外缩进 → 缩进过深 → 悬垂分支，仅新逻辑行起点）、
  词法（字符串错误/括号错误/括号过深，按行内从左到右第一个）"
  的次序只报第一个；被拒绝的行视为从未发生，不改变任何状态。
- `Close` 依次拒绝：已关闭、输入未完成（括号未闭或续行待续）、
  缺少缩进块（冒号块期望为真）；否则弹出缩进栈除栈底外每项一个
  `DEDENT` 再产生 `ENDMARKER`。

### 本地验证

```bash
# 全部测试（含 2000 组随机行序列与朴素模拟的差分对照，
# 朴素模拟每次 Feed 都从当前逻辑行第一个物理行起整体重扫）
go test ./layout/

# 查看随机对照日志（输入、输出与判定依据）
go test ./layout/ -run TestRandomDifferential -v

# 更换随机种子复验
LAYOUT_SEED=42 go test ./layout/ -run TestRandomDifferential -count=1

# 竞态检测
go test -race ./layout/
```

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```
