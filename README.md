# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## resolver 包：允许重叠实例的类型类实例解析器

`resolver` 包实现带上下文的类型类实例登记、约束求解（推导树）与带增量失效的解析缓存。

### 类型与约束

- 类型是构造子应用 `Con(名字, 参数列表)`（名字为 1 到 32 字节的非空串，参数至多 4 个）或变量 `Var(i)`（`i` 为 0 到 7，只出现在实例中）。
- 基础类型不含变量，深度（零参数构造子为 1，否则为 1 加参数最大深度）不超过 16。
- 规范文本：零参数构造子写名字，否则名字后接尖括号、参数以逗号分隔，如 `Pair<Int,List<Char>>`。
- 约束为（特征名, 类型）；特征名为 1 到 32 字节的非空串。
- `AddInstance(特征名, 头类型, 上下文)` 登记实例：编号从 1 递增、至多 200 个；上下文至多 4 个约束，且其中出现的变量必须都出现在头类型里。同特征的两个实例，若头类型在变量按先序首次出现次序重新编号后逐位相同，后者为重复实例并被拒绝。

### 匹配与更特化

- 头类型 `H` **匹配**基础类型 `T`：存在把 `H` 的各变量代换为基础类型的代换使 `H` 与 `T` 逐位相同；同一变量的各处必须代换为同一个类型（非线性头如 `Pair<a,a>` 只匹配两个参数相同的类型）。
- 实例 `A` **更特化于**实例 `B`（同特征）：把 `A` 的头类型里的变量当作互不相同的不可代换常量后，`B` 的头类型能匹配它。该关系一般不对称：`List<Char>` 更特化于 `List<a>`，反之不成立；`Pair<Int,a>` 与 `Pair<a,Int>` 互不更特化。

### 求解规则

- `Resolve(特征名, 基础类型)` 的候选是同特征且头类型匹配该类型的实例。无候选为**无实例**；有候选时必须存在一个比其余每个候选都更特化的实例（**唯一最特化**），否则为**歧义**。
- 选定实例后**不再考虑其他实例，也不看上下文，即使上下文失败也不回退**。
- 选定实例在匹配所得代换下，把上下文各约束按声明次序依次递归解析为子树；第一个失败即整体失败，携带失败所在的（特征，规范类型文本）与类别（深度优先、上下文声明次序下最先出现者）。
- 推导树高度：无上下文的实例为 1，否则为 1 加子树最大高度。
- 目标所在层数 `ℓ` 从顶层的 1 起；解析一个目标时**先判循环**（同一（特征，类型）已在当前递归路径的祖先目标中出现），**再判** `ℓ > D` 为**深度超限**，再选实例。

### 缓存与增量失效

- 成功解析的目标（含各级子目标）进入缓存，键为（特征，基础类型），条目记录所选实例、树高度与直接子目标的键；失败不缓存，但失败前已成功的子目标照常入缓存。
- `Resolve` 遇到缓存条目且 `ℓ + 树高度 - 1 ≤ D` 时直接使用，不再检查任何实例；不满足该条件时不算命中，按正常过程解析。
- `AddInstance` 成功后精确失效：记新实例为 `N`，对缓存中每个目标 `g`，若 `N` 与 `g` 同特征且 `N` 的头类型匹配 `g` 的类型，设 `g` 所选实例为 `S`，则**当且仅当 `S` 不更特化于 `N` 时 `g` 失效**；失效再沿被依赖方向传递（任何树内含失效目标的条目也失效），其余条目全部保留。因此保留的条目重新解析结果与缓存完全相同。
- 所有操作与查询可并发调用，结果等价于某个串行顺序；`Resolve` 的结果只取决于当前实例集与 `D`，不取决于缓存内容与调用历史。

### 本地验证

```bash
# 全量测试（含 2000 组随机登记/解析序列与朴素模拟的差分对照）
go test ./resolver/

# 查看差分测试日志（输入、输出与判定依据）
go test ./resolver/ -run TestRandomDifferential -v

# 竞态检测
go test ./resolver/ -race

# 静态检查
go vet ./resolver/
gofmt -l resolver/
```

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```
