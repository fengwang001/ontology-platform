# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## aria：Aria 式确定性批处理事务执行器

`aria` 包实现确定性批处理事务执行：一批事务先在批起点快照上并行试执行，
再用按键的最小事务号预留表判定可提交者，其余按事务号顺序回退串行重执行，
使每个事务的阶段、读到的值与最终状态可精确复现。

### 事务与执行语义

- 构造参数：键数 `K`（1..64，编号 0..K-1，初值均为 0）与批容量 `Bsz`（1..16），越界整体拒绝。
- `Submit(ops)` 登记事务并返回从 1 起递增的事务号；`ops` 为 1..8 条 `R(k)` / `W(k,d)`，
  `d ∈ [−10^6, 10^6]`。拒绝原因按顺序只报第一个：操作条数、键越界、d 越界；
  被拒调用不改状态、不消耗事务号。
- 执行语义：累加器 `acc` 初值 0；`R(k)` 把 k 的当前值（本事务已缓冲写过则取缓冲值，
  否则取执行所用状态中的值）累加进 `acc`；`W(k,d)` 把 `acc+d` 记入缓冲。
  读集 RS 为取自状态而非缓冲的键，写集 WS 为缓冲的键。
  任一步 `acc` 或缓冲值溢出 int64，该事务以溢出失败（不是拒绝：占用批容量、消耗事务号）。

### 批执行三步（RunBatch）

取最早的至多 `Bsz` 个待处理事务：

1. **并行阶段**：每个事务都在批起点快照上试执行；溢出失败者就此失败，
   不参与预留，也不回退。
2. **预留表与判定**：对未失败者按事务号升序建表——
   - `wres[k]` = WS 含 k 的最小事务号；`rres[k]` = RS 含 k 的最小事务号（中止者也计入）。
   - 三类依赖（对事务 t）：
     - **WAW**：WS(t) 中有键 k 使 `wres[k] < t`（有更早事务写同一键）；
     - **RAW**：RS(t) 中有键 k 使 `wres[k] < t`（读到了更早事务要写的键，读到的是旧值）；
     - **WAR**：WS(t) 中有键 k 使 `rres[k] < t`（有更早事务读 t 要写的键）。
   - **提交条件**：`无 WAW 且 非(RAW 且 WAR)`。
     推导：WAW 直接违反写次序（两事务写同键，快照上无法定序），必须中止其一；
     仅 RAW 时，t 读的是旧值——只要把被读的写者排在 t 之前即可串行化；
     仅 WAR 时，把读者排在 t 之前即可串行化；但 RAW 与 WAR 同时出现时，
     t 既在某写者之后又在某读者之前，而成环的依赖无法排成串行次序，故中止。
     这也是本规则与"有 RAW 即中止"的普通规则的差异：仅含 RAW 的事务仍可提交。
   - 推论：批内事务号最小且未失败者三类依赖都不可能成立，必在并行阶段提交；
     提交者的写集两两不交（否则较小者会让较大者产生 WAW）。
3. **写回与回退**：提交者的缓冲按事务号升序写入状态；其余事务按事务号升序
   在当前状态上串行重新执行并立即写入（因此回退者能看到并行阶段提交者与
   更早回退者的写入），重执行溢出则失败。

每个事务恰好落入 并行 / 回退 / 失败 三种结局之一；无待处理事务时返回空且不改状态。
预留表建立与判定触及的表项数不超过批内操作总数的两倍。

### 并发与确定性

`Submit` 与 `RunBatch` 可并发调用：事务号按进入 `Submit` 的串行顺序分配，
内部互斥串行化保证结果等价于某个串行顺序；相同的提交序列与批边界得到
完全相同的阶段、acc 与终态。

### 本地验证

```bash
# 规则用例 + 与朴素模拟对照 2000 组随机批次（日志含输入、输出与判定依据）
```

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```
