# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```

## 流式旋转门压缩（`swingdoor` 包）

`swingdoor` 包逐点接收时序采样，只保留必要的存档点，使任一被丢弃点
到其前后相邻存档点连线的纵向偏差都不超过容差 `E`，存档点序列可逐点复现。

### 算法（斜率上下界）

- 容差 `E` 为非负整数，最大 `4e9`；时间戳与数值均为 `int64`，绝对值不超过 `1e9`。
- 第一个采样立即存档，成为当前起点 `(t0,v0)`，待定点集合为空，
  此时 `lo = -∞`、`hi = +∞`。
- 此后每来一个采样 `(t,v)`，计算相对起点的斜率
  `s = (v-v0)/(t-t0)`（时间戳严格递增，分母恒正）：
  - 若待定点为空，或 `lo <= s <= hi`（恰等于 `lo`/`hi` 仍算可继续），
    该采样成为待定点，并更新
    `lo = max(lo, (v-E-v0)/(t-t0))`、
    `hi = min(hi, (v+E-v0)/(t-t0))`；
  - 否则「上一个」采样（最近一个待定点）成为存档点并成为新起点，
    此前的待定点全部丢弃；触发超界的新采样相对新起点重新计算，
    成为新起点之后的第一个待定点，其 `lo`/`hi` 只由它自己决定。
- 关闭时，若最后一个采样尚非存档点则追加为存档点。

重启规则的关键：超界时存档的是**上一个待定点**，不是触发超界的新采样。
例如 `E=1` 依次输入 `(0,0),(1,0),(2,3),(3,0)`：`(2,3)` 的斜率 `3/2`
超出 `hi=1`，于是 `(1,0)` 成为存档点——而不是把 `(2,3)` 存档后让
首段连线出现 `1.5 > E` 的偏差。

分数比较一律使用整数交叉相乘（`n1*d2 ? n2*d1`），实现上采用
`math/big.Int`，因此交叉乘积超过 `int64` 范围时依然精确，全程无浮点。

### 拒绝原因与检查顺序

每次 `Write`/`Close` 按以下顺序检查，命中即返回可区分的哨兵错误，
被拒绝的操作不改变存档点、待定点与上下界：

1. 压缩器已关闭 → `ErrClosed`（关闭后再写入也是此原因）；
2. 数值绝对值超过 `1e9` → `ErrValueOutOfRange`；
3. 时间戳绝对值超过 `1e9` → `ErrTimeOutOfRange`；
4. 时间戳等于上一采样 → `ErrDuplicateTime`；
5. 时间戳小于上一采样 → `ErrTimeBeforePrev`（与上一条是两种不同原因）；
6. 空流关闭 → `ErrEmptyClose`（该拒绝不置关闭位，之后仍可正常写入）。

`New(E)` 在 `E < 0` 或 `E > 4e9` 时返回 `ErrInvalidTolerance`。

### 并发与确定性

- 写入、关闭、查询（`Archives`/`Closed`）由同一把读写锁保护，
  结果等价于某个串行顺序（可线性化）。
- 存档点时间戳严格递增，首尾采样必在存档点中。
- 相同输入序列重放得到逐位相同的存档点序列（纯函数式状态演进）。

### 判定日志

`NewWithLogger(E, w)` 会把输入、输出与每一步判定依据写入 `w`，
包括当前斜率、收紧后的 `[lo, hi]`、超界重启时存档的是哪个待定点。

### 本地验证

```bash
# 全部用例（含 -race 并发检测与逐点朴素对照校验）
go test -race -v ./swingdoor

# 仅竞态/覆盖率
go test -race -cover ./swingdoor
```

测试覆盖：斜率恰等于 `lo`/`hi` 时继续、`E=0` 共线点丢弃而折点保留、
重启起点是上一待定点、上述规定反例、单采样、两采样、
关闭时末点已是存档点、各类拒绝原因与顺序、确定性重放、
大坐标（交叉乘积超过 `int64`）以及 300 组随机序列。
每组序列都会与用有理数（`big.Int`）逐点验证「每个被丢弃点相对
相邻存档点连线的偏差不超过 `E`」的朴素校验器对照。
