# ontology-platform

本体服务平台（对标 Palantir Foundry Ontology）。

## 逐仓保证金与强平引擎（`margin` 包）

引擎管理账户保证金 `M`、带符号持仓量 `q`（多正空负）与带符号成本
`C`（各笔带符号数量×成交价之和），并维护全局保险基金 `Z`（恒不为负）
与坏账累计 `B`。构造参数为万分比整数：初始保证金率 `I`、维持保证金率
`Mm`、强平费率 `F`，要求 `1 <= Mm < I <= 10000` 且 `0 <= F <= 10000`。

### 权益与维持要求

- 权益：`E = M + q×P − C`（`P` 为标记价格）。
- 维持要求：`R = ceil(|q|×P×Mm/10000)`（向上取整）。
- 开仓要求：`M >= ceil(|C|×I/10000)`，恰等通过；开仓不收费、不检查强平。

### 强平（`Mark(P)`，三步为一个原子步骤）

1. 按 Mark 开始时的状态一次性定出强平集合 `Λ`：有仓位且 `E` 严格小于
   `R`（恰等不强平），此后不再改变——即使减仓把某候选的权益压到 `R`
   之下，本次也不会补入。
2. 按账户编号字节序升序逐个执行 `Λ` 中的账户，以 `P` 全部平仓：
   - `E >= 0`：罚金 `f = min(E, floor(|q|×P×F/10000))`（向下取整，罚金
     超过 `E` 时只扣 `E`），`M = E − f`，`Z += f`，不产生亏空。
   - `E < 0`：`M = 0`、`f = 0`，亏空 `d = −E` 先由 `Z` 吸收
     `u = min(Z, d)`（`Z` 此刻只含排在前面账户的罚金）；余额 `s = d − u`
     触发自动减仓。
3. 返回按执行次序的清单：账户、`E`、`f`、`u`、减仓明细与记入 `B` 的金额。

### 自动减仓（ADL）

- 候选：当前有仓位、方向与被强平账户相反、不属于 `Λ` 且浮盈
  `pnl = q×P − C` 严格大于 0 的账户。
- 排序：按盈利率 `pnl/|C|` 从大到小，用 128 位/大整数交叉相乘比较
  （`pnl_i×|C_j|` 对 `pnl_j×|C_i|`，乘积可达 10^24），相等时按账户编号
  字节序小者在前；每个亏空账户触发时都按当时的 `C` 重新排序。
- 取走：依次取 `take = min(s 剩余, 该候选当前 pnl)`，方式是令候选的
  `C` 增加 `take`（权益恰好减少 `take`，`M` 与 `q` 不变，`C` 的符号
  不翻转）；候选用尽后的剩余记入 `B`。

### 守恒式（任意时刻成立）

- `Z == 全部已扣罚金之和 − 全部 Z 吸收额之和`，且 `Z >= 0`、所有 `M >= 0`。
- `全部亏空之和（含 Close 产生的）== 全部 Z 吸收额 + 全部减仓取走额 + B`。

### 其他操作

- `Deposit(a, x)`：账户不存在先创建；存入后 `M <= 10^15`。
- `Close(a, p)`：全部平仓，`M = max(E, 0)`；`E < 0` 时亏空先由 `Z` 吸收、
  其余记入 `B`；不触发减仓、不收平仓费。
- `Withdraw(a, x)`：仅无仓位时可用，`x <= M`。
- 错误按 参数非法 → 账户不存在 → 持仓冲突或无仓位 → 资金不足 的顺序
  只报第一个；被拒绝的操作不改变任何状态。所有方法可并发调用，`Mark`
  的三步对外表现为一个原子步骤。

## 环境要求

- Go 1.26+（`go version` 确认）

## 运行

```bash
# 拉取依赖
go mod tidy

# 直接运行
go run ./cmd/server

# 编译后运行
go build -o bin/server ./cmd/server
./bin/server
```

## 测试

```bash
# 全量测试
go test ./...

# 强平引擎（含 2000 组随机序列与朴素模拟的差分对照，
# 日志打印每组输入、输出与判定依据）
go test -v ./margin

# 带竞态检测与详细输出
go test -race -v ./...

# 单个包 / 单个用例
go test ./ontology
go test -run TestObjectType ./ontology

# 覆盖率
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 代码检查

```bash
gofmt -l .
go vet ./...
```
