# 包版本依赖求解器

这是一个 Go 实现的内存包仓库与语义版本依赖求解器，支持发布、撤回、确定性回溯求解、循环依赖和并发调用。

## 使用方式

```go
repo := resolver.NewRepository()
err := repo.Publish("app", "1.2.0", map[string]string{
    "lib": "^1.0.0",
})
err = repo.Yank("app", "1.2.0")

solution, err := repo.Solve(
    map[string]string{"app": ">=1.0.0 <2.0.0"},
    resolver.WithLogger(os.Stdout),
)
```

`Solve` 返回包名到具体版本的映射；`WithLogger` 可打印输入、候选、拒绝原因、回溯和最终输出。

## 版本与排序

版本格式为 `X.Y.Z` 或 `X.Y.Z-pre`：

- `X`、`Y`、`Z` 都是 `0..9999` 的非负整数，且不允许前导零。
- `pre` 是点分标识符列表，不能为空段。
- 数字标识符只含数字且不允许前导零；非数字标识符只含 ASCII 字母、数字和连字符。
- 排序先比较 `X`、`Y`、`Z`。
- 核心三元组相同时，不带预发布字段的版本大于带预发布字段的版本。
- 两个预发布字段逐标识符比较：数字按数值，数字标识符小于非数字标识符，非数字按字节序；前面的标识符全相同时，标识符更少者更小。

例如：`1.0.0-alpha.1 < 1.0.0-alpha.beta < 1.0.0`。

## 范围语义

范围由一个或多个以空白分隔的比较子组成，比较子之间取交集。空范围、不含比较子、比较子与版本之间有空白、缺少版本均为非法范围。

比较子支持：

- `=X.Y.Z`：等于。
- `>X.Y.Z`、`>=X.Y.Z`、`<X.Y.Z`、`<=X.Y.Z`：普通比较。
- `~X.Y.Z`：`>=X.Y.Z` 且 `<X.(Y+1).0`。
- `^X.Y.Z`：从指定版本开始，但不跨越当前允许升级的最左非零段：
  - `X > 0`：`>=X.Y.Z` 且 `<(X+1).0.0`。
  - `X = 0, Y > 0`：`>=0.Y.Z` 且 `<0.(Y+1).0`。
  - `X = 0, Y = 0`：`>=0.0.Z` 且 `<0.0.(Z+1)`。

因此，`^0.0.3` 上界是 `0.0.4`，`^0.2.1` 上界是 `0.3.0`，`^1.2.3` 上界是 `2.0.0`。

## 预发布规则

不带预发布字段的候选只按比较子交集判定。

带预发布字段的候选必须满足两个条件：

- 范围中至少有一个比较子自身带预发布字段，并且它的 `X.Y.Z` 与候选版本相同。
- 该候选仍须满足范围中的全部比较子。

例如，`>=1.0.0-alpha.1 <1.0.0` 可以放行 `1.0.0-alpha.beta`，但 `>=0.9.0 <1.0.0` 不能放行 `1.0.0-alpha.1`，因为后一个范围没有 `1.0.0` 三元组上的预发布比较子。

## 撤回与搜索次序

撤回只把版本标记为不可选；版本仍然存在于仓库中，因此重复版本检测等仓库状态不受影响。被撤回版本不进入候选列表。

求解采用固定的深度优先回溯：

- 始终选择“已受约束但尚未选定”的包中包名字节序最小者。
- 该包的候选版本从高到低尝试。
- 选定版本后加入它的全部依赖约束；已选包若不再满足新增约束则回滚。
- 允许包之间形成循环依赖；每个包最终至多选择一个版本。
- 第一个能扩展为完整解的候选被采用，其余候选不会继续尝试。

结果只取决于某一时刻的完整仓库快照和根依赖，不取决于历史发布顺序。仓库内容与根依赖相同时，重复求解得到完全相同的结果。

## 错误原因

以下错误互不相同，可通过 `errors.Is` 判断：

- `ErrInvalidVersion`：发布版本格式非法。
- `ErrDuplicateVersion`：同名同版本重复发布。
- `ErrInvalidRange`：发布依赖或根依赖的范围语法非法。
- `ErrVersionNotFound`：撤回的包版本不存在。
- `ErrPackageNotFound`：根依赖或某个可行选择所需依赖包不在仓库。
- `ErrNoSolution`：仓库中的版本组合无法同时满足全部约束。
- `ErrInvalidPackageName`：包名为空。

发布和撤回事先完成必要解析，并在锁内进行状态检查；被拒绝的操作不会部分修改仓库。

## 并发与快照

仓库内部使用读写锁保护可变状态。`Solve` 在开始时复制一份不可变快照，随后全部候选枚举、约束传播和回溯都在该快照上完成；因此一次求解不会看到发布或撤回执行到一半的中间状态。发布、撤回和求解可以并发调用。

## 测试覆盖

测试包含：

- `^0.0.3`、`^0.2.1`、`^1.2.3` 上界。
- 预发布候选被同三元组带预发布比较子放行、被其它范围拒绝。
- `1.0.0-alpha.1 < 1.0.0-alpha.beta < 1.0.0`。
- 需要回溯才成功的依赖组合。
- 撤回最高版本后选择次高版本。
- 循环依赖。
- 字节序最小待决包优先，与另一种包决策次序得到不同解。
- 独立朴素实现枚举全部可行版本组合，并按同一版本优先级选出首个解与生产求解器对照。
- 发布顺序无关、重复求解一致、竞态检测。
- 输入、输出、候选拒绝原因和回溯日志。

## 本地验证

```bash
go test ./...
go test -race -v ./...
go vet ./...
gofmt -l .
```

如果系统 `PATH` 中没有 Go，可使用本机安装路径并指定可写构建缓存：

```bash
PATH=/usr/local/go/bin:$PATH GOCACHE=/tmp/go-cache-ontology go test -race -v ./...
```
