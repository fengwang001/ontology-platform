# 现金存款结构化拆分检测设计

## 模块划分

- `Config`、错误、报告和领域类型定义在 `aml/types.go`。
- 对外状态机位于 `aml/system.go`，负责参数校验、错误优先级、时钟、账户、交易号和读写锁。
- 客户组合并、窗口集合、覆盖标记与报告生成位于 `aml/group.go`。
- 无状态辅助函数位于 `aml/helpers.go`。
- 独立朴素模型和随机对照测试位于 `aml/*_test.go`。

## 数据模型

每个账户创建时成为独立客户组，账户对象记录当前所属组。组内保存：

- 当前成员账户集合；
- 按存款日期分桶的小额存款集合；
- 最近一次影响该组的接受时刻，用于在不扫描全部历史的情况下丢弃已知失效窗口。

每笔存款由唯一交易号全局索引，并记录金额、日期、冲正状态和覆盖状态。大额存款及金额小于 `L` 的存款可冲正，但不会进入任何结构化集合。

## 判定规则

在一次被接受的存款或关联后，系统对触发账户所在组评估一次。触发时刻为 `now`，窗口日期为：

```text
now-D+1 <= 存款日期 <= now
```

只有未冲正、金额满足 `L <= amount < H` 的存款属于集合。集合笔数至少为 `K` 且金额合计至少为 `H` 时，结构化条件成立。条件成立后仍须检查集合中是否存在未被任何已发出结构化报告覆盖的存款：

- 存在未覆盖存款：发出一份报告，记录集合中的全部交易号及合计，并把集合中全部存款标记为已覆盖；
- 全部已覆盖：不发报告，也不改变报告编号。

冲正不触发评估，也不恢复覆盖标记。已发出报告保持不变。

## 确定性与并发

所有修改操作在同一个互斥锁内原子执行，因此并发执行等价于某个合法的线性化串行顺序。全局报告切片只在锁内追加，报告按接受操作的实际串行次序编号。

关联操作 ID 按两个账户 ID 排序后生成，存款报告以交易号为触发 ID；交易号列表按日期、交易号排序，账户列表按账户 ID 排序。因此相同输入序列重放得到完全相同的报告序列。

查询使用读锁，不修改状态。查询返回的账户、交易号和报告均为深拷贝，调用方无法污染系统内部状态。

## 错误优先级

实现严格按以下顺序短路：

1. 参数非法；
2. 时钟回退；
3. 账户不存在；
4. 存款交易号重复；冲正交易号不存在或已冲正；
5. 关联双方已经在同一组。

任一步返回错误前都不写入账户、交易、时钟、覆盖标记或报告。

## 复杂度

设：

- `A_s` 为关联时较小组的账户数；
- `S_s` 为较小组当前窗口内的小额存款数；
- `S` 为合并后或当前组当前窗口内的小额存款数；
- `R` 为已发报告数。

操作复杂度：

- 开户：`O(1)`；
- 存款、冲正：`O(D+S log S)`，排序只用于确定性输出报告中的交易号；冲正的删除是常数次哈希查找；
- 关联：`O(D+A_s+S_m log S_m)`；只访问两组窗口内的 `D` 个日期桶并重建当前窗口，不访问窗口外历史，其中 `S_m` 是合并后当前窗口集合大小；
- 当前组账户查询：`O(A log A)`，用于稳定排序输出；
- 窗口摘要：`O(D+S log S)`，排序用于稳定枚举；
- 全部报告查询：`O(R)`。

复杂度结论可直接从代码验证：`mergeGroupsLocked` 中循环上界是配置常量 `D`，只读取双方的 `dst.buckets[date]` 与 `src.buckets[date]`；没有遍历全部账户、全部交易、任意一方的完整 `buckets` 映射，也不会读取较大组窗口外历史。`windowDepositsLocked` 同样只枚举 `D` 个日期，再遍历这些日期内仍属于当前窗口的存款。

## 关键取舍

- 选择全局互斥锁而非每组建锁：报告必须全局有序，单锁使线性化和编号最直接，避免多锁合并死锁。
- 选择小并大：关联时把较小组成员和窗口内桶并入较大组，保证同一账户的组成员关系只会迁移对数次。
- 选择按天桶：日期是整数且窗口按天计算，查询只需访问 `D` 个键；比为每组维护滑动队列更能自然处理多组独立时间和关联。
- 覆盖标记保存在存款对象上：冲正后仍保留，已覆盖集合不会因冲正而重新可报。
- 大额报告与结构化判定完全独立：大额存款不进入按天桶，不能因自身改变结构化集合。

## 被放弃的方案

- 每次评估扫描全部交易：实现简单但复杂度随全部历史增长，不满足要求。
- 为每组维护全局有序树或 Treap：能支持范围查询，但需要随机结构或复杂平衡逻辑，也增加合并、冲正和确定性验证成本。
- 仅维护滚动金额计数器：无法在报告中确定性枚举集合内交易号，也难以正确处理覆盖、冲正和多组关联。
- 关联后复制较大组：会把合并成本放大到较小组和较大组总和，无法证明不随较大历史增长。
