# 多成员镜像块卷：成员故障、世代仲裁与部分重同步

## 模块划分

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 错误分类 | `mirror/errors.go` | 六类可区分错误，声明顺序即上报优先级 |
| 有序块集合 | `mirror/treap.go` | 确定性树堆，插入/删除/弹最小元 O(log d) |
| 脏区记录 | `mirror/dirtylog.go` | 每非在线成员一份；超限丢弃并永久标记全量 |
| 成员 | `mirror/member.go` | 状态机（在线/故障/重同步中）、故障世代、盘面数据 |
| 卷服务 | `mirror/volume.go` | 写、读、报告故障、重新加入、重同步推进、快照、工作量统计 |
| 朴素模型 | `naive/naive.go` | 独立编写的逐块参照实现，用于随机对照 |

## 关键取舍

- **单一互斥锁实现可线性化**：所有操作持同一把锁，并发调用天然等价于
  某个串行顺序。成员数最多 4、写路径只触及成员数级别的数据，锁竞争
  不是瓶颈，换来的是正确性论证的最小化。
- **脏区记录与重同步游标合一**：非在线成员各持有一份 `dirtyLog`。对故障
  成员它是缺失块登记簿（受上限约束）；成员转入重同步中后，同一份记录
  直接充当待同步块游标——写入直落该成员时清除对应块标记，推进时按块号
  升序弹出。因此"重同步中再次故障脏区保留"无需任何额外拷贝。
- **确定性树堆**：块号集合用树堆存储，优先级由块号经 splitmix64 确定性
  导出，与插入顺序无关，保证任意时刻状态可精确复现；弹最小元天然给出
  升序推进序列。
- **写拒绝是事务性的**：全部在线成员写失败时，在变更任何状态之前整体
  拒绝（预检失败集合是否覆盖全部在线成员），不留任何状态、世代、脏区
  痕迹。注入失败只来自调用方，预检与"先执行再回滚"语义等价。
- **世代只在新故障时推进**：一次写入/一次报告故障内无论多少成员新故障，
  世代只加一；故障世代一律取转换前的卷世代。最后一个在线成员被报告
  故障时，重同步中成员以同一故障世代一并故障。
- **权威选取落在重新加入路径上**：全部成员故障时，只有故障世代最大
  （并列取编号最小）者能首个重新加入并立即在线；其余成员的脏区记录
  当场被丢弃并标记全量，此后重新加入一律全量重同步。
- **可验证的复杂度**：`Volume` 内嵌计数器统计块级读写次数与脏区元素
  访问次数（`Stats()`/`ResetStats()`）。测试用相同操作序列分别作用于
  256/128 块与 2^18 块的卷，断言两次计数完全一致，直接证明写开销只随
  成员数增长、部分重同步选块开销只随脏区块数增长。
- **重同步期间无陈旧读**：读只由在线成员服务（编号最小者），重同步中
  成员永不服务读；写入同时落到在线与重同步中成员，因此任何成员未
  同步完成的陈旧值都不会被读到。

## 被放弃的方案

- **位图脏区记录**：每成员一个 `numBlocks` 位图。内存与"统计不同块数"
  的开销都随总块数线性增长，无法满足"选块开销只随脏区块数增长"的
  约束，放弃。
- **有序切片脏区记录**：插入 O(d)、弹最小元 O(1)，复杂度上也满足约束，
  但插入需搬移元素，且与树堆相比没有常数之外的收益；树堆的确定性
  结构还额外提供了可复现性，故选树堆。
- **每成员读写锁 / 无锁状态机**：读多写少场景理论吞吐更高，但"全部
  在线成员写失败则整体拒绝""最后一个在线成员故障级联"等跨成员
  不变量需要多步原子判断，细粒度锁会把正确性论证复杂化到得不偿失，
  放弃。
- **重同步游标与脏区记录分离**：两份结构需要在故障、重加入、写落盘
  三条路径上保持同步，不变量翻倍；合一后"重同步中再故障脏区保留"
  是自然结果，放弃分离方案。
- **写失败回滚而非预检**：先执行再发现全部在线失败再回滚，需要为
  世代、脏区、成员状态设计撤销日志；预检在语义等价的前提下零成本，
  放弃回滚方案。

## 本地验证方法

```bash
# 全部场景单测 + 随机对照 + 并发冒烟
go test ./...

# 竞态检测
go test -race ./...

# 查看随机对照的逐条日志（输入、输出、判定依据）
go test ./mirror -run TestDifferentialRandom -v

# 复杂度证明用例
go test ./mirror -run 'Cost' -v

# 代码检查
gofmt -l .
go vet ./...
```

覆盖点：脏区恰等于上限与多一、同时多成员故障世代只增一、重同步中
再次故障后重新加入、标签小于/等于/大于故障世代、全量标记完成后清除、
全部故障后权威选取与并列、全部在线写失败拒绝不留痕、重同步期间读写、
错误类别与优先级、写与部分重同步的块数无关性、30 种子 × 300 步随机
对照（六种错误类别与成功路径均被覆盖）、8 协程并发冒烟（`-race`）。
