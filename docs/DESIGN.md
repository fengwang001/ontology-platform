# 协同表格按用户选择性撤销/重做服务 — 设计说明

## 模块划分

`sheet` 包按职责拆分为五个内聚模块：

| 文件 | 职责 |
| --- | --- |
| `sheet/types.go` | 对外契约：`Edit`/`Result`/`CellInfo`/`HistoryInfo`、结果码 `Code`、取值与时间常量 |
| `sheet/record.go` | 历史记录 `txnRecord` 与记录栈 `recordStack`（压入、弹出、按深度丢弃最旧） |
| `sheet/validate.go` | 参数校验与时钟校验（纯函数，无副作用） |
| `sheet/service.go` | 服务状态与并发边界：互斥锁、单元格表、保护表、用户表、全局修订号、时钟 |
| `sheet/ops.go` | 五个操作的内部实现（调用方已持锁），每个操作只触及所涉事务的单元格 |

测试侧另有两个独立模块：`sheet/naive_test.go`（朴素参考模型）与
`sheet/random_test.go`（随机对照驱动），见"本地验证方法"。

## 关键取舍

- **单互斥锁串行化**。所有操作在入口加同一把 `sync.Mutex`，天然满足
  "并发调用结果等价于某个串行顺序"，且串行位置上的版本与保护检查
  就是实际生效的检查。放弃细粒度锁（每单元格/每用户锁）：Undo/Redo
  的"版本检查 → 保护检查 → 整体提交"必须原子完成，全局修订号本身
  就是全局序列化点，细粒度锁只增加复杂度与出错面，没有吞吐收益。
- **每单元格版本号作为覆盖判据**。Undo/Redo 不要求"当前值等于某个值"，
  只要求每个单元格的当前版本恰等于记录版本。这样"当前值恰好与原值
  相同但版本不同"自然落入被覆盖分支，无需特判。从未写入的单元格版本
  为 0，用 map 缺省表示。
- **一条事务记录只存一个期望版本**。同一事务内所有单元格共享同一个新
  修订号，因此记录不必逐单元格存版本，期望版本检查是 O(事务大小) 的
  整数比较。记录内单元格按键升序存放，"按键排序的第一个不符单元格"
  是顺序扫描的第一个失配，无需临时排序。
- **被覆盖即丢弃，且只弹一条**。版本检查失败时弹出栈顶记录、不进入
  重做栈、表格与两栈其余部分不变，返回 `Popped=true` 标明这一例外；
  不级联检查下一条（规范要求逐次报告，重放才能精确复现）。
- **时钟只在被接受的操作上推进**。所有拒绝（含被覆盖弹出）都不改变
  `lastNow`；被覆盖弹出是唯一允许改变状态的拒绝，并在结果中标明。
- **保护状态与历史完全解耦**。Protect/Unprotect 不改修订号、版本与
  历史；Apply 的保护检查覆盖全部编辑（含将被判无效的编辑），Undo/
  Redo 的保护检查在版本检查之后，符合规定的拒绝次序。
- **深度限制的不变量**。Apply 后撤销栈裁剪到 D 并清空自己的重做栈；
  Undo 在撤销栈与重做栈之间移动记录，二者总数不超过 D，因此重做栈
  无需裁剪；Redo 把记录放回撤销栈顶后同样按 D 裁剪（防御性，实际
  不变量保证不会超出）。

## 被放弃的方案

- **OT/CRDT 式并发变换**：适用于实时共编辑的字符级合并，但本需求是
  "按用户选择性撤销"，语义由版本精确匹配定义，变换反而引入不确定性。
- **全局命令历史 + 反向补偿**：撤销时扫描全局历史寻找交叉编辑，开销
  随全体历史增长，违反性能约束；且"被覆盖丢弃"的语义难以精确复现。
- **整表快照（copy-on-write）**：每次事务复制表格，内存与时间都随表格
  总规模增长，同样违反性能约束。
- **每单元格独立撤销链**：无法表达"一个事务整体生效/整体恢复"，
  也无法在事务级给出第一个不符单元格。

## 复杂度论证

Apply/Undo/Redo 只访问：事务内的单元格（map 均摊 O(1)）、记录内
单元格的保护表项（O(1)）、操作用户的两个栈（切片尾部 O(1)，裁剪为
O(D)，D ≤ 100 为常数上界）。排序只发生在事务内（≤ 50 个键）。因此
单操作开销为 O(事务大小)，与表格单元格总数、全体历史事务总数、用户
总数均无关。`TestPerfScaleInvariance` 与两组基准（10^4 与 10^6 单元格）
给出可执行对照。

## 本地验证方法

```bash
export PATH=$PATH:/usr/local/go/bin   # 如 go 不在 PATH
export GOCACHE=/tmp/gocache GOPATH=/tmp/gopath

go test ./sheet/                 # 全部单元测试 + 1500 组随机对照
go test -race ./sheet/           # 竞态检测（并发串行化冒烟）
go test -v -run TestRandomDifferential ./sheet/   # 打印每步输入/输出/判定依据
go test -v -run TestPerfScaleInvariance ./sheet/  # 两档规模耗时对照
go test -bench=. -benchtime=200x ./sheet/         # Apply/Undo/Redo 两档基准
gofmt -l . && go vet ./...       # 格式与静态检查
```

随机对照使用固定基准种子（`baseSeed = 20261007`，逐序列递增），失败时
日志会给出序列号与种子，可确定性地复现同一输入序列。
