# 住院病区感染病例接触者追踪与隔离期判定系统 — 设计说明

## 1. 模块划分

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 错误模型 | `errors.go` | 五类可区分错误及其优先级 |
| 公共类型 | `types.go` | 时间常量、状态/等级枚举、查询结果、开销统计 |
| 住宿存储 | `stays.go` | 住宿记录的按患者/按病房双索引、重叠判定；只增不删 |
| 病例存储 | `cases.go` | 病例登记数据与推导缓存；按 ID/按患者索引 |
| 推导器 | `derive.go` | 单病例密接/次密接的纯函数推导与缓存维护 |
| 失效传播 | `invalidate.go` | 住宿/病例变更后精确标记受影响病例 |
| 操作 | `ops.go` | 全部变更操作：校验（含错误优先级）、状态变更、时钟推进 |
| 查询 | `query.go` | 状态查询（两跳候选收集 + 多病例叠加）与清单查询 |
| 引擎 | `engine.go` | 并发入口（单互斥锁）、时钟、统计 |
| 朴素模型 | `naive/` | 独立参考实现：无索引无缓存，查询时全量暴力重算 |
| 演示 | `cmd/demo/` | 端到端示例场景，打印每步输入/输出/判定依据 |

## 2. 核心语义的决定（对规格未尽之处的解释）

- **查询也是操作**：状态/清单查询携带 `now`，参与时钟单调性校验，
  被接受后同样推进时钟。被拒绝的操作（含查询）不改变任何状态与时钟。
- **时钟只在接受时推进**：先完成全部校验，通过后才推进时钟，
  因此被拒绝的操作不会污染时钟（有专门测试 `TestRejectedOpKeepsClockAndState`）。
- **依赖对象状态的参数检查**：如“隔离时刻不早于传染期起点”“出住晚于入住”，
  只有在对象存在时才能求值。此类违规仍报**参数非法**，且在对象存在且同时
  存在状态型错误时优先于状态不符（符合优先级：参数非法 > 状态不符）。
- **次密接经多个密接达标**：只要存在某一个密接，与其在其暴露期内的累计
  重叠 >=120 分钟即认定为次密接（不跨密接累加）；最后接触时刻取所有使其
  达标的密接中重叠段的最晚结束时刻；`Minutes`/`Via` 记录累计最大的达标
  路径（并列取字典序较小者），保证结果与遍历顺序无关。
- **多病例叠加的解除时刻**：取**全部来源**中最晚的解除时刻。存在仍在期内
  的来源时，它必然晚于 now 因而也晚于一切已过期来源，两种读法等价；
  全部过期时为已解除，解除时刻即最晚来源的解除时刻。
- **撤销**：撤销的病例不再产生任何接触者，其清单查询返回空（不报错）；
  曾有的接触者状态回到无关（除非另有来源），因为结果只由当前登记决定。
- **未知患者的状态查询**返回“无关”，不视为错误。
- **同一患者可拥有多个病例**（病例 ID 唯一即可）。
- **发病改正不受既有隔离时刻约束**：若改正后传染期起点晚于隔离时刻，
  传染期为空，该病例不再产生接触者。

## 3. 可复现性的根基：推导是纯函数

`derive(case, now)` 只读取：当前全部住宿登记、该病例的登记数据与 `now`。
它不读取任何历史推导结果。缓存（`caseRec.valid` 等）只是该纯函数的记忆化：

- 任何住宿/病例变更都通过失效传播把受影响病例的缓存标记为无效；
- 未隔离且推导读到开区间住宿记录的病例标记为 `nowSensitive`，
  `now` 变化时缓存自动失效（开区间端点随 now 生长，重叠累计可能变化）；
- 已隔离病例的传染期固定、暴露期以确诊登记时刻为界，结果与 now 无关，
  缓存长期有效。

因此查询结果与“把全部登记按任意顺序一次性给出”完全一致，
不依赖追补/改正/撤销的先后。差分测试中的**规范重建**步骤
（`buildCanonical`）对每个随机序列验证这一点。

## 4. 失效传播的精确性

病例 C 的推导只读取三类记录：

1. 病例患者 P 的住宿，及与 P 同病房有重叠的其他患者住宿（密接）；
2. 各密接 Q 的住宿，及与 Q 同病房有重叠的其他患者住宿（次密接）；
3. 病例自身登记数据。

因此患者 A 在病房 W 的区间 [lo,hi) 发生变化时，受影响病例恰好为：

- A 自己的病例；
- 在 W 内与 [lo,hi) 有重叠的每个患者 Q 所拥有的病例（密接边可能变化）；
- 上述 Q 当前作为密接的病例（由 `closeOf` 提示索引给出，次密接边可能变化）。

`closeOf` 对所有缓存有效的病例是精确的；对已经失效的病例其提示可能过时，
但过时只会令失效集合保守放大，不会遗漏——因为任何会改变 C 的推导的变更
发生的那一刻，C 就会被上述规则标记失效。病例级操作（登记隔离/改正/撤销）
只影响该病例本身。失效是标记式的，重新推导延迟到查询时按需进行，
且只涉及失效病例自身相关的病房记录。

## 5. 查询的开销界

状态查询 `Status(X)` 的候选病例通过住宿索引按同病房重叠关系收集：

- 一跳：与 X 同病房重叠过的患者所拥有的病例（X 可能是其密接）；
- 二跳：与上述患者同病房重叠过的患者所拥有的病例
  （X 可能经某个密接成为其次密接；次密接不再外传，两跳即完备）。

开销只与 X 及其同病房相关记录数相关，与全院住宿记录总数无关。
每个操作重置并记录 `OpStats`（扫描的住宿记录数、推导/失效的病例数），
测试 `TestScaleIndependence` 在 2 千与 20 万条住宿两档规模下断言
统计值**完全一致**（实测：扫描 30 条记录、推导 1 个病例），
基准测试显示两档规模查询耗时无增长（约 1us vs 0.6us，差异为噪声）。

## 6. 关键取舍与被放弃的方案

- **单互斥锁 vs 细粒度锁**：所有公开方法由一把 `sync.Mutex` 串行化。
  规格只要求“并发调用等价于某个串行顺序”，单锁天然满足且避免了
  锁序/死锁与不确定性。放弃读写锁，因为查询会按需触发惰性推导（写缓存）。
- **惰性推导 vs 变更时立即重算**：变更只做失效标记，查询时按需推导。
  立即重算会为无人查询的病例做功；惰性方案下“重新推导只涉及受影响
  病例”由失效集合的大小直接度量（`OpStats.CasesInvalidated`）。
- **线性扫描涉及病房 vs 区间树/有序索引**：病房的住宿列表按插入序保存、
  扫描时线性过滤。规格允许“与同病房相关记录数相关”的开销；引入区间树
  会把每次入住/追补的索引维护变为 O(病房记录数) 甚至更复杂，
  收益不抵复杂度，故放弃。
- **朴素模型作为独立参照而非主实现**：`naive` 包每次查询全量扫描，
  语义相同但复杂度不可接受；它用于差分测试证明主引擎的增量优化不改变语义。
- **不持久化任何推导结果**：缓存可随时丢弃重建，从机制上保证
  “不得依赖旧的推导结果”。

## 7. 测试策略

- **边界与语义测试**（`engine_test.go`）：恰 120 与 119、跨病房分段累计、
  传染期起点与隔离时刻取等、恰加 7 天/3 天解除、次密接暴露期与确诊登记
  时刻取等、多病例最严与最晚、改正使接触者进出、追补使已解除者重新隔离、
  撤销、错误优先级、被拒操作不改变时钟与状态、次密接不外传、开区间语义。
- **差分测试**（`differential_test.go`）：默认 1500 组随机操作序列
  （可用 `ONT_DIFF_SEQ`/`ONT_DIFF_OPS`/`ONT_DIFF_SEED` 调整），
  每组与朴素模型逐步对照（含错误类别），随后做同序列重放对照与
  规范重建对照；每步输入、输出与判定依据写入
  `testdata/differential.log`（可用 `ONT_DIFF_LOG` 改路径）。
- **规模对照**（`scale_test.go`）：两档规模下统计计数器完全一致 + 基准测试。
- **并发**（`concurrency_test.go`）：多 goroutine 混合变更与查询，
  `go test -race` 验证无数据竞争，且结果与串行参照一致。

## 8. 本地验证方法

```bash
export PATH=$PATH:/usr/local/go/bin
export GOCACHE=/tmp/gocache        # 本机默认 GOCACHE 只读时需要

go build ./...                     # 编译
go vet ./...                       # 静态检查
gofmt -l .                         # 格式（无输出即通过）
go test ./...                      # 全量测试（含 1500 组差分）
go test -race ./...                # 竞态检测
go test -run TestScale -v .        # 两档规模对照（打印计数器）
go test -run xxx -bench . .        # 基准：两档规模查询耗时
go run ./cmd/demo                  # 端到端示例
ONT_DIFF_SEQ=3000 go test -run TestDifferentialAgainstNaive -v .
```
