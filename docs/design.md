# 高校教师授课任务分配与学期工作量核算服务 — 设计说明

## 1. 领域模型与精确口径

### 1.1 折算工作量（总量守恒的核心）

一项任务中承担 `h` 学时的教师，其折算工作量为

```
workload = floor( h * sizeCoeff * newCourseCoeff * labCoeff / 100^3 )
```

- 三个系数均以**整数百分数**给出：规模系数取命中档位的 `Coeff`；
  新开课系数为 `100 + NewCourseAdd`（非新开课为 `100`）；
  实验课系数为 `LabCoeff`（非实验课为 `100`）。
- 三个系数**先连乘、只做一次向下取整**。实现用 `math/big.Int` 精确计算，
  从根本上排除浮点误差与中间溢出，保证任意输入下结果逐位可复现。
  对题目给定范围整数，`int64` 也足够，但 big.Int 让"精确"成为结构性保证。
- **严禁分步取整**。测试 `TestExactProductVsStepwise` 用
  `h=9, 120%, 110%, 110%` 锁定差异：连乘一次取整 = 13，
  分步取整 = `floor(floor(floor(9*1.2)*1.1)*1.1)` = 12。

### 1.2 规模档位：边界取等归高档

档位按 `MaxSize` 升序、互不重叠。班级人数 `n` 命中**最小的**满足
`n <= MaxSize` 的档位；因此人数恰等于某档 `MaxSize` 时归该档（较高档），
例如 `...,60→120%, 61→...` 中 `60` 归 120% 而不是 100%。
没有任何档位覆盖（超过最大档）视为参数非法。

### 1.3 学时守恒

- 课程总学时在任务创建时固定。同一课程可多人合上，但一批指派提交后，
  该任务"既有活跃学时 + 本批学时"之和必须**恰等于**课程总学时，否则整批拒绝。
- 每人承担整数、正数学时；批次内同一教师对同一任务只允许出现一次
  （否则参数非法，报第二次出现的下标）。
- 换人只重新切分承担段，不改变任务总学时（见 1.5）。
  守恒由 `allocated[taskID]` 计数器与全量差分测试双重保证。

### 1.4 指派生命周期与占用

一条承担关系状态机：

```
pending ──accept──▶ confirmed
   │  ┌─reject──────▶ rejected   （释放时段/上限/学时）
   └──┤
      └─now>deadline─▶ released   （惰性释放，不得再确认）
```

- `pending` 与 `confirmed` **都**占用时段与职级上限。
- 确认期限语义：`now > deadline` 才算超时；`now == deadline` 仍可确认
  （测试 `TestTimeoutBoundaryLazyRelease` 锁定恰等边界）。
- 超时不设后台线程，由"后续任意操作触达"时在临界区内**惰性释放**
  （`sweepExpiredLocked`，最小堆按 deadline 排序）。

### 1.5 中途换人与零头归属

学时按**全课程周数**均匀分布：

```
totalWeeks = weekEnd - weekStart + 1
base       = hours / totalWeeks        // 每周整数学时
rem        = hours % totalWeeks        // 零头
```

- 零头 `rem` **永远归首任教师**。自 `fromWeek`（含）起换人：
  首任保留 `taughtWeeks*base + rem`，新教师得 `(totalWeeks-taughtWeeks)*base`。
- 链式换人时，非首任教师的当前段只含整数 `base`，切分公式
  `taughtInSegment*base` 仍使各教师学时之和恒等于课程学时
  （不变量由差分测试在任意换人链路下验证）。
- 换人立即生效（管理动作），新教师得到一段 `confirmed` 承担段；
  必须同时通过新教师的**时段冲突**与**上限**校验，任一失败则整体不动。
- `fromWeek` 必须落在 `(WeekStart, WeekEnd]`：至少上完一周、至少剩一周，
  否则参数非法。

### 1.6 学期核算与抵扣

对 `(semester, teacher)` 做幂等核算：

- 核算时该教师本学期仍 `pending` 的指派一律释放（期末语义上晚于确认期限），
  只统计 `confirmed` 工作量。
- `shortfall = max(0, min - load)`，`excess = max(0, load - min)`。
- 超额的一半（向下取整）结转为**下一学期**可抵扣额度 `creditEarned`。
- 下学期可用抵扣额度：`used = min(incoming, shortfall, floor(min/4))`。
  抵扣只能冲抵欠额，**不能抬高上限**；封顶之外的额度作废。
- `unmet = shortfall - used` 为未达标。
- 核算结果落库即**冻结**：该教师该学期的指派/换人不再允许变更
  （`ErrIllegalState`）；重复核算原样返回，且不推进时钟、不触发释放。
- 学期字符串用 `NextSemester` 推导下学期（支持 `2024-1/2024-2` 等），
  未用完的结转额度在被使用学期结算时作废，不跨第三个学期。

## 2. 关键取舍

- **单一互斥锁串行化所有操作**。题目要求"并发等价于某个串行顺序"，
  单把 `sync.Mutex` 让该性质成为定义级保证，`-race` 下由
  `TestConcurrentEquivalence` 验证。放弃了分片锁/乐观 MVCC：
  对教学任务分配这种低频、强守恒场景，其复杂度不具性价比。
- **冲突判定 O(周数×节数)，与历史任务总数无关**。
  维护 `occ[teacher] map[(week,period)] -> taskID`，指派/换人时只遍历
  **新任务自身**的格子做 map 查询。同任务承担者（合上）豁免。
  `BenchmarkConflictLookup` 在 10/100/1000 个历史任务下度量单次判定，
  耗时近似平稳，提供可复现的经验证据；朴素模型则刻意 O(历史总数) 扫描。
- **惰性超时 + 最小堆**：不依赖定时器线程，可确定性重放。
  关键点：惰性释放若发生在随后**被拒绝**的操作中，会违反"拒绝不改状态"。
  因此每个写操作先在"含释放效果"的视图上校验，失败时用 `rollbackSwept`
  恢复被释放指派并回退时钟；成功才提交。测试
  `TestRejectedOpDoesNotAdvanceClock` 等锁定该语义。
- **拒绝优先级全局固定**：
  参数非法 > 时钟回退 > 不存在 > 状态不允许 > 时段冲突 > 超出上限 > 学时不守恒。
  批量指派收集每项错误后，按"下标最小优先、同下标按优先级"取唯一一个
  （`Error.Index` 指出失败项），保证题目"只报第一个"的口径。
- **时钟由调用方随每个操作传入**（逻辑时钟，单调不减），
  使同一操作序列重放逐字节确定；`now < s.now` 即 `ErrClockRollback`。

## 3. 被放弃的方案

- **浮点系数 / `float64` 连乘**：会在边界上产生不可复现的取整，放弃。
- **分步取整后相加**：会改变总量且依赖乘法顺序，放弃（测试显式对比）。
- **区间树/位图做冲突检测**：当前以 `(周,节次)` 稀疏格 map 最直接，
  查询 O(1) 且天然支持换人按周裁剪；区间树只在节次极多时才更优，暂不需要。
- **后台 goroutine 扫描超时**：破坏确定性重放、引入并发关闭问题，
  改为惰性释放。
- **乐观并发 + 冲突重试**：守恒校验（跨请求求和）在重试下推理复杂，
  单锁更简单且严格正确。

## 4. 可复现性与验证

- 所有错误为强类型 `*Error{Code, Index, Msg}`，调用方可精确分支处理。
- 快照查询 `ListAssignments / ActiveLoad / Occupied / TaskAllocated`
  返回确定性顺序结果。
- 随机差分测试（`TestRandomDifferential`，`-v` 打印每步输入、输出
  错误码/下标与判定依据）用独立朴素模型（深拷贝快照回滚 + 线性扫描）
  对照生产实现，覆盖 40 个种子 × 300 步混合操作（含合上、不守恒、
  换人、链式换人、两学期结转、冻结、超时）。
- 本地验证命令：

```bash
export GOCACHE=/tmp/gocache                 # 若默认缓存目录不可写
go test -race ./...                          # 全量 + 竞态
go test -race -run TestRandomDifferential -v ./teaching/  # 含逐步日志
go test -run='^$' -bench=. ./teaching/       # 复杂度经验证据
go vet ./... && gofmt -l .
```
