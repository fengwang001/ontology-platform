# 条带化奇偶校验块卷（raid 包）

`raid` 包实现了一个带分布式奇偶校验的条带化块卷（RAID-5 风格），
支持单盘失效后的降级读写、换盘重建，并通过写意图日志消除写洞。

## 1. 布局推导

共 `N` 块盘（`N >= 3`），每块盘 `S` 个物理块，块大小固定。逻辑卷有
`S` 个条带，每个条带含 `N-1` 个数据块和 1 个校验块，逻辑块总数
`S*(N-1)`。

条带 `s` 内各块的落盘位置：

- 校验块在盘 `P(s) = N-1-(s mod N)`；
- 第 `k` 个数据块（`k = 0..N-2`）在盘 `D(s,k) = (P(s)+1+k) mod N`，
  即从校验盘的下一块盘起依次排列并回绕；
- 条带内所有块的物理块号都等于条带号 `s`。

逻辑块号 `b` 的映射：`s = b / (N-1)`，`k = b mod (N-1)`，落在盘
`D(s,k)` 的物理块 `s`。

校验块沿盘循环分布（`s` 每增 1，校验盘减 1 回绕），因此校验负载均匀
散布到全部 `N` 块盘，不存在单一校验热点盘。以 `N=4` 为例：

| 条带 | 校验盘 | 数据盘(k=0,1,2) |
| ---- | ------ | --------------- |
| 0    | 3      | 0 1 2           |
| 1    | 2      | 3 0 1           |
| 2    | 1      | 2 3 0           |
| 3    | 0      | 1 2 3           |

条带不变式：校验块 == 该条带全部数据块的异或。任何已完成写入的
条带在任意时刻都满足该式；降级读、重建都靠它异或还原缺失块。

## 2. 读改写公式

- 部分条带写（`Write`）：读旧数据 `D_old` 与旧校验 `P_old`，按
  `P_new = P_old XOR D_old XOR D_new` 计算新校验，然后把新数据块与
  新校验块写回。只需 2 读 2 写，不必读整条带。
- 整条带写（`WriteStripe`）：`P = D_0 XOR D_1 XOR ... XOR D_{N-2}`，
  直接由新数据算出，无需预读。
- 降级写：失效数据块的旧值由其余 `N-1` 块异或还原后代入上式；若失效
  的是校验盘，则只写数据块，校验留待重建时按数据重算。
- 降级读（`Read` 命中失效盘）：目标块 = 其余 `N-1` 块的异或。

## 3. 写洞成因

部分条带写要先后更新数据块和校验块两个物理块，无法原子完成。若在
两次写之间断电，盘上会出现"数据是新的、校验是旧的"（或反之）的
条带——这就是写洞。此时若再有一块盘失效，用不一致的校验去异或
还原，会静默得到错误数据。因此每次写入前先把意图记录（intent）
落盘，恢复时按意图把条带修复到一致状态。

## 4. 意图日志与恢复规则

日志是独立块设备，每个条带一个槽位（头部块 + 最多 N 个负载块）。
提交顺序：先写负载块，最后写带校验和的头部块——头部落盘即意图
生效；写完成后清除槽位。超级块持久化当前失效盘编号。

正常状态（无失效盘）：意图只记录"条带 s 在写"。恢复时对该条带
按数据块重算校验（`P = XOR(全部数据块)`）并写回校验盘。无论断电
发生在数据块写入前还是后，重算都让校验与盘上数据重新一致，已落盘
的新数据不会丢。

降级状态（有一块失效盘）：不能靠"按数据块重算"恢复——若失效的
是数据盘，重算需要它的旧值，而旧值又要靠旧校验还原，形成循环依赖。
因此降级下意图记录同时携带新数据与新校验作为负载，恢复时把负载
整体重放到各存活盘（失效盘的目标块跳过，留待重建）。重放是幂等的
整体覆盖：写已确认但清除记录前断电时重放一次同样内容，已确认的
写入不丢。

重建：`Rebuild(target, 新盘)` 在后台逐条带执行
`新盘块 = 其余 N-1 块异或`。重建与读写按条带锁串行化，读写不中断；
已重建的条带立即参与读写（写直接落新盘，读直接读新盘）。崩溃后
重建进度不保留，重新上电后对仍处于失效状态的盘再次发起 `Rebuild`
即可，已重建的块会被同样的值重写。

## 5. 并发与确定性

- 每条带一把读写锁：同条带操作串行，不同条带并发。
- 全局状态（失效盘、重建进度）由互斥锁与原子计数保护。
- 设备写顺序固定（意图负载 -> 意图头 -> 数据块 -> 校验块 -> 清除），
  断电点按全局设备写计数模拟，因此同一写入序列与同一断电点产生
  逐字节相同的各盘内容。

## 6. 错误语义

以下操作整体拒绝，且拒绝前不写任何盘（测试用写计数器验证）：

| 操作 | 错误 |
| ---- | ---- |
| 读/写越界逻辑块 | `ErrBlockOutOfRange` |
| 写越界条带 | `ErrStripeOutOfRange` |
| 已有失效盘时再标记另一块 | `ErrDiskAlreadyFailed` |
| 对未失效盘发起重建 | `ErrDiskNotFailed` |
| 重建进行中再次发起 | `ErrRebuildInProgress` |

均可用 `errors.Is` 区分。

## 7. 本地验证方法

```bash
# 全部测试（映射表 / 逐步断电 / 降级重放 / 并发重建 / 逐条带校验）
go test ./raid -v

# 竞态检测
go test ./raid -race

# 关键用例
go test ./raid -run TestMappingTable -v
go test ./raid -run TestPartialWriteCrashEveryStep -v
go test ./raid -run TestDegradedCrashReplay -v
go test ./raid -run TestRebuildConcurrentWrites -v
go test ./raid -run TestRebuildVerifyEveryStripe -v
```

测试日志以"输入 / 输出 / 判定依据"的格式打印每个场景的操作、
结果与校验规则。断电由 `CrashController` 模拟：武装后允许固定次数
的设备写，随后所有写被丢弃；重新 `Open` 即触发崩溃恢复。
