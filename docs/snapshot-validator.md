# 子图快照完整性校验与损坏定位器 — 设计说明

代码位于 `snapshot/` 包，入口为 `Validate(records []Record) Result`。

## 功能概述

对一份已导出的子图快照记录序列（对象记录与链接记录按序混合）逐条校验，
在第一条损坏记录处截断，返回：

- `PrefixLen`：最大可恢复前缀长度（首条即损坏时为 0，合法返回值而非错误）；
- `Corruption`：三类损坏原因之一（对象记录自身字段损坏 / 链接记录自身字段损坏 / 链接记录引用缺失）；
- `Complete`：整份序列自洽时为 `true`，与「损坏恰好发生在最后一条」严格区分——
  区分依据是损坏记录是否存在，而非前缀长度占比；
- 空序列直接判定为「完整」，不与「零长前缀」混用同一返回值。

## 关键取舍

- **单次顺序扫描，首坏即停**。用一张 `map[对象标识]对象类型` 记录已纳入前缀的
  对象声明；链接记录查表命中即满足先出现约束。时间复杂度 O(n)，空间 O(不同对象数)。
  截断后不再读取任何后续记录，读取计数 `recordsRead = PrefixLen + 1`。
- **损坏分类在截断记录上按固定次序判定**：对象记录自身字段损坏 >
  链接记录自身字段损坏 > 引用缺失。实现上体现为对每条记录先查自身字段、
  再查引用；只判定实际导致截断的那一条记录，不追溯前缀内已接受的记录。
- **重复对象声明**：同类型视为冗余直接放行（不更新状态也不报错）；
  类型冲突视为该对象记录自身字段损坏。两者共用同一张声明表即可区分。
- **不可变性与并发安全**：`Validate` 是纯函数，所有状态（声明表）均为调用内局部变量，
  不读写输入切片、不持有包级可变状态，因此并发多次调用互不干扰且结果确定。
- **内部度量不暴露**：`Result.recordsRead` 为非导出字段，调用者无法读取；
  包内测试在每次断言中验证 `recordsRead <= PrefixLen + 1`，
  以此证明读取量与「前缀长度加一」同量级。
- **记录建模**：`Record` 为封闭接口（仅 `ObjectRecord` / `LinkRecord` 实现），
  编译期排除未知记录种类；字段缺失以空字符串建模，方向取值不合法以
  枚举外 `Direction` 建模。无法识别的记录（如 `nil`）兜底归类为对象记录字段损坏。

## 被放弃的方案

- **扫描全部记录后汇总所有损坏**：违反「首坏即停、不信任后续记录」的要求，
  且读取量会达到 O(n) 而非 O(前缀长度+1)，放弃。
- **先整体构建索引再校验的两遍扫描**：需要读取全部记录，无法满足
  「不对前缀之外的记录做多余检查」的度量约束，放弃。
- **把读取度量导出给调用者**：需求要求度量「内部可验证、不对调用者暴露」，
  故仅保留非导出字段供包内测试断言，放弃导出。
- **用 `error` 表达截断**：首条损坏导致零长前缀是合法结果而非错误，
  且「完整」与「零长前缀」必须可区分，故统一用 `Result` 结构表达，放弃错误返回。

## 本地验证方法

```bash
# 环境：Go 1.26+；若默认 GOCACHE 不可写，使用 GOCACHE=/tmp/gocache
go build ./...
go vet ./...
gofmt -l .                # 应无输出
go test -race ./snapshot/ # 竞态检测 + 全量测试
go test -v -run TestRandomizedDifferential ./snapshot/  # 查看每次校验的输入/输出日志
```

测试覆盖：

- 损坏发生在序列最前 / 中间 / 最后的边界（`TestBoundaries`）；
- 空序列判「完整」与首条损坏判「零长前缀 + 原因」的区分（`TestEmptySequenceIsCompleteNotZeroPrefix`）；
- 末条损坏与整体完整的区分（`TestCorruptAtLastDiffersFromComplete`）；
- 对象重复声明类型一致（冗余）与不一致（损坏）（`TestDuplicateObjectRecords`）；
- 链接引用自身已损坏对象的连锁情形：截断归属对象记录且扫描立即停止（`TestChainFromCorruptObject`）；
- 三类原因的判定优先级（`TestCorruptionPriority`）；
- 重复校验与并发校验结果一致、输入不被修改（`TestRepeatAndConcurrentValidation`）；
- 随机生成 + 随机注入损坏的序列上，与独立实现的朴素 O(n²) 逐条校验模型对照，
  并逐条记录输入、输出、最大可恢复前缀与损坏原因（`TestRandomizedDifferential`）。
