# 多版本事务历史隔离异常判定器（`anomaly` 包）

给定读写操作与每个键的版本次序，判定器构建已提交事务之间的
依赖图，按 Adya 风格的异常分类输出**最先命中**的类别、隔离等级
与规范见证环。

## 版本模型

- 至多 12 个事务，编号为正且互不重复；状态为 `committed` / `aborted`。
- 事务对键 k 的第 n 次写（n 从 1 起，按该事务操作的时间序计数）
  产生版本 `(事务编号, n)`；`(0,0)` 是初始版本。
- 每个键给出版本次序：初始版本最先，其后是每个**已提交事务对该
  键的最后一次写**，各出现一次。已中止版本、中间版本、缺失或
  重复的最后写都构成 `malformed-version-order`。
- 读操作显式给出返回的具体版本 `readVersion`。

## 三类边的方向

只有版本次序内的版本产生边，且只在**已提交事务**之间、
**两端事务不同**时产生（自读自写不成边）。同一对事务在不同键
上产生的边按类型合并（WW / WR / RW 位掩码）。

- **写写边 WW**：Ti 写的版本在次序中紧邻 Tj 写的版本之前，
  则 `Ti ──WW──▶ Tj`。
- **写读边 WR**：Tj 读到 Ti 写的版本，则 `Ti ──WR──▶ Tj`。
- **读写边 RW**（反序依赖）：Tj 读到某版本，而 Ti 写的版本
  在次序中紧邻该版本之后，则 `Tj ──RW──▶ Ti`。
  读初始版本时，其后继是次序中的首个版本。

## 类别判定顺序与隔离等级

按下列顺序检查，**只报第一个命中**：

| 顺序 | 类别      | 命中条件                                   | 等级  |
| ---- | --------- | ------------------------------------------ | ----- |
| 1    | G0        | 纯 WW 边构成的环                           | 无    |
| 2    | G1a       | 已提交事务读到已中止事务写的版本           | PL-1  |
| 3    | G1b       | 已提交事务读到别的事务对该键非最后一次的写 | PL-1  |
| 4    | G1c       | 仅由 WW/WR 边（无 RW）构成的环             | PL-1  |
| 5    | G-single  | 恰含一条 RW 边的环                         | PL-2  |
| 6    | G2        | 含 RW 边且不止一条的环                     | PL-2+ |
| —    | PL-3      | 无任何命中                                 | PL-3  |

## 见证环的规范化

对每类环选取：最短；等长时取事务编号序列字典序最小；序列以环内
最小编号起头、沿边方向排列。搜索先用带 RW 计数状态的 BFS 求各类
别最短长度，再用定长 DFS 按邻居编号升序取字典序最小环。

## 拒绝（整体拒绝，不改变任何状态）

按固定顺序只报第一个：

1. `zero-or-duplicate-txn-id`（编号为零、非正或重复）；
2. `read-references-unknown-version`（读引用不存在的版本）；
3. `malformed-version-order`（初始版本不在最先、含已中止/中间版本、
   缺少已提交事务最后写、或最后写重复）；
4. `too-many-transactions`（事务数超过 12）。

## 并发与排列无关

`anomaly.Analyze` 是无共享可变状态的纯函数，可被任意并发调用；
`anomaly.NewLogger(w).Analyze` 额外以互斥锁串行化日志写入，日志
中先打印按事务编号规范化后的输入，再打印输出与判定依据（reason）。
事务在输入中的排列不影响结果；每事务操作的相对次序承载写版本
编号语义，不做重排。

## 输入格式

```json
{
  "txns": [
    {"id": 1, "status": "committed", "ops": [
      {"type": "read",  "key": "x", "readVersion": [0, 0]},
      {"type": "write", "key": "x"}
    ]}
  ],
  "order": {"x": [[0, 0], [1, 1]]}
}
```

## 本地验证

```bash
# 全量测试（含随机小历史 × 逐环穷举对拍、乱序、并发）
go test ./anomaly/

# 竞态检测 + 详细输出
go test -race -v ./anomaly/

# 代码检查与格式化
go vet ./...
gofmt -l .

# 内置演示（丢失更新 / 写偏斜 / G0）
go run ./cmd/anomaly

# 判定自定义历史
go run ./cmd/anomaly -in history.json
```
