# fdb：带注入时钟的以太网学习交换机转发表

`fdb` 包实现一个结果可精确复现的二层学习交换机转发表（Filtering Database）。
时间不取自系统时钟，而由每个变更类调用的参数 `t`（纳秒）注入，
因此同一条调用序列在任何机器上重放都得到完全相同的返回值与计数。

## 构造

```go
f, err := fdb.New(N, A, C)
```

- `N`：端口数，`1 <= N <= 64`，端口编号 `0..N-1`。
- `A`：动态表项老化时长（纳秒），必须为正。
- `C`：动态表项容量，必须为正；静态表项不占容量。
- 任一参数非法返回 `ErrInvalidConfig`。
- 地址与 VLAN：MAC 为 6 字节；首字节最低位为 1 即组播（全 `FF` 广播亦属组播）；
  VLAN 取 `1..4094`。

## 处理顺序（固定，不可调换）

所有变更类调用（`Frame` / `AddStatic` / `FlushPort`）都严格按以下顺序：

1. **校验参数**：端口范围、VLAN 范围、时钟单调性。任何一项不通过即整体拒绝，
   不改动表项、时钟与任何计数。
2. **清除全部已过期的动态表项**：对每条动态表项，当 `t - seen >= A`（左闭）时删除，
   每删一条 `Expired` 加一。静态表项永不过期。
3. （仅 `Frame`）**学习**。
4. （仅 `Frame`）**转发**。

成功的变更调用把内部时钟推进到 `t`；`t` 等于上次时刻合法，严格更早则返回
`ErrClockBackward`。

### 学习（按源地址）

- 源 `s` 为组播：不学习，帧仍继续转发。
- `(v, s)` 无表项：新建动态表项 `(port=p, seen=t)`，`Learned` 加一。
  - 若当前动态表项已达 `C` 个，先淘汰再新建：
    取 `seen` 最早的动态表项；`seen` 并列时取键 `(v,mac)` 字节序最小者；
    `Evictions` 加一。
- 已有动态表项：无条件把端口改为 `p`、`seen` 置为 `t`（同端口也刷新）；
  仅当端口发生变化时 `Moves` 加一。
- 已有静态表项：表项不改动；若 `p` 不等于静态端口，本帧丢弃——返回空列表、
  `SecurityDrops` 加一、不再进入转发阶段；`p` 相同则照常进入转发。

### 转发（按目的地址）

- `d` 为组播，或 `(v,d)` 无表项（未知单播）：泛洪，出端口为除 `p` 外的全部端口
  （升序），`Floods` 加一。
- 有表项且其端口等于 `p`：过滤，返回空列表，`Filtered` 加一。
- 有表项且端口不等于 `p`：返回只含该端口的单元素列表。

源与目的相同的单播帧因为“先学习、后转发”，转发时必然命中同端口而被过滤。

## 其他操作

- `AddStatic(v, mac, p, t)`：`mac` 为组播返回 `ErrMulticastStatic`；
  同键已有动态表项则覆盖为静态、释放动态容量，`Overridden` 加一；
  同键已有静态表项则改端口（不计数）。
- `FlushPort(p, t)`：删除端口 `p` 上的全部动态表项，`Flushed` 按删除条数累加；
  静态表项不受影响；返回删除条数。
- `Lookup(v, mac, t)`：只读查询，已过期动态表项视为未命中；
  不校验时钟、不改任何表项/时钟/计数。
- `Len()`：当前存放的动态表项数（包含已过期但尚未被下一次变更调用清除者）。
- `Stats()`：全部计数的快照。

## 计数口径与守恒式

| 计数 | 口径 |
| --- | --- |
| `Learned` | 新建动态表项的次数（不含迁移/刷新） |
| `Moves` | 动态表项端口发生变化的次数 |
| `Evictions` | 容量满时被淘汰的动态表项数 |
| `Expired` | 过期清除阶段删除的动态表项数 |
| `Flushed` | `FlushPort` 删除的动态表项数 |
| `Overridden` | 动态表项被静态表项覆盖的次数 |
| `SecurityDrops` | 源命中静态表项但入端口不符而丢弃的帧数 |
| `Floods` | 组播目的或未知单播而泛洪的帧数 |
| `Filtered` | 命中同端口而过滤（返回空）的帧数 |

动态表项的每一次“新生”最终只可能处于四种去向之一：仍在表中、被淘汰、
老化过期、被 flush、被静态覆盖。因此任意时刻都有：

```
Len() + Evictions + Expired + Flushed + Overridden == Learned
```

`Moves`、`SecurityDrops`、`Floods`、`Filtered` 不计入守恒式。

## 拒绝原因（errors.Is）

- `ErrPortRange`：端口越界。
- `ErrVLANRange`：VLAN 不在 `1..4094`。
- `ErrMulticastStatic`：为组播 MAC 安装静态表项。
- `ErrClockBackward`：变更调用的 `t` 早于上一次成功调用的时刻。
- `ErrInvalidConfig`：构造参数非法。

被拒绝的调用不改变任何表项、时钟与计数。

## 并发与确定性

所有方法由单一互斥锁保护，并发执行等价于某个串行顺序；
注入时钟保证相同调用序列重放得到完全相同的返回值与计数；
`Frame`/泛洪返回的切片每次新建，不与内部状态共享存储。

## 本地验证

```bash
# 全量测试（含竞态检测）
go test -race -v ./fdb

# 覆盖率
go test -race -coverprofile=cov.out ./fdb
go tool cover -func=cov.out

# 格式与静态检查
gofmt -l .
go vet ./...
```

`fdb/naive.go` 中的 `Naive` 是严格按本文件规则写成的朴素逐条扫描实现
（无哈希、无索引）；`TestDifferentialRandom` 在 40 个随机种子、每种子 400 步上
对两种实现做差分对照并逐步校验守恒式，`TestReplayDeterministic` 校验序列重放一致，
`TestConcurrentSafe` 在 `-race` 下压测并发。
