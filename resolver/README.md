# resolver — 允许重叠实例的类型类实例解析器与增量失效缓存

`resolver` 包实现带上下文实例的登记、对基础类型的约束求解（推导树），
以及在新增实例后精确失效的解析缓存。所有方法可并发调用，效果等价于
某个串行顺序；相同操作序列重放得到完全相同的推导树、错误原因与实例
编号。

## 类型与约束

- 类型是构造子应用 `Con(名字, 参数列表)`（名字 1–32 字节非空，参数至多
  4 个）或变量 `Var(i)`（`i` 为 0–7，只出现在实例中）。
- 基础类型不含变量，深度（零参数构造子为 1，否则 1 加参数最大深度）
  不超过 16。
- 规范文本：零参数写名字，否则 `名字<参数1,参数2>`（逗号分隔）。
- 约束为 `(特征名, 类型)`，特征名 1–32 字节非空。
- 推导深度上限 `D` 为构造参数，范围 1–64。

## 匹配与更特化

- 头类型 `H` **匹配**基础类型 `T`：存在把 `H` 的各变量代换为基础类型
  的代换使二者逐位相同；同一变量的各处必须代换为同一类型（非线性头，
  如 `Pair<a,a>` 不匹配 `Pair<Int,Char>`）。
- 实例 `A` **更特化于**实例 `B`（同特征）：把 `A` 的头类型变量当作互
  不相同的不可代换常量后，`B` 的头类型能匹配它。该关系自反但不对称；
  两个头类型可能互不更特化（如 `Pair<Int,a>` 与 `Pair<a,Int>`）。

## 实例选择：唯一最特化与不回退

`Resolve(特征, 基础类型)` 的候选是同特征且头类型匹配该类型的实例：

- 无候选 → **无实例**；
- 有候选时必须存在一个比其余每个候选都更特化的实例（唯一最特化），
  否则为**歧义**；
- 选定后不再考虑其他实例，也不看上下文：上下文递归解析失败即整体
  失败，**不回退**到其他候选。

上下文各约束按声明次序依次递归解析为子树，第一个失败即整体失败；
失败携带失败所在目标（特征，规范类型文本）与类别，取深度优先且声明
次序下最先出现者。推导树高度：无上下文实例为 1，否则 1 加子树最大
高度。

## 深度与循环判定

目标所在层数 `ℓ` 从顶层 1 起。解析一个目标时：

1. 先判**循环**：同一 `(特征, 类型)` 已在当前递归路径的祖先目标中
   出现；
2. 再判**深度超限**：`ℓ > D`；
3. 然后查缓存、选实例。

因此 `ℓ == D` 允许、`ℓ == D+1` 拒绝，且同一目标既是循环又超限时报告
循环。

## 缓存与精确失效

- 成功解析的目标（含各级子目标）进入缓存，键为 `(特征, 基础类型)`，
  条目记录所选实例、树高度与直接子目标的键；失败不缓存，但失败前已
  成功的子目标照常入缓存。
- `Resolve` 遇到缓存条目且 `ℓ + 树高度 - 1 ≤ D` 时直接使用，不再检查
  任何实例（非导出计数器 `headMatches` 头类型匹配尝试次数为 0 可验
  证）；不满足该条件不算命中，按正常过程解析。
- `AddInstance(N)` 成功后，对缓存中每个目标 `g`（所选实例为 `S`）：
  当且仅当 `N` 与 `g` 同特征、`N` 的头类型匹配 `g` 的类型、且 `S`
  **不**更特化于 `N` 时，`g` 失效。失效沿被依赖方向传递：任何树内含
  失效目标的条目也失效（不向子目标传递）。其余条目全部保留。因此失
  效的条目重新解析结果必然不同，保留的条目重新解析结果与缓存完全相
  同（`VerifyCacheConsistency` 自检）。

## 重复实例与拒绝原因

- 同特征两个实例的头类型在变量按先序首次出现次序重新编号后逐位相同，
  后者为重复实例（与上下文无关）。
- 拒绝原因可区分：`RejectInvalidParam`（名字为空或超长、参数个数越
  界、变量号越界、基础类型含变量或深度超限、上下文变量不在头类型中、
  `D` 越界）、`RejectDuplicateInstance`、`RejectTooManyInstances`
  （超过 200 个实例）。被拒绝的操作不改变任何状态。

## 本地验证

```bash
# 全部测试（含 2000 组随机登记/解析序列与朴素模拟对照，
# -v 日志打印每组输入、输出与失效判定依据）
go test ./resolver/ -v

# 竞态检测（并发等价于某个串行顺序）
go test -race ./resolver/

# 单个用例
go test ./resolver/ -run TestShowExample -v
go test ./resolver/ -run TestRandomDifferential -v

# 代码检查
gofmt -l resolver/
go vet ./resolver/
```
