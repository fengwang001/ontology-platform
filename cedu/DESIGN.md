# 执业资格继续教育学分周期核算服务 — 设计说明

## 1. 目标与建模口径

服务（`cedu` 包）管理持证人在连续固定长度证书周期内的学分登记、
更正、撤销、达标判定、宽限补修、超额结转与证书失效，使
“计入规则 + 边界条件 → 达标结论”可精确复现。

时间全部以非负整数日序号表示。周期自发证日 `issueDate` 起：

- 周期 `k` 为左闭右开区间 `[start,end)`，其中
  `start = issueDate + k·CycleLength`、`end = start + CycleLength`；
- 末日（`end-1`）取得的学分归本周期；`end` 当日取得的归下一周期；
- 宽限期为 `[end, end+GraceDays)`；`end+GraceDays` 当日补登、
  取得日落在宽限带内的学分一律不计入（“恰等允许、晚一日拒绝”）；
- 更正/撤销窗口为自登记日起的 `[regAt, regAt+CorrectDays]`，
  恰等于 `CorrectDays` 仍允许，超过拒绝。

## 2. 计入规则（纯函数，无状态）

`counting.go` 中 `countCredit` 是整个系统的规则锚点：

1. 必修、选修原始量分别按 `RequiredCap`、`ElectiveCap` 封顶，
   线上类无独立上限；
2. 线上类计入量再受联合约束
   `onlineIn ≤ requiredIn + electiveIn`（以封顶后的必修/选修为准）；
3. “同时存在多个约束时取使总计入量最大者”：规则 1、2 都是逐类
   取可行上界，各类独立取最大，顺序应用即得到联合可行域内总量
   最大的点，不存在需要枚举的取舍。

达标（`met`）要求同时满足：
`totalIn ≥ TotalRequired` 且 `requiredIn ≥ RequiredMin`。

结转（`carryOut`）：

- 仅周期末日本体达标的周期产生结转；宽限期内补足的周期
  `ocGracePass` 强制结转为 0；
- 可结转量为
  `min(CarryoverCap, 总量超额, 选修+线上口径的超额来源)`，其中
  来源 = `(electiveIn+onlineIn) − max(0, TotalRequired−requiredIn)`，
  即先以必修满足要求，缺口由选修/线上补足后，剩余的选修+线上
  才是超额来源；必修超额永远不进入结转；
- 结转学分在下一周期按选修类计入，与该周期自有选修、上周期
  宽限带流入的选修记录合并后，共同受 `ElectiveCap` 约束。

## 3. 状态结构与周期评估

每个持证人保存：

- `aggs[k]`：周期 `k` 的两个三维桶 —— `win`（取得日在周期本体）
  与 `zon`（取得日在本周期宽限带，仅当本周期窗口判定失败时才可能
  被采纳，否则作为取得日记录流入下一周期本体，并保留原类别）；
- 每条记录带 `cycle/zone` 归属标记。该标记在“登记被接受的时刻”
  依据当时的 front 决定，更正只改学分数，不移动归属；
- `cache[k]`：周期 `k` 的窗口判定结果 `{outcome, winMet, carryOut}`；
- `front`：尚未终结的最早周期序号；
- `events`：被接受操作的追加型事实日志（注册/登记/更正/撤销）。

周期推进 `advance(now)` 只依赖当前 `front`：

- `now < end`：进行中；
- `now ≥ end` 且窗口口径达标：`ocPass`，front 前移，结转生效；
- `end ≤ now < graceEnd` 且窗口不达标：宽限期中，等待补修；
- `now ≥ graceEnd`：把 `zon` 并入判定，达标则 `ocGracePass`
  （续期、无结转），否则 `ocExpired`，证书失效。

关键取舍：**窗口判定与采纳解耦**。宽限带内的记录始终有两个候选
归属（补修给当前失败周期 / 按取得日流入下一周期），最终归属只由
“该周期窗口口径是否达标”这一结构事实决定，因此更正/撤销后只需
重算聚合桶，再沿周期链重放判定，结果与记录一开始就是新值完全
一致（见 `TestCorrectionEquivalentToDirectValue`）。

## 4. 复杂度：核算开销不随历史记录总量增长

- 每次登记/更正/撤销只更新**一个**聚合桶（O(1) 次加法）；
- 周期判定只读取 `front` 与 `front-1` 的桶和缓存，不扫描记录；
- 更正影响历史周期时，缓存失效沿周期序号级联，在“首个结果不变
  的周期”处停止（影响被下游计入上限/达标线吸收即终止），摊销
  O(1)，且只与周期数有关、与记录条数无关。

可验证性：

- `BenchmarkStatusFixedCost` 在预置 100 与 10000 条历史记录两种
  规模下测量 `Status`，耗时同为百纳秒量级、不随记录数增长；
- 在线实现与全量 O(N) 朴素模型（`naive_test.go`，每次操作都从
  记录集合重算所有周期）在 300 组随机操作序列上逐操作比对错误码
  与快照，全部一致。

## 5. 时钟、拒绝优先级与原子性

服务维护**服务级单调时钟** `lastNow`（被接受的变更才推进；纯
查询不推进时钟，但周期到点与失效是客观终局，可在查询时物化）。
即使持证人不存在，时钟回退仍可被独立判定。

错误严格按以下优先级只报第一个（各方法入口顺序即优先级）：

1. 参数非法 `INVALID_PARAM`
2. 时钟回退 `CLOCK_ROLLBACK`
3. 持证人或记录不存在 `NOT_FOUND`
4. 状态不允许 `STATE_NOT_ALLOWED`（含取得日落入已终结周期、
   活动持证人重复注册）
5. 重复登记 `DUPLICATE_REGISTRATION`
6. 超出更正期限 `CORRECTION_WINDOW_EXPIRED`
7. 证书已失效 `CERTIFICATE_EXPIRED`

所有校验在任何状态写入之前完成；被拒绝的操作既不改聚合桶、
记录集合，也不推进时钟。可能由“本次操作恰好跨到宽限满日”导致
的失效，通过非突变预判 `wouldExpire / frontAt` 在写入前完成，
从而保证拒绝路径零副作用。

重复键为 `(org, earnedOn, category)`：同一机构、同一持证人、
同一取得日、同一类别即拒绝；撤销后该键释放，可重新登记。

## 6. 宽限、失效与重新注册

- 宽限期内取得日在宽限带、且在宽限满日之前补登的学分进入该
  未达标周期的 `zon`，与窗口记录同口径计入；补足即 `ocGracePass`，
  续期且不结转。
- 宽限届满未补足即失效。失效后除重新注册外的一切变更都报
  `CERTIFICATE_EXPIRED`；只能以相同或新的持证人 ID 重新注册，
  实现上直接以全新生命周期替换旧对象，旧学分、旧日志均不继承
  （记录序号从 R1 重新开始，见测试）。

## 7. 并发与确定性

服务以单一 `sync.Mutex` 串行化所有公开方法。并发调用的结果严格
等价于按锁获取顺序的某一串行执行；给定相同的操作序列（含相同
`now`），任何重放都得到逐字段相同的结果。记录 ID 由持证人内
单调序号生成，不引入随机量。`TestConcurrentEquivalence` 用
`-race` 验证 8 路并发登记无竞争，且总量恒等于串行结果。

## 8. 历史查询

`HistoryAt(holder, asOf)` 在独立服务实例上重放该持证人事实日志中
`at ≤ asOf` 的被接受操作（`replay.go`），再取 `asOf` 时刻快照。
重放走的是与在线完全相同的公开方法路径，因此历史结论可与“当时
的实际”逐字节核对；`asOf` 晚于最近被接受时钟按时钟回退拒绝。

## 9. 被放弃的方案

- **在周期结束时立即物化达标/结转事件**：无法表达“更正后等价于
  一开始就是更正值”，需要补偿事务与事件回滚，复杂且易错。改为
  结构归属 + 增量缓存，终局结论可随时重算。
- **宽限带记录物理迁移到下一周期桶**：续期/宽限达标翻转时要批量
  搬运记录，开销随记录数增长，且更正后难以回溯。改为保留
  `win/zon` 双桶 + 结构性归属，迁移只是判定时的口径选择。
- **每周期保存全部记录快照**：历史查询简单但更新成本高、冗余大。
  改为只追加事实日志，历史查询用重放换取 O(历史操作数) 的可接受
  成本，而在线核算保持 O(周期数)。
- **无锁/细粒度锁并发**：本题规模下单锁已线性化且无竞争热点，
  细粒度锁只会增加不可复现的排序风险，故放弃。
- **放宽 `GraceDays ≤ CycleLength`**：避免宽限带与下一周期窗口
  语义重叠带来的歧义；初始化直接拒绝该配置。

## 10. 本地验证方法

```bash
# 全量测试
go test ./...

# 竞态 + 详细用例
go test -race -v ./cedu/

# 随机对照序列的逐步输入/输出/判定日志
go test ./cedu/ -run TestDifferentialRandom -v

# 核算开销不随记录数增长的基准
go test -bench=BenchmarkStatusFixedCost -run=^$ ./cedu/

go vet ./...
gofmt -l .
```
