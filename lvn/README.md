# lvn — 基本块局部值编号器

按指令顺序为基本块内的每条指令分配值编号（从 1 起连续、无空洞），并识别重复计算。
`Block` 内部以互斥锁保护，`Append`/`Seal`/`Snapshot` 可并发调用，结果等价于某个串行顺序；
相同指令序列重放得到完全相同的编号与复用标记。

## 指令

| 指令 | 构造 | 语义 |
| --- | --- | --- |
| `CONST c` | `lvn.Const(c)` | 产生常量值 |
| `LOAD s` | `lvn.Load(s)` | 读槽 `s` |
| `ADD a b` | `lvn.Add(a, b)` | 可交换 |
| `MUL a b` | `lvn.Mul(a, b)` | 可交换 |
| `SUB a b` | `lvn.Sub(a, b)` | 不可交换 |
| `STORE s v` | `lvn.Store(s, v)` | 把值编号 `v` 存入槽 `s`，不产生值编号 |
| `CALL` | `lvn.Call()` | 调用屏障，恒产生新值编号且不复用 |

## 表键规范化

值编号表的键为「（操作，规范化操作数）」：

- `CONST`：键为其数值，如 `(CONST 5)`。
- `ADD`/`MUL`（可交换）：两个操作数按值编号升序规范化，`ADD 2 1` 与 `ADD 1 2` 同键。
- `SUB`（不可交换）：保留操作数顺序，`SUB 2 1` 与 `SUB 1 2` 不同键。
- `LOAD`：键为 `(槽, 该槽存取版本, 调用纪元)`。
- `CONST`/`ADD`/`MUL`/`SUB` 的键**不含**调用纪元，`CALL` 不会使这些键失效。

命中已有键时复用旧编号（`Reused=true`），不分配新编号；未命中才取下一个编号。

## 存取版本与调用纪元

- 槽版本与调用纪元初值均为 0。
- `STORE s v`：若槽 `s` 的已知值恰为 `v`，标记 `Redundant=true`，版本不变；
  否则槽版本加一，并令槽 `s` 的已知值为 `v`。
- 已知值只由 `STORE` 设置；`LOAD` 的结果**不**设置已知值。
- `LOAD s`：若槽 `s` 有已知值（最近一次 `STORE` 存入且之后无 `CALL`），直接返回该值编号并算复用；
  否则查表，键含当前槽版本与调用纪元。
- `CALL`：调用纪元加一、清空全部已知值，恒分配新编号；两次 `CALL` 不合并。

## 拒绝规则

同一次操作按「已封口 → 操作数 → 槽号」的次序只报第一个错误，
被拒绝的操作不改变值编号表、已知值与版本：

- `ErrSealed`：块已封口后再 `Append`。
- `ErrOperand`：操作数引用不存在的值编号。
- `ErrSlot`：槽号为负。
- `ErrReseal`：重复封口（封口只能一次）。

## 本地验证

```bash
# 全部测试（含朴素模拟对照与并发用例）
go test ./lvn

# 竞态检测 + 打印输入/输出/判定依据日志
go test -race -v ./lvn

# 代码检查
gofmt -l lvn && go vet ./lvn
```

测试要点：`TestAgainstNaiveModel` 用按上述规则独立写成的朴素模拟
（线性扫描 + 字符串键）对随机指令序列逐步对照编号、复用标记与最终状态；
`TestConcurrentMixed` 在并发追加下验证值编号连续无空洞。
