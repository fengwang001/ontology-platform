# index — 多列有序索引的访问路径推导与扫描器

`index` 包把各列上的等值、集合与范围条件编译成**最少的键区间**，
扫描时只考察落在这些区间内的条目，结果与全表逐行过滤恒等。

## 数据模型

- 索引按列声明顺序做字典序排序；**空值（NULL）排在每列最前**。
- 列类型：`KindInt`（`int`/`int64`）、`KindFloat`（`float64`）、
  `KindString`（`string`）；存储值为 `nil` 表示 NULL。
- 条件算子：`OpEq`（=）、`OpIn`（属于集合）、`OpLt`（<）、`OpLe`（<=）、
  `OpGt`（>）、`OpGe`（>=）、`OpIsNull`（为空）。

## 区间推导规则

1. **同列求交**：同一列上的多个条件取交集——
   - 等值与等值、等值与集合、等值与范围、集合与集合、集合与范围、
     范围与范围分别求交；
   - `IS NULL` 视为对 NULL 的**等值**；范围收敛为单点（如 `>= 3 AND <= 3`）
     也视为等值；集合与范围取交后仍是集合（可能收缩或变为单点）；
   - 交集为空（矛盾条件）时整个查询得到**空区间集合**，考察零条。
2. **首列无条件**：整个索引即一个区间，其余各列全部作为残余过滤。
3. **前缀组合**：从首列起，连续的等值/集合列做笛卡尔积，每个组合
   生成一个点区间前缀。
4. **范围并入**：遇到第一个范围列时，把它并入各组合的区间下界/上界
   后停止；其后的列只作残余过滤。
5. **退化规则**：前缀组合数超过上限 `L` 时，从**使组合数首次超限的
   那一列**起（含该列）全部改作残余过滤。
6. 推导出的区间按索引序排列、互不重叠；扫描结果恒等于对区间内条目
   施加全部条件（残余过滤），因此与全表逐行过滤一致。

## 空值处理

- 比较条件（`= < <= > >= IN`）对 NULL **永不成立**；只有 `IS NULL`
  能匹配 NULL。
- 因此 `a < 5` 的区间下界是 `-∞`，NULL 条目会被考察但被残余过滤剔除；
  `IS NULL` 则生成点区间 `[NULL, NULL]`。

## 查询拒绝

以下情况整体拒绝并返回可区分的错误（`errors.Is` 可判定），且**不改变
任何统计**：

- `ErrUnknownColumn`：引用未知列；
- `ErrTypeMismatch`：值类型与列类型不符（含用 NULL 作比较/集合操作数）；
- `ErrEmptySet`：`IN` 集合为空；
- `ErrInvalidComboLimit`：组合数上限 `L` 不为正。

## 并发与快照

- 写入（`Insert`/`Delete`）采用写时复制；每次 `Scan` 看到其**开始时的
  一致快照**，可与写入并发调用。
- 考察条目数恰等于该快照中落在推导区间内的条目数；结果按索引序输出。
- `Snapshot()` 可显式获取快照；同一快照与相同条件反复扫描结果完全
  相同。

