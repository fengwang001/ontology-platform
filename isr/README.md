# isr：分区副本同步副本集（ISR）维护与高水位推进

`isr` 包实现单个分区副本集的协调逻辑：领导者写入推进日志结束位点（LEO），
跟随者通过拉取上报自己已拥有的位点；系统据此维护同步副本集（ISR）并推进
高水位（HW）。所有方法均可用一把互斥锁被多个执行体并发调用。

## 核心模型

- **LEO（日志结束位点）**：每个副本拥有的下一个日志位点，单调递增。
- **LastCaughtUp（追上时间）**：跟随者最近一次追平当时高水位的时间。
- **ISR（同步副本集）**：始终包含领导者；跟随者在追平时加入，落后超时被移出。
- **HW（高水位）**：ISR 内全部副本（含领导者）LEO 的最小值，且只进不退。

## 操作语义

### 写入 `rs.Append(newLEO, now)`

- 仅领导者写入；`newLEO` 必须严格大于领导者当前 LEO（只推进，不回退）。
- 写入成功后重算高水位：`min(LEO of every member in ISR)`。

### 拉取 `rs.Fetch(replicaID, offset, now)`

- 跟随者上报其已拥有位点；要求 `0 <= offset`、不小于自身进度、不大于领导者 LEO。
- 当 `offset >= 当前高水位` 时：刷新该副本的追上时间为 `now`；
  若它此前已被移出 ISR，则**重新加入** ISR（追平当前高水位即可，无需追到领导者 LEO）。
- 成功后重算高水位。

### 周期检查 `rs.PeriodicCheck(now, tolerance)`

- 对 ISR 内每个跟随者，当且仅当 `now - LastCaughtUp > tolerance`
  （**严格大于**；相等不剔除）时将其移出 ISR。
- 领导者永不移出。移出后重算高水位；因 HW 只进不退，缩小 ISR 不会使 HW 回退。

### 查询 `rs.Query(now)`

- 返回 HW、ISR 列表（已排序）与各副本进度（LEO、LastCaughtUp）的深拷贝快照。
- 查询为只读操作，但同样校验时间单调性并更新已观察最大时间。

### 注册 `rs.AddReplica(id)`

- 新跟随者初始 LEO 0；HW 为 0 时直接进入 ISR，否则留在集外，待拉取追平 HW 后加入。

## 高水位规则

1. HW = ISR（含领导者）内所有 LEO 的最小值。
2. 新计算值仅在严格大于旧值时生效：**只进不退**。
3. 因此 HW 永远不超过 ISR 内任一副本的进度。
4. 副本移出后不再参与最小值；副本重新加入后重新参与。

## 边界与错误类别

任何输入校验失败都会**整体拒绝**，HW、ISR、各副本进度与已观察时钟均不改变
（“失败不留痕”，校验全部先于任何状态写入）。四类可区分的哨兵错误，
用 `errors.Is` 判断：

| 错误 | 触发条件 |
| --- | --- |
| `ErrInvalidArgument` | 空/重复副本标识、跟随者使用领导者标识、领导者执行拉取、`now < 0`、`tolerance < 0` 等 |
| `ErrUnknownReplica` | 拉取目标副本未注册 |
| `ErrInvalidOffset` | Append 位点未严格推进；Fetch 位点为负、小于自身进度或大于领导者 LEO |
| `ErrClockWentBack` | `now` 早于本副本集已成功观察到的最大时间（时钟回退） |

时间语义：所有方法的 `now` 共享同一个单调时钟基准；成功调用推进已观察最大时间，
被拒调用不推进。相等时间戳是允许的（时钟不动不算回退）。

## 并发

- 内部用 `sync.Mutex` 串行化状态变更与读取；`Query` 返回深拷贝快照。
- 领导者恒在 ISR；并发不变量（HW 不超过任一 ISR 成员进度、HW 单调）
  由竞态检测下的并发测试覆盖。

## 日志

每次调用都打印：操作名、当前 HW、当前 ISR、本次输入与判定依据；
被拒调用额外打印 `REJECTED reason=...`，便于逐步复现。
