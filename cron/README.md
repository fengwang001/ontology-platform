# Cron 触发时刻计算器与错过触发控制器

`package cron` 用**自 2000-01-01 00:00（星期六）起的整数分钟**表示时间，
覆盖公历 2000 至 2199 年（闰年规则：能被 4 整除且不能被 100 整除，
或能被 400 整除，因此 2000 闰、2100 平、2196 闰）。

## 时间换算

- `ToMinute(y, mo, d, h, mi)`：公历日期时间 → 分钟数；非法日期
  （如 2000-02-30）或超出 2000–2199 返回 `ErrIllegalTime`。
- `FromMinute(t)`：分钟数 → 公历日期时间；`t < 0` 或超过
  2199-12-31 23:59 返回 `ErrIllegalTime`。

## 表达式语法

`Parse(spec)` 以**单个空格字符**切分（不合并连续空格），恰好五个字段，
次序为：分（0-59）、时（0-23）、日（1-31）、月（1-12）、周（0-6，
0 为星期日，7 非法）。字段内是逗号分隔的非空项列表，每项为：

- `*`：整个字段取值集合；
- `a`：单个值；
- `a-b`：闭区间，要求 `a <= b`；
- `*/s`：全字段按步长 `s` 取值，且**字段文本以 `*` 开头即带通配标志**；
- `a/s`：等价于“从 `a` 到字段上限、步长 `s`”（如 `5/20` 在分字段是 5、25、45）；
- `a-b/s`：区间内按步长取值。

步长 `s` 必须在 1 到该字段取值个数（分 60、时 24、日 31、月 12、周 7）
之间。逗号允许重复项（如 `0,0,30`）。

错误按固定次序报第一个违规：**字段个数 → 分/时/日/月/周字段 →
字段内各项的出现次序 → 每项内“语法 → 取值越界 → 范围反向 → 步长非法”**。

### 日与周的“或 / 与”规则

日期判定先要求月份命中，然后：

- 日字段与周字段的**通配标志都为假**（都不是以 `*` 开头的项）时，
  当天命中“日集合 **或** 周集合”即可；
- 只要其中一个字段带通配标志（含 `*/2`），就要求“日集合 **与** 周集合”
  同时命中（通配集合本身恒为真）。

例：

- `0 0 13 * 5`（都非通配，取或）：自 2000-01-01 起依次为 1 月 7 日（周五）、
  1 月 13 日（13 日）、1 月 14 日（周五）。
- `0 0 */2 * 5`（日字段通配，取与）：1 月 7 日之后跳过偶数日的 1 月 14 日，
  下一次是 1 月 21 日。
- `0 0 29 2 *`：2096-02-29 之后的下次触发是 2104-02-29（2100 不闰）。
- `0 0 31 2 *`：2 月永远没有 31 日，无下次触发。

## NextFire

`NextFire(spec, t)` 返回**严格大于 `t`** 的最小匹配分钟。`t` 之后
`4000×1440` 分钟内无匹配，或匹配超过 2199 年末，返回 `ErrNoNext`；
`t` 越界返回 `ErrIllegalTime`。

实现不逐分钟扫描：按天推进（包内 `lastDaySteps` 计数器证明步数不超过
4001：起点天 + 后续至多 4000 天），在已命中的日内用二分直接跳到
分/时集合的下一个值。

## 控制器 NewJob

`NewJob(spec, created, D, policy)`：

- `created` 必须在 `[0, 2199 年末]`，初始“上次调度时刻” `L = created`，
  Sync 时钟水位初值也是 `created`；
- `D` 为 `-1`（无截止）或 `[0, 10^9]` 分钟；
- `policy` 为 `Allow`、`Forbid`、`Replace` 之一；
- spec 无法解析或参数非法统一返回 `ErrInvalidArg`。

任务编号从 1 起单调递增；活动任务集合记为 `A`。

`SetSuspend(b)` 设置停摆标志。恢复本身不补偿任何内容。

### Sync(now) 窗口与只补最近一次

`now` 必须不小于上次成功 Sync 的水位。窗口是满足

```
t > L 且 t <= now 且（D != -1 时）t >= now - D
```

的全部触发分钟，个数为 `n`：

- `n == 0`：无事发生；
- `n > 100`：返回 `ErrTooMany`，**不改变 `L`、`A`、计数，也不推进水位**；
- `1 <= n <= 100`：只取窗口内**最大**的触发分钟 `t*`：
  - `Allow`：无条件新建任务；
  - `Forbid`：`A` 非空则跳过（`Skipped` 加一），否则新建；
  - `Replace`：先终止 `A` 中全部任务（`Replaced` 加被终止数），再新建。
- 无论新建还是跳过，最后都令 `L = t*`。

停摆（suspend 为真）时 Sync 不做补偿、不推进 `L`，但仍推进时钟水位。

错误次序：**时间非法（`now` 越界）→ 时钟回退 → 错过太多触发**；
被拒绝的操作不改变任何状态（被拒绝的 Sync 不推进水位）。
一次 Sync 内部最多调用 102 次 `NextFire`（1 次定位窗口起点 +
至多 101 次后继枚举）。

`Finish(taskID, now)`：把任务移出 `A`；任务不存在返回 `ErrNoSuchTask`，
`now` 越界返回 `ErrIllegalTime`。

所有方法用互斥锁保护，可被并发调用，结果等价于某个串行顺序；
重放相同操作序列得到完全相同的触发时刻、任务编号与计数。

```bash
go test ./cron/ -v          # 全量用例，含窗口边界与判定日志
go test -race ./...         # 竞态检测
go vet ./...
gofmt -l .
```

`TestRandomAgainstNaive` 用固定种子生成 2000 组随机表达式与起点
（起点覆盖约三年），将 `NextFire` 与逐分钟朴素扫描结果逐一对照，
并在日志中打印输入表达式、起点、输出触发时刻与按天步数。
