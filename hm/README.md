# hm — 层级泛化与值限制的 Hindley–Milner 合一会话

`hm` 包实现一个并发安全的 Hindley–Milner 类型推断会话：支持创建类型变量、
按层级（level）合一、把类型泛化为类型模式（scheme）、再实例化。所有操作
在互斥锁保护下是原子的，重放同一操作序列得到逐位相同的编号、绑定、层级
与模式环境。

## 数据模型

- 类型只有两种：`Var(id)` 与 `Con(名字, 参数...)`。构造子表在 `New` 时给定，
  参数个数必须等于其元数。
- 会话状态：当前层级 `L`（初值 0）、下一个变量编号（从 1 起，严格递增、无
  空洞）、每个变量的层级与绑定（初始未绑定）、模式环境（名字→模式，初始为空）。
- `NewVar()` 分配编号恰为“下一个编号”的变量，层级为当前 `L`；变量数已达
  上限 `V` 时拒绝。`Enter()`/`Leave()` 调整 `L`，分别以 1000 与 0 为界。

## Prune 与 Resolve

- Prune 沿绑定链走到未绑定变量或构造子应用。
- `Resolve(t)` 返回完全解析形式：所有已绑定变量递归替换为其绑定，得到只含
  未绑定变量与构造子的项。
- `Level(id)` 对 `Var(id)` Prune：落在未绑定变量时返回其层级；已绑定到构造
  子应用时以 `ErrVariableBound` 拒绝。

## 合一与层级调整

`Unify(a, b)` 先对两侧 Prune，然后递归：

1. 两侧是同一个未绑定变量：成功（同时把两条操作数可达绑定链上的层级重算为
   最小值，见下）。
2. 左侧未绑定变量 → 绑定到右侧；右侧未绑定而左侧是构造子时对称处理。
   - 右侧是变量：绑定后**右侧变量**（Prune 得到的未绑定根）的层级取两侧
     较小值；层级以“等价类”为准——通过变量绑定与该根相连的成员共享最小
     层级，因此最小值沿已有绑定链双向传播（未绑定变量的层级只会变小）。
   - 右侧是构造子应用：先做出现检查（沿已有绑定解析后，右侧内任意处出现左
     侧变量即 `ErrOccursCheck`）；通过后把右侧内每个层级高于左侧变量层级的
     未绑定变量降到左侧变量的层级（包含经绑定链到达的变量），再绑定。
3. 两侧都是构造子：名字不同 → `ErrConstructorMismatch`；名字相同则按参数
   从左到右逐对合一，后面的子项看得见前面子项已建立的绑定。

**原子性**：一次 `Unify` 是单一原子步骤。实现用写入日志（journal）记录本次
新增绑定与每一次层级变更的旧值；失败时逆序撤销，会话与调用前逐位相同。
参数在触碰状态前先完整校验（先左后右）。

## 泛化与值限制

`Bind(名字, 类型, expensive)`：

- 先取完全解析形式 `R`，收集 `R` 中层级**严格大于**当前 `L` 的未绑定变量，
  按它们在 `R` 中从左到右先序首次出现排序（重复只记一次）。
- `expensive == false`：这些变量被量化，按列表次序重编为 `G0, G1, ...`，
  与原变量解除关联（之后合一原变量不影响已存模式），原变量保持原状。
- `expensive == true`（值限制）：不量化，而是把这些变量（含指向它们的别名
  链上变量）的层级都降为 `L`，模式是无量化的 `R`，保留原变量共享。

## 实例化编号规则

`Lookup(名字)` 按量化次序为每个量化变量分配一个新变量：

- 新变量在当前 `L` 创建，编号连续递增；同一模式中量化变量共享同一新变量。
- 未量化部分原样保留，与原变量共享。
- 新变量会使总数超过 `V` 时拒绝（`ErrVariableLimit`）。

## 拒绝原因与优先级

所有错误都是可区分的哨兵值：

- 参数非法 `ErrInvalidArgument`（未登记构造子、元数不符、未知变量、空名字等）
 始终优先。
- `ErrLevelUnderflow`（L=0 时 Leave）、`ErrLevelLimit`（L=1000 时 Enter）、
  `ErrVariableLimit`、`ErrEnvironmentFull`（环境满 1000）。
- `Bind`：先重名 `ErrNameExists` 后容量；`Lookup`：先名字不存在
  `ErrNameNotFound` 后变量超限。
- 合一：`ErrOccursCheck` 与 `ErrConstructorMismatch`，按第一个遇到的失败返回。

被拒绝的操作不改变任何状态（编号、层级、绑定、环境）。

## 并发

会话内部用互斥锁串行化所有操作，结果等价于某个串行顺序；一次 `Unify`
是一个不可分割的原子步骤，观察者看不到中间的部分绑定或层级调整。

## 本地验证

```bash
# 全量测试（含 2000 组随机差分）
go test ./hm

# 详细输出，打印每组序列的输入、输出与判定依据
HM_VERBOSE=1 go test -v -run TestDifferentialRandom ./hm

# 固定随机种子复现
HM_SEED=12345 go test -v -run TestDifferentialRandom ./hm

# 竞态检测
go test -race ./hm

# 全仓
go test ./...
```

测试包含：

- 定向用例：变量-变量层级取小、构造子降层、右侧作为被绑定方、自合一、
  经绑定链的出现检查、失败回滚（绑定与层级）、参数从左到右、量化次序、
  层级边界、值限制、模式与原变量解除关联、实例编号连续、三个上限边界等。
- `TestDifferentialRandom`：2000 组随机操作序列，与 `naive_test.go` 中按规范
  逐步实现的朴素模拟器（显式替换映射、全量快照回滚、每次全量重算层级）逐
  步比对返回值与完整状态。
- `TestDeterministicReplay`：同序列两次重放，结果与状态逐字节相同。
- `TestConcurrentIsSerializable`：高并发下校验层级/编号/`L` 等不变量。
