# 学分替换与毕业审核引擎 — 设计说明

1. 模块划分：`model.go`（培养方案/要求树/错误）、`engine.go`（并发安全操作与校验）、
   `counting.go`（及格过滤、重修折叠、转入截断、替换身份）、`assign.go`（归入穷举与归因）、
   `audit.go`（总学分/GPA/未结清必修与结论组装）。
2. 要求树：叶子给可计入课程+最低学分+最低门数；内部节点给须满足子节点最少数（0/越界=全部）。
3. 版本：学生绑定入学版本；登记替换必须匹配当前绑定版本；`Migrate` 仅允许 order 更大的新版本，
   旧替换因版本不匹配自然失效。
4. 计入链（确定性、与登记顺序无关，转入登记次序除外）：撤销剔除 -> `score>=pass` ->
   转入按 transferOrder 贪心截断到上限 -> 原生课程按（最高分、最早学期、最早登记）取冠军 ->
   两阶段产生身份：仅冠军保留原生身份，所有候选可产生替换身份（学期>=生效期、版本匹配、
   学分取 min）-> 每个目标课程只保留最佳身份。
5. 归入：对“叶子×可用身份”做严格递增子集 DFS；记录默认叶子间互斥，仅 `SharedPairs`
   声明的叶子对可重复计入；叶子内同学分身份去重。状态按分支快照，回溯不会污染。
6. 通过判据：存在使根满足的归入即树通过；canonical 取按叶子编号满足向量字典序最大者。
7. 归因：不通过时在“所有归入下都不满足”的节点中取编号最小（含内部节点），
   缺口按对该节点最有利的归入计算：叶子给学分/门数缺口，内部给子节点缺口。
8. 附加条件：总学分（每条记录最佳可主张学分之和，只计一次）、按计入学分校权的 GPA、
   未结清必修（某课程在某种可行归入中进入必修叶子，且存在不及格修读且其后无及格修读）。
9. 错误固定优先级：参数非法>不存在>已撤销>替换不适用版本>转入超限>目标版本过旧；
   所有拒绝路径在写状态前返回，不改状态（有测试锁定）。
10. 并发：全局 RWMutex 管目录/方案/学生表；每学生独立 mutex，审核只取该学生锁与方案只读快照，
    不触达其他学生；测试以“占用全部无关学生锁仍可完成审核”证明代价不随无关学生增长。
11. 被放弃方案：贪心归入（无法保证“存在即通过”与确定性归因）、全局每课程单选项（会错误压制
    替换冠军）、LP/SAT（可复现性与归因解释差）。
12. 可复现性：所有集合排序后枚举，同分按学期再按登记序；仅转入登记次序是规则的一部分。
13. 朴素模型：`naive_test.go` 用位掩码独立重写计数与穷举，随机 400 例 x 多种子对照引擎结论、
    归因、总学分、GPA 与附加条件；`-v` 打印每步输入、输出与判定依据。
14. 本地验证：`GOCACHE=/tmp/gocache go test -race ./...`；随机种子用 `DIFF_SEED=<n>` 复现。
