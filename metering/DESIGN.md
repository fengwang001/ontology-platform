# 楼宇抄表记账与公摊分摊服务 — 设计说明

## 模块划分（metering 包，8 个 .go 文件）
- `types.go`：公开类型与八种错误码，声明顺序即固定报告优先级。
- `meter.go`：单表只追加读数序列（实抄/估抄/换表标记）、翻转判定、估抄替代。
- `usage.go`：区间用量；二分定位 + 线性归属（余数归较晚账期），big.Int 取整。
- `settle.go`：账期结算、在住权重、最大余数法精确分摊。
- `correction.go`：账期重算与链式更正生成。
- `service.go`：门面；互斥锁串行化、时钟、校验次序、性能计数。
- `metering_test.go` / `model_test.go`：定向测试与朴素模型差分对照。

## 关键取舍
- 读数序列只追加：新读数时刻须大于该表全部既有时刻；"录入更早时刻的实抄"
  指早于当前 now 而非早于末次读数。估抄被更晚实抄整段替代后重算。
- 翻转：后值小于前值且差额 ≤ 量程一半（按 2*diff <= range 判定）计一次翻转，
  用量 = (量程 - 前值) + 后值；超过一半报读数非法。
- 换表为序列中的标记：旧表结算至终读数、新表自起始读数起算，当刻不计用量；
  换表标记视同实抄基线。
- 应付口径：账单同时记录自用量（记账）与公摊分摊额，应付 = 公摊分摊额；
  由此任一账期各户更正之和恒等于该账期公摊重算前后之差。
- 更正基线为"最近一次已发出的重算视图"，多次更正取增量、不重复累计；
  更正只记差额，不改已结算账单。
- 分摊：权重 = 面积 × 在住时长（空置按账期全长），最大余数法 + big.Int
  精确取余，余数并列按户号升序，之和恒等于公摊；负公摊更正按对称规则分摊。
- 结算开销：二分定位 O(log n) 次比较，扫描只触碰账期涉及读数 O(k)；
  以 Stats.ScanEntries/SearchProbes 计数并由测试断言与历史总量无关。
- 并发：全局互斥锁，所有操作等价于某串行序；同表同时刻读数后者报乱序。

## 被放弃的方案
- 允许按时刻任意插入改写历史段：破坏只追加不变式，拒绝（报乱序）。
- 应付 = 自用 + 公摊：更正之和将等于总表差而非公摊差，违反要求，放弃。
- 浮点比例分摊：精度失守，改为 big.Int 有理数。
- 估抄替代后保留估抄作审计：序列多源难判定，更正日志即审计轨迹。

## 本地验证
- `go test ./metering/ -v`：定向用例（翻转半量程±1、换表当刻、边界读数、
  余数去向、估抄替代、在住精度、链式更正、负公摊拒绝、拒绝次序等）。
- `go test ./metering/ -run TestDifferentialRandom -v`：30 组种子 × 300 步
  随机操作与朴素模型逐步对照，日志含每步输入、输出与判定依据。
- `go test -race ./metering/`：并发串行化与同表同时刻读数唯一性。
