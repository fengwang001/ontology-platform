# fanout — 分片扇出查询与部分结果合并

`fanout.Execute` 把同一个聚合查询发往一组预先登记的分片，在**并发上限**与
**截止时间**内收集结果，并把成功分片合并为一个「既不夸大、也不漏报不确定性」
的答案。

## 输入与登记上界

每个分片登记两个非负整数上界：

- `MaxRows`：该分片匹配行数的上界；
- `MaxValue`：该分片任一取值的上界（取值均为非负整数）。

客户端通过 `ShardClient.Query(ctx, spec, agg, k, emit)` 上报结果；每个分片
只允许产出一次结果，多次 `emit` 的后到者被丢弃。

## 可信范围推导

记已收到分片的合并值为 `v`，缺失分片集合为 `M`：

- `R = Σ MaxRows`（缺失分片行数上界之和）
- `V = max MaxValue`（缺失分片取值上界中的最大者）

| 聚合 | 全部成功 | 有缺失 |
| --- | --- | --- |
| count（计数） | 精确点值 | 闭区间 `[v, v+R]` |
| sum（求和） | 精确点值 | 闭区间 `[v, v+R*V]`（乘积按 `uint64` 饱和） |
| min（最小值） | 精确点值 | 仅上端 `<= 已收到的最小值`；不存在可信的正向下界 |
| max（最大值） | 精确点值 | 下端 = 已收到的最大值，上端 = `max(已收到最大值, V)` |
| top_k（前 K 名） | 全部名次 `Certain=true` | 仅把取值**严格大于 `V`** 的前缀标为确定；等于 `V` 即不确定 |

理由要点：

- 缺失分片可能贡献 0 行，所以计数/求和的下端就是已收到部分之和；
- 缺失分片的最小取值可能比已见值更小，因此 min 不能给正向下界；
- 缺失分片的最大取值不会超过其登记上界，因此 max 上端可取上界；
- top-k 只有在任何缺失分片都不可能追平该名次时才确定，边界条件是
  **严格大于** `V`（取等则仍可能被并列/超越）。

**无任何分片成功时**答案为「无结论」：`Conclusive=false`，不带任何区间端点
或名次。

合并在单收集器内按值进行，分片结果以任意顺序到达都得到逐字段相同的答案
（top-k 以 `(value desc, key asc)` 稳定排序消歧）。

## 发前整体拒绝

下列情况在**任何请求发出之前**整体拒绝，返回 `*fanout.RejectError`，可用
其 `Kind` 字段区分原因：

| Kind | 触发条件 |
| --- | --- |
| `empty_shards` | 分片列表为空 |
| `duplicate_shard_name` | 分片名重复 |
| `invalid_k` | top-k 的 K 非正 |
| `invalid_concurrency` | 并发上限非正 |
| `invalid_deadline` | 截止时长非正 |
| `unknown_aggregation` | 聚合不在五种之内 |
| `nil_client` | 未提供 `ShardClient` |

## 故障分类（分别计数）

`Stats` 对四类情形分别计数；除成功外的所有分片都按**缺失**参与区间推导：

- `Failed`：`Query` 返回非空错误；
- `TimedOut`：截止时间（或父 context 取消）前未产出可用结果；
- `BoundViolation`：结果违反登记上界（count 超 `MaxRows`；sum 超
  `MaxRows*MaxValue`；min/max/top-k 值超 `MaxValue`）；
- `Duplicate`：同一分片第 2 次及以后的 `emit`，只取首个，其余丢弃。

另有 `PeakConcurrent` 报告执行期间同时在途请求数的峰值；该值保证不超过
`Concurrency`。

截止后迟到的结果被丢弃，既不改变已给出的答案，也不改变统计（重复 `emit`
仍计入 `Duplicate`）。

## 本地验证

```bash
go test ./fanout -v                 # 详细日志：输入 / 输出 / 判定依据
go test -race ./...                # 竞态检测
go test -cover ./fanout            # 覆盖率
go vet ./... && gofmt -l .         # 静态检查与格式
```

测试覆盖：五种聚合在缺失下的区间方向、top-k 确定前缀的严格大于边界（含
等值边界）、四类故障分别计数、峰值并发（并发上限 1/2/5）、截止与迟到结果
丢弃、任意到达顺序的逐字段一致性，以及全部拒绝原因与无结论情形。
