# rotation — 有序用电错避峰轮换调度器

`rotation` 包把“区域—轮换组—用户”的拓扑、带等级与窗口的限电指令、
逐时段公平选组、通知确认与单调时钟放进一个可确定重放的模型中。

## 核心概念

- **类别**：`Exempt`（免控，不限电、不通知）、`Reserved`（保底，限到保底功率，
  通知携带该功率）、`Normal`（限到零）。
- **时段**：每个区域固定 `slotLen`，时间为整数，指令窗口 `[start,end)` 必须
  对齐时段边界。
- **有效等级**：某时段的等级 = 覆盖该时段的所有未取消指令等级的最大值；
  无覆盖则为 0。
- **选组**：每时段按 `(累计被限时长升序, 组编号升序)` 取前 N 组（N=有效等级）。
- **边界两阶段**：时钟停在边界时该时段仍可被“恰在边界”的改级/取消修改；
  严格越过边界才冻结并对未确认通知记考核。时段内部的操作不影响该时段，
  自下一边界生效。
- **确认**：下一时段在开放时即预选并发通知，用户须在时段开始前确认；
  在开始时刻及之后确认返回 `RejectAfterDeadline`，开始时未确认记考核；
  改级撤组会撤回通知，撤回（含已确认）不计考核。

## 快速使用

```go
s := rotation.New(nil)                    // 可传入 rotation.Logger 打印每步依据
s.AddRegion("R", 10)                      // 10 分钟一个轮换时段
s.AddGroup("R", 1)
s.AddUser("u1", "R", 1, rotation.Reserved, 7)

id, _ := s.Issue("R", 1, 10, 30)         // 区域 R，[10,30)，等级 1
s.ChangeLevel(id, 2)                     // 视当前时刻在边界/槽内决定生效边界
s.Cancel(id)
s.Advance(30)                            // 逐边界结算，不跳过任何边界
s.Confirm("u1", "R")                     // 开始前确认成功；开始后为已过截止
```

## 错误类别（固定拒绝次序）

`RejectInvalid`（参数非法）> `RejectClockBack`（时钟回退）>
`RejectNoOrder`（指令不存在或已取消）> `RejectInSlot`（时段进行中）>
`RejectAfterDeadline`（已过截止）> `RejectNoNotice`（通知不存在）。
任何被拒绝的操作都不改变任何状态。

## 文件结构

- `model.go`：拓扑类型与错误类别。
- `orders.go`：指令生命周期、边界生效时间线、活跃指令集。
- `scheduler.go`：时钟、逐边界结算、选组与对账，操作串行化。
- `notify.go`：通知、确认、考核与只读查询。
- `DESIGN.md`：关键取舍、被放弃方案、性能与验证方式（40 行）。
- `*_test.go`：边界场景测试、朴素模型随机差分、并发与性能验证。

## 验证

```bash
go test -race -v ./rotation/
```

冻结时段选组、累计时长、被限组数不变量与公平性（最大-最小 ≤ 一个时段长度）；
不一致时日志逐条打印输入、输出及判定依据。
