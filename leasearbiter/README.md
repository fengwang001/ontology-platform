# 领导者读租约仲裁器（leasearbiter）

本包实现 Raft 风格的“领导者读租约”仲裁：领导者（节点 0）根据跟随者
对心跳的确认推算本地读租约，租约有效时直接本地读；租约缺失或失效时
退化为 ReadIndex 式的多数派确认；与多数派失去联系时自动降级。所有状态
由单一互斥锁保护，任何并发交错的结果都等价于某个串行顺序。

## 构造参数与状态

`New(n, dur, rho, et, start)`，参数越界（见下）整体拒绝，返回
`ErrInvalidConfig`：

- `n`：节点数，1–9；本节点是领导者 0，跟随者 1…n-1，`q = ⌊n/2⌋+1`。
- `dur`：租约时长，1–10^9。
- `rho`：允许的时钟漂移千分数，0–999。
- `et`：失联超时，`dur ≤ et ≤ 10^9`。
- `start`：起始时钟，0–10^15。

内部状态：每个跟随者的确认发送时刻 `ack[i]`（初为空）、投票静默截止
`pr[i]`（初 0）、挂起读队列、领导标志（初真）、时钟水位 `T = start`。

## 租约到期推导

有效租约窗口（漂移后保守缩短）：

```
W = ⌊Dur × (1000 - Rho) / 1000⌋
```

除法是整数向下取整，例如 `Dur=1001, Rho=1` 时
`⌊1001×999/1000⌋ = 999`。

- 租约基点 `base`：在**已有 ack 的跟随者**的 `ack`（心跳**发送**时刻
  `s`，不是接收时刻 `r`）中取第 `q-1` 大的值；不足 `q-1` 个跟随者有
  ack 时无租约。基点不含领导者自身。
- 到期时刻 `E = base + W`。
- `n=1` 时 `q-1=0`：`base` 取调用时的 `now`，因此每次 `Read` 都本地读，
  `E = now + W`。
- `Read(now)`：仅当存在租约且 **`now < E`（严格小于）** 时返回本地读与
  `E`；`now == E` 已算失效，进入挂起队列。

租约锚定发送时刻的含义：一个在 `s=100` 发送、`r=1900` 才收到的心跳，
租约仍是 `100+W`，而不是 `1900+W`——接收再晚也不能延长租约。

## Ack 与挂起读确认

`Ack(i, s, r)` 合法条件按“参数非法（`i∉[1,n-1]`、`s>r`、越界）→ 时钟
回退（`r<T`）”的顺序只报第一个错误：

1. `ack[i] = max(ack[i], s)`（较旧发送时刻不会使 ack 回退）；
2. `pr[i] = max(pr[i], r + Dur)`（静默截止按**接收**时刻加原始 `Dur`）；
3. `T = r`；
4. 按**到达顺序**检查挂起队列：当 `ack[f] >= a` 的跟随者数达到 `q-1`
   时确认该读并出队，遇到第一个不能确认的读立即停止；返回被确认读的
   编号序列。

注意确认依据是发送时刻 `s` 是否不小于读的到达时刻 `a`：较早发送的心跳
即使更晚到达也不能确认后来的读；边界 `s == a` 算确认。非导出计数器
`examined`（经 `Examined()` 读取）记录本次 Ack 实际检视的挂起读数，
因此恒有 `examined ≤ 确认数 + 1`（停在首个未确认读处）。

## ReadIndex 降级路径

`Read(now)` 校验顺序：参数非法（`now` 越界）→ 时钟回退（`now<T`）→
非领导者（`ErrNotLeader`）。租约不可用时，以 `a=now` 挂起，读编号从 1
起单调递增，返回 `Pending` 与编号；随后由 Ack 按上述规则确认。

## 降级条件（Tick）

`Tick(now)` 仅接受 `now ≥ T`。当同时满足：

1. 领导标志为真；
2. `now ≥ start + Et`（启动宽限期内绝不降级）；
3. 联系数 `c + 1 < q`，其中 `c` 为 `ack[f] >= now - Et` 的跟随者数；

则降级：领导标志置假，挂起读全部中止并按编号返回（空队列时返回空）。
边界 `ack == now-Et` 仍算联系。已降级后 `Tick` 幂等，`Ack` 仍被接受并
更新 `ack/pr/T`，但队列已空、不再确认任何读。

## 投票静默期与安全性

跟随者 `i` 每次确认后承诺静默到 `pr[i] = max(pr[i], r + Dur)`：在此之前
它不会给任何挑战者投票。`ChallengerVotes(now)`（只读）返回

```
#{f ≥ 1 : now ≥ pr[f]} + (领导标志为假 ? 1 : 0)
```

即静默已过期的跟随者数，加上降级后领导者自己的一票（从未联系的跟随者
`pr=0`，天然愿意投票）。

安全性论证：

- 本地读在 `now < base + W` 发生，其中 `base` 是第 `q-1` 大的 ack 发送
  时刻，故至少 `q-1` 个跟随者在 `base` 时仍认为旧领导者合法，其静默截止
  为 `r + Dur ≥ s + Dur ≥ base + Dur`。
- 由于漂移保守取 `W = ⌊Dur·(1000-Rho)/1000⌋ ≤ Dur`，本地读时刻
  `now < base + W ≤ base + Dur ≤ pr[f]`，这 `q-1` 个跟随者在 `now` 时都
  不会投挑战者。
- 于是挑战者至多得到 `n-1-(q-1) = n-q = ⌊N/2⌋` 票（领导者自己仍为领导，
  也不会投出自己的一票），严格小于多数派 `q`。因此租约内本地读与
  “挑战者当选”不可能同时成立。
- 降级条件独立兜底：`start+Et` 宽限期后，若加上领导者自身也凑不齐
  `q`（`c+1<q`），领导者主动退位，此后读一律走 `ErrNotLeader`/新领导者的
  ReadIndex。

随机差分测试对每个“本地读”时刻直接断言领导标志为真且
`ChallengerVotes(now) < q`。

## 错误与不可变性

- 配置错误：`ErrInvalidConfig`（仅构造时）。
- 操作错误依次为 `ErrInvalidArgs`、`ErrClockSkew`；`Read` 其后还有
  `ErrNotLeader`。
- 任何被拒绝的操作都不改变 `ack`、`pr`、挂起队列、领导标志与 `T`。
- 相同操作序列在全新实例上重放得到完全相同的本地/挂起结果、确认序列、
  中止序列与降级时刻。
