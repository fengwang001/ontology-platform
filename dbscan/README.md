# dbscan — 滑动窗口增量 DBSCAN 聚类服务

在二维整数点随插入、删除与时间过期持续变化时，维护每个点的核心 / 边界 /
噪声身份与确定的簇标签，并精确报告每次操作引起的标签变化（Changes）与
簇事件（Events）。所有方法可并发调用，效果等价于某个串行顺序。

## 定义

- **邻域 N(p)**：全部存活点中与 p 的距离平方 `dx²+dy² <= eps²` 的点
  （含 p 自己，恰等于 eps 算在内）。
- **核心点**：`|N(p)| >= minPts` 的点。
- **簇**：核心点在"互为邻域点"关系下的连通分量；簇标签取簇内核心点的
  最小编号。
- **边界点**：非核心点且邻域内存在核心点；其标签取邻域内核心点所属簇
  标签的最小者（与先后顺序、距离远近无关）。
- **噪声点**：邻域内没有核心点的非核心点，标签为 0。

标签只由当前存活点集合决定，与插入顺序及实现的增量路径无关：同一状态
下以任意顺序重新聚类得到的标签完全相同。

## 窗口与时钟

- 系统时钟 `now` 初值为 0，只前进。
- `Insert(id,x,y)` 以出生时刻 `now` 加入点。
- `Tick(t)` 把 `now` 推进到 `t`（`t == now` 允许，只做过期检查），并使
  所有满足 `出生时刻 + W <= now` 的点过期——存活当且仅当
  `now < 出生时刻 + W`（左闭右开）。
- `Remove(id)` 手动删除。过期或删除后 id 可被再次使用。

## 变化报告口径

- **Changes**：按编号升序的 `(编号, 旧标签, 新标签)`，包含全部前后标签
  不同的点；操作前不存在的点旧标签记 `-1`，操作后不存在的点新标签记
  `-1`。Tick 的报告是该次推进前后两个状态之差，与过期顺序无关。
- **Events**：把操作前后的簇看作二分图两侧，两个簇只要共有一个在操作
  前后都存活的核心点就连一条边，每个连通分量产生至多一个事件：
  Birth（只含新簇）、Death（只含旧簇）、Relabel（1 旧 1 新标签不同）、
  Merge（多旧 1 新）、Split（1 旧多新）、Reshape（多旧多新）；
  1 旧 1 新且标签相同（仅成员增减）不产生事件。事件按涉及的最小标签
  升序（相同最小标签时按旧、新标签列表字典序，保证确定性）。

## 错误

可区分的拒绝原因（`errors.Is` 判定）：`ErrInvalidParam`（构造参数越界、
id 非正、坐标越界、Tick 的 t 大于 10^15）、`ErrDuplicateID`、
`ErrCapacityFull`、`ErrNotFound`、`ErrClockBack`。Insert 按参数非法 →
点已存在 → 点数已满的顺序只报第一个；Tick 按参数非法 → 时钟回退的顺序。
被拒绝的操作不改变任何点、标签与时钟。

## 局部性

实现只维护受影响的区域：插入发出恰好 1 次 eps 邻域查询（网格索引），
删除与过期发出 0 次（邻接关系已缓存），重聚类只在受影响簇的核心点子图
上进行。非导出计数器 `rangeQueries` 记录邻域查询次数，测试证明：与改动
点相距超过 10×eps 的无关点从 1000 增加到约 100000 时，同一操作的
`rangeQueries` 完全相同。

## 接口

```go
d, err := dbscan.New(eps, minPts, window, capacity)
res, err := d.Insert(id, x, y)   // res.Changes / res.Events
res, err := d.Remove(id)
res, err := d.Tick(t)
label := d.Label(id)             // 不存在返回 -1
nb := d.Neighbors(id)            // 升序编号，含自身
clusters := d.Clusters()         // 按标签升序，不含噪声
n := d.Alive()
```
