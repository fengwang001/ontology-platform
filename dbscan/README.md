# dbscan — 滑动窗口增量 DBSCAN 聚类服务

包 `ontology/dbscan` 在二维整数点随**插入、手动删除、时间推进过期**持续变化时，
增量维护每个点的核心 / 边界 / 噪声身份与确定的簇标签，并报告每次操作引起的
标签变化（`Changes`）与簇事件（`Events`）。所有结果只由“当前存活点集合”决定，
与插入 / 过期顺序无关；同一操作序列任意顺序重放都得到完全相同的标签与报告。

## 构造参数

```go
svc, err := dbscan.New(eps int64, minPts int, W int64, C int)
```

- `eps`：邻域半径，`1 … 10^6`。
- `minPts`：邻域点数门槛，`1 … 1000`。
- `W`：存活窗口，`1 … 10^9`。
- `C`：存活点数上限，`1 … 100000`。

点：`id` 为正整数，在存活点中唯一（过期或删除后可复用）；坐标 `(x,y)` 各在
`-10^6 … 10^6`。系统时钟 `now` 初值 0，只前进。

## 定义

- **邻域** `N(p)`：全部**存活点**中与 `p` 的距离平方 `dx²+dy² ≤ eps²` 的点，
  含 `p` 自己；恰等算在内，差 1 不算。
- **核心点**：`|N(p)| ≥ minPts`。
- **簇**：核心点在“互为邻域点”（核心图相邻）关系下的连通分量；
  **簇标签取该簇内核心点的最小编号**。
- **边界点**：非核心点，但其邻域内存在核心点；标签取其邻域内核心点所属簇标签的
  最小者（与到达先后、远近无关，只看编号大小）。
- **噪声点**：非核心且邻域内无核心点，标签 `0`。

因此任意时刻：每个簇标签 = 其最小核心点编号；非核心点标签 = 邻域内核心簇标签的
最小者；噪声点没有核心邻居。

## 操作与窗口 / 时钟规则

- `Insert(id,x,y)`：以**当前 `now`** 为出生时刻加入点。校验顺序为
  参数非法（id 非正、坐标越界）→ 点已存在 → 点数已满（存活点数已等于 `C`），
  只报第一个原因。
- `Remove(id)`：手动删除存活点；id 非正为参数非法，未存活为“点不存在”。
- `Tick(t)`：把 `now` 推进到 `t`，并使所有满足 `born + W ≤ now` 的点过期。
  存活当且仅当 `now < born + W`（左闭右开）。`t` 上界 `10^15`；校验顺序为
  参数非法 → 时钟回退（`t < now`）；`t == now` 允许，只做一次过期检查。
- 被拒绝的操作不改变任何点、标签与时钟。

## 报告口径

每次**被接受**的操作返回：

- `Changes []Change`：按 id 升序的 `(id, 旧标签, 新标签)`，只含前后标签不同的点。
  操作前不存在的点旧标签记 `-1`；操作后不存在（删除 / 过期）的点新标签记 `-1`。
  `Tick` 的报告是推进前后两个状态之差，与过期先后无关；一次 Tick 同时过期多个点
  也只报一次、只含前后真正不同的标签。
- `Events []Event`：把操作前每个簇与操作后每个簇当作二部图两侧，两侧簇只要
  **共有一个操作前后都存活的核心点**就连一条边，每个连通分量产生至多一个事件：
  - 只含新簇：`Birth`（旧标签列表为空）
  - 只含旧簇：`Death`（新标签列表为空）
  - 1 旧 1 新且标签相同：无事件（成员增减不报）
  - 1 旧 1 新但标签不同：`Relabel`
  - 多旧 1 新：`Merge`
  - 1 旧多新：`Split`
  - 多旧多新：`Reshape`

  事件写作 `(类型, 旧标签升序, 新标签升序)`，并按事件涉及的最小标签升序输出。
  事件只由前后两个状态决定，与增量实现路径无关。

## 查询

- `Label(id) (label, ok)`；`Neighbors(id)` 返回升序编号；
  `Clusters()` 返回按标签升序的 `(标签, 成员升序)`，不含噪声；
  `Alive()` 返回存活点数；`Now()` 返回时钟。

所有操作与查询都可并发调用，结果等价于某个串行顺序，查询不会看到进行到一半的
重新聚类（服务内用互斥串行化状态变更）。

## 增量实现与局部性计数

- 边长为 `eps` 的空间网格：一次邻域查询只扫描 9 个格子，插入新点时发出
  **恰好一次** `rangeQuery` 建立双向邻接；删除 / 过期不再发查询。
- 非导出计数器 `RangeQueries()` 度量发出的邻域查询次数，可精确复现：
  - 插入一个与全部存活点相距 `> eps` 的点时恰为 `1`；
  - 没有点过期的 `Tick` 恰为 `0`；
  - 与改动点相距 `> 10·eps` 的无关点堆从 1000 增到接近 100000 时，
    同一局部操作的 `rangeQueries` 完全相同（局部更新而非整体重算）。
- 一次变更只重算“受影响集合”（插入 / 删除点的邻居闭包）内的核心身份、
  核心图连通分量与边界标签；簇事件由变更前后局部簇分量构造，但结果与整体
  重算的前后状态严格一致。

## 本地验证

```bash
# 全量测试（含 2000 组随机操作序列与朴素整体重算的对照）
go test ./...

# 详细日志：打印每组随机序列的输入、实际输出与判定依据（朴素整体重算结果）
go test -run TestRandomDifferential -v ./dbscan/

# 竞态检测（并发调用）
go test -race ./dbscan/

# 题目示例、距离/门槛边界、七类事件、rangeQueries 三项局部性
go test -run 'TestSpecExample|TestDistanceBoundary|TestBuildEventsSevenTypes|TestRangeQuery' -v ./dbscan/
```

`TestRandomDifferential` 用 2000 组随机 `Insert/Remove/Tick` 序列，在每次操作后
把增量服务与一个**整体重新聚类的朴素实现**逐点比对标签、邻域、簇、存活数、
拒绝原因与 `Events`；`-v` 日志打印每组序列的输入、输出与判定依据。
