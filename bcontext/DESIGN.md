# 跨源隔离与权限策略求值内核 — 设计说明
1. 模块划分：`types.go`（策略枚举、文档、日志）、`tree.go`（树节点与六类错误）、
2. `group.go`（开启者组边）、`isolation.go`（隔离与准入）、
3. `permissions.go`（能力逐项求值）、`kernel.go`（并发内核与对外操作）。
4. 取舍一：隔离状态在装载时计算并缓存为节点布尔值，查询 O(1)、与深度无关；
5. 导航后按新头重算一次，天然保证“装载时刻父链一致”，无需版本号或增量传播。
6. 取舍二：能力查询沿父链自顶向下单趟遍历，每层常数次来源匹配，O(深度)、
7. 与树总节点数无关；“父可用”以累计布尔量携带，避免重复递归。
8. 取舍三：嵌入允许列表在框架上可变，但每次装载复制快照供当前文档使用，
9. “修改只影响此后装载”与“导航不改父链和框架属性”由数据结构直接保证。
10. 取舍四：父导航不物理删除子树，而递归打 `detached` 标记；id 仍可查，
11. 查询返回“文档不存在”，上下文 id 永不复用，杜绝 ABA 式歧义。
12. 开启者组独立于树：边为两个方向的独立布尔量，开窗定初值，之后任一侧
13. 导航只做 true→false 收紧，单向断开且永不恢复。
14. 并发：单个 `sync.RWMutex`，每个公开操作是一个临界区，串行化即线性化；
15. 被拒操作在任何结构修改前完成校验，不留副作用（随机差分测试验证）。
16. 拒绝次序固定：参数非法→上下文不存在→文档不存在→嵌入策略不符→
17. 开启者组已断开→能力未知，各方法按此次序短路。
18. 来源匹配为字符串相等与 `*` 通配；不引入 URL 归一化，避免语义外推。
19. 被放弃一：每次查询全树重算（朴素）——能力查询 O(节点数)，不达标；
20. 保留为测试中的独立对照模型。
21. 被放弃二：隔离状态跨节点订阅/传播——子框架不影响祖先，传播无收益且
22. 破坏“装载时冻结”，故用装载期快照。
23. 被放弃三：物理删除被替换子树——无法区分两类“不存在”且 id 复用会让
24. 并发开窗引用错位，故用墓碑标记；每边单独加锁收益不明且易错，同样放弃。
25. 本地验证：
26. - `go test ./...` 功能覆盖；`go test -race ./...` 并发与竞争。
27. - `go test -run TestNaiveDifferential -v ./bcontext`：200+20 条随机序列
28.   与独立朴素模型逐项对照（错误类别与布尔输出完全一致）。
29. - 复杂度实测（可复现）：
30.   `go test -run=NONE -bench BenchmarkIsolated -benchtime=10000x ./bcontext`
31.   深度 8→4096、灌木 64→4096 时稳定 ~30–45 ns/op，证明 O(1)；
32.   `go test -run=NONE -bench BenchmarkEnabled -benchtime=10000x ./bcontext`
33.   同深度灌木 64→4096 耗时基本不变，深度 64→4096（64 倍）
34.   耗时 ~1.7µs→~146µs（近线性），证明 O(深度)。
35. - 日志：`NewKernel(..., NewLogger(w))` 传入任意 `io.Writer` 即得输入/
36.   输出/判定依据日志，见 `ExampleKernel`；默认 stderr，测试用 Discard。
37. 局限：来源按字符串比较，不做 scheme/port 归一化；能力集合静态注册。
