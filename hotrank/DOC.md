# hotrank — 实时热度排行榜

滑动窗口分桶计分，支持乱序/迟到事件、驻榜迟滞（hysteresis）、并列名次
以及相对上一榜的升降与掉榜对比。

## 构造

```go
b, err := hotrank.New(L, W, M, K, Hs)
```

| 参数 | 含义 | 范围 |
| --- | --- | --- |
| `L` | 桶长（时间单位） | 1..10^9 |
| `W` | 窗口桶数 | 1..1000 |
| `M` | 上榜门槛 | 1..10^12 |
| `K` | 榜单容量 | 1..100 |
| `Hs` | 迟滞次数 | 1..100 |

时间 `t`、`now` 为 `[0, 10^15]` 的 `int64`，桶号 `b = ⌊t/L⌋`。

## 窗口分桶与迟到规则

- 系统时钟 `c` 为所有已接受的 `Add` / `Snapshot` 见到的最大时刻（初值无）。
- 当前桶号 `cur = ⌊c/L⌋`；窗口为桶号区间 `(cur−W, cur]`。
- `Add(id, d, t)`：`d ∈ [1, 10^9]`。若 `t > c` 先推进 `c`；事件桶号
  `b ≤ cur−W` 则以 `ErrExpired` 拒绝（`cur` 取推进后、该 Add 时刻的值）。
  否则把 `d` 计入 `b` 桶——**允许迟到**，只要该桶仍在窗口内。
- `cur` 前进时，旧桶（`≤ cur−W`）自动退出窗口；实现用桶号最小堆只弹出
  真正离开的桶，`Add` 不遍历窗口内全部 `W` 个桶。
- `Score(id)` 只读，返回当前窗口得分。

## 资格线与迟滞

`Snapshot(now)`（`Peek` 同规则）先要求 `now ≥ c` 并推进 `c`，然后：

- 在上一榜中且迟滞计数 `hc < Hs` 的项，资格线为 `M − ⌊M/4⌋`；
  其他项（含不在上一榜、或 `hc ≥ Hs` 的项）资格线为 `M`。
- `hc` 是该项**连续以得分低于 M 留任**的已发布 Snapshot 次数：
  - 本次入榜且得分 `≥ M`：`hc = 0`（回升即清零）；
  - 本次入榜但得分 `< M`：`hc += 1`（新上榜者从 0 起算）；
  - 掉榜后其迟滞身份失效，再次上榜必须达到 `M`。
- 每次 `Snapshot` 都计一次，包括同一时刻重复调用；`Peek` 不计数。

## 排序、并列名次与截断

- 候选 = 窗口得分不低于自身资格线的项。
- 候选按得分降序、同分按 id 字节序升序排列。
- 取前 `K` 个入榜；名次在**全部候选**中按
  `名次 = 1 + 得分严格更高的候选数` 计算，即并列同名次
  （1、2、2、4……）。被 `K` 截掉的同分项不占已入榜项的名次。

## 变动与掉榜

- 入榜项：若在上一榜出现，`Change = 上一名次 − 本次名次`
  （正=上升，负=下降，0=不变）；否则 `New = true`（新上榜）。
- 上一榜有而本次未入榜（分数不够或被 `K` 截掉）的项进入 `Dropped`，
  记录上一名次，按上一名次升序（同名次按 id）排列。
- `Snapshot` 的结果成为新的上一榜；`Peek` 做完全相同的计算与时钟检查，
  但不推进 `c`、不改上一榜与 `hc`。

## 拒绝原因与优先级

只报第一个命中的原因，顺序如下；被拒操作不改变任何桶、`c` 与上一榜：

1. `ErrInvalidArgument`：构造参数越界、id 为空、`d/t/now` 越界；
2. `ErrExpired`：Add 的桶 `b ≤ cur−W`；
3. `ErrClockRewind`：Snapshot/Peek 的 `now < c`；
4. `ErrScoreOverflow`：按 `c` 推进后的窗口计算，某项得分超过 10^15。

## 并发与状态回收

- 所有操作经互斥串行化，对外等价于某个串行顺序；Snapshot 不会观察到
  计入一半的 Add。
- 任何时刻入榜项不超过 `K`；得分为零且不在上一榜的项会被回收，内部
  状态不随历史项数无限增长。
- 相同操作序列重放产生完全相同的榜单、名次、变动与掉榜清单。

## 本地验证

```bash
# 全量测试（含竞态检测）
go test -race ./...

# 仅本包 + 详细输出
go test -race -v ./hotrank

# 2000 组随机序列差分测试（对照朴素逐桶模拟）
go test -run TestRandomDifferential2000 -v ./hotrank
# 输入/输出/判定依据日志：/tmp/hotrank-diff.log

go vet ./...
gofmt -l .
```

> 若默认 `GOCACHE` 只读，可设置 `GOCACHE=/tmp/go-cache`。
