# 顺序预读窗口状态机（有限页缓存 + 抖动回退）

实现在 `ontology/readahead.go`，类型为 `ontology.Readahead`。它精确复现
Linux 风格的顺序预读窗口在有限缓存下的行为：按每次读请求判定顺序访问、
发起同步/异步预读、维护窗口与标记页、按 LRU 淘汰缓存，并在「预读页还没被
读到就被淘汰」（抖动）时收缩窗口。

## 构造

```go
r, err := ontology.NewReadahead(N, I, M, Cp)
```

- `N` 文件总页数，`I` 初始窗口，`M` 最大窗口，`Cp` 缓存容量（页）。
- 约束：`N>=1`、`I>=1`、`M>=I`、`Cp>=1`，任一不满足返回
  `ontology.ErrInvalidConfig`（可用 `errors.Is` 判断），整体拒绝。
- 初始：缓存为空（每页带 `pf`「预读未读」标记）；`prev=-1`；窗口
  `(ws,wsz)` 中 `wsz=0` 表示无窗口；无窗口时无标记页 `mk`。

## Read(p, n)

读闭开区间 `[p, p+n)`，返回三个**升序/淘汰序**的页列表：
需求读 `demand`、预读 `ahead`、被淘汰 `evicted`（按淘汰次序），以及错误。

### 顺序判定

`seq == (p == prev+1)`。首次读 `p=0` 时 `prev=-1`，故首次读第 0 页
天然视为顺序；首次从其它页开始则是随机访问。

`missing` 为请求页中**读之前**尚未缓存的页。所有窗口计算都以读之前的
`wsz` 为准。

### (1) 同步预读（`missing` 非空）

- `missing` 中所有页作为需求读发起。
- `seq` 为真：
  - 新窗口大小 `s = min(M, max(I, 2*wsz, n))`（`wsz` 取本次读之前的值）。
  - 预读起点 `rs = p+n`。
  - 若 `rs < N`：对 `[rs, min(rs+s, N))` 中读之前未缓存的页发起预读；
    窗口记为 `(rs, s)`，**`s` 不因被 `N` 截断而改变**；
    标记页 `mk = rs + floor(s/2)`（可能 `>= N`）。
  - 若 `rs >= N`：不预读，窗口清空。
- `seq` 为假（随机访问）：不预读，窗口清空。

### (2) 异步预读（全部命中）

仅当存在窗口（`wsz>0`）且标记页落在请求区间 `mk ∈ [p, p+n)` 时触发：

- `s = min(M, max(I, 2*wsz))`，起点 `rs = ws + wsz`。
- `rs < N`：预读 `[rs, min(rs+s, N))` 中未缓存页，窗口 `(rs, s)`，
  `mk = rs + floor(s/2)`。
- `rs >= N`：窗口清空。
- `mk` 不在请求区间内：什么都不做（窗口与缓存均不变）。

### (3) 缓存更新与抖动回退

顺序固定，确保结果可精确复现：

1. 按升序处理请求页：已缓存页移到最近使用并清除其 `pf`；需求读页以
   最近使用插入，`pf=false`。
2. 按升序把预读页以最近使用插入，`pf=true`。
3. 若缓存页数 `> Cp`，从**最久未用**者起逐页淘汰直到 `<= Cp`
   （可能淘汰本次刚读的页）。
4. 若被淘汰页中至少有一页 `pf=true`，且此刻 `wsz>0`，则
   `wsz = max(1, floor(wsz/2))`；`ws` 与 `mk` 保持不变。

### (4) 收尾与拒绝

- 最后 `prev = p+n-1`。
- 参数非法（`p<0` 或 `n<1`）返回 `ErrInvalidArg`；越界（`p+n>N`）
  返回 `ErrOutOfRange`。按此顺序只报第一个，可用 `errors.Is` 区分。
- 被拒绝的调用不改变缓存、LRU 次序、`pf`、`prev`、窗口与标记页。

## DropCache / State

- `DropCache()` 清空已缓存页集合（连同 LRU 与 `pf`），但保留 `prev`、
  窗口 `(ws,wsz)` 与标记页 `mk`。两次 `DropCache` 之间同一页被再次发起
  读之前必已被淘汰，因此再读必落入需求读。
- `State()` 返回 `prev`、窗口与标记页快照（`HasMk=false` 表示无标记）。

## 并发与不变量

`Read`、`DropCache`、`State` 由同一把互斥锁保护，可并发调用，结果等价于
某个串行顺序。实现保证：

- 任何时刻缓存页数 `<= Cp`；
- 需求读页与预读页互不相交且都在 `[0,N)` 内；
- `wsz <= M`；
- 相同读序列重放得到完全相同的需求读、预读、淘汰列表和状态。

## 规格示例

`N=100, I=2, M=8, Cp=4`：

- `Read(0,1)`：需求 `{0}`，`s=2`，预读 `{1,2}`，窗口 `(1,2)`，`mk=2`。
- `Read(1,1)`：全命中，`mk=2∉[1,2)`，无动作。
- `Read(2,1)`：全命中且 `mk=2` 在内，`s=4, rs=3`，预读 `{3,4,5,6}`，
  窗口 `(3,4)`，`mk=5`；缓存 7 页，淘汰 `[0,1,2]`（无 `pf` 页，不缩）。
- `Read(3,1)`、`Read(4,1)`：全命中，`mk=5` 不在内。
- `Read(5,1)`：`s=8, rs=7`，预读 `{7..14}`，窗口 `(7,8)`，`mk=11`；
  淘汰 `[6,3,4,5,7,8,9,10]`，其中 `6,7,8,9,10` 的 `pf` 为真（`3,4,5`
  已被读命中而清 `pf`），故 `wsz` 由 8 收缩为 4。最终 `prev=5`、
  窗口 `(7,4)`、`mk=11`。

该示例由 `TestSpecWorkedExample` 逐步断言。
