# 预付费电表账户与远程停送电控制器 — 设计说明

## 模块划分（5~9 个 .go 文件）
- `types.go`：金额/时刻类型、四态枚举、事件结构、错误哨兵（8 类）。
- `config.go`：配置校验；电价二分 `priceAt`；友好时段/节假日 O(1) 日历；周期锚定。
- `controller.go`：状态机核心——区间计费、一次性预警（滞回）、停电排入/执行、
  周期边界汇总、停电时长切分。
- `api.go`：对外操作（读数/应急/充值/确认/推进/参数变更）、互斥锁、拒绝次序、
  拒绝前投影校验（被拒操作不动时钟与状态）。
- `naive.go`：独立朴素模型：逐 tick 推进、电价线性查找，仅用于随机对照。
- `meter_test.go` / `extra_test.go`：题目列举的全部边界用例与拒绝次序、参数非法。
- `diff_test.go` / `bench_test.go`：400×120 步随机对照（逐条输入/输出/依据日志）、
  不变量、并发安全（-race）、历史/节假日无关性能基准。

## 关键取舍
- 时刻与电量均为离散整数；友好时段左闭右开；确认时限时刻确认仍有效，
  超时事件只在“严格推进越过时限”时由 Advance/后续操作触发。
- 首条读数只登记为计费基准，不产生扣费；区间 [prev,t) 用 prev 时刻电价。
- 扣费金额 `floor(电量Wh × 单价 / 1000)`；停电期间用电计入欠费、余额保持 0。
- 停电执行瞬间负余额一次性转欠费；待停电/待复电期间靠单一状态字段保证互斥。
- 开户余额视作首次入账计入充值总额，使资金恒等式自创建起成立。
- 所有公开方法用同一把互斥锁串行化，天然等价于某一串行顺序，可并发调用。

## 被放弃的方案
- 按事件堆调度：引入额外数据结构且可能随事件增长；改为直接从当前状态计算
  下一周期边界/停电时刻/确认时限，单操作 O(1)（电价二分 O(log n)）。
- 节假日用切片遍历：不满足 O(1)；改为 map[天]struct{} + 周末取模。
- 确认超时在“拒绝调用”时翻转状态：违反“被拒操作不改状态”；改为仅推进触发。

## 本地验证
```bash
go test ./...                 # 全部边界 + 随机对照 + 不变量
go test -race ./...           # 并发安全
go test -run XXX -bench . ./meter   # 历史/节假日规模无关
```
随机对照打印每条操作的输入、返回错误、事件与判定依据（状态/余额/欠费/周期）。
