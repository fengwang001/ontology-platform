# epoll：多实例共享文件状态就绪队列

`epoll.Poll` 在单进程内维护 `1..4` 个互相独立的 epoll 实例。所有实例共享同一份按文件编号索引的状态表，但每个实例拥有独立的监视项表与 FIFO 就绪链。全局锁使每个公开操作原子执行，因此并发调用等价于某个合法的串行顺序。

## 构造与限制

```go
p, err := epoll.New(W, E, U)
```

- `W`：每个实例的监视项上限，范围 `1..1_000_000`。
- `E`：实例数量，范围 `1..4`，实例编号为 `0..E-1`。
- `U`：所有实例监视项总数上限，范围 `1..1_000_000`。
- 任一构造参数越界都会整体拒绝，不创建任何状态。

错误值包括 `ErrInvalid`、`ErrExists`、`ErrNoSpace`、`ErrTooMany`、`ErrNoEnt`、`ErrExclChange`。各操作按规范规定的顺序只返回第一个错误；被拒绝的操作不修改监视项、文件状态或就绪链。

## 兴趣、事件与标志

事件位为：

- `IN = 1`
- `OUT = 2`
- `ERR = 4`
- `HUP = 8`

标志位为：

- `ET = 1`：边沿触发，只对本次新升起且与有效兴趣相交的位触发。
- `ONESHOT = 2`：成功交付一次后禁用，直到 `Mod` 重新武装。
- `EXCL = 4`：同一文件状态变化时，多个就绪的独占候选最多唤醒实例编号最小的一个。

监视项的有效兴趣恒为：

```text
eff = interest | ERR | HUP
```

因此即使 `interest == 0`，`ERR` 与 `HUP` 仍会在 `Wait` 中报告。`EXCL` 不能与 `ONESHOT` 同时使用；带 `EXCL` 时，原始 `interest` 不能显式包含 `ERR` 或 `HUP`，但有效兴趣仍自动包含二者。

## 入链规则

就绪链是每个实例内部的双向链表，同一监视项至多出现一次，内部 `queued` 标记与链成员关系始终一致。

- `Add(ep, fd, interest, flags)` 建立监视项后，若当前 `state[fd] & eff != 0`，立即追加到链尾；`ET` 与 `EXCL` 也适用，`Add` 不参与独占候选选择。
- `Mod(ep, fd, interest, flags)` 必须保持现有 `EXCL` 位不变；它整体替换兴趣和标志、清除 `disabled`，若当前就绪且尚未入链则追加到链尾，已在链中则保留原位置。
- `Del(ep, fd)` 删除监视项并在 O(1) 时间内从链中摘除，其他条目相对次序不变。

## SetState 与独占唤醒

`SetState(fd, m)` 原子执行：

1. 记录旧状态 `old`，写入新状态 `m`。
2. 按实例编号升序检查监视该文件的项，检查数量不超过 `E`。
3. 已禁用或已经在链中的项不参与本次触发。
4. 水平触发项在 `m & eff != 0` 时触发。
5. 边沿触发项在 `(m &^ old) & eff != 0` 时触发，即只有新升起的位有效。
6. 非独占候选立即追加到各自实例链尾。
7. 独占候选先暂存；全部检查结束后，只把实例编号最小的候选项追加到对应实例链尾。

状态清零不会主动摘除已经在链中的条目。这样的条目会保留到下一次 `Wait`，由重新求值决定是否作为过期条目丢弃。

## Wait、丢弃与回填

`Wait(ep, max)` 也是一个原子步骤：

1. 从该实例链首弹出条目，直到返回事件数达到 `max` 或链空。
2. 对每个弹出的条目计算 `revents = state[fd] & eff`。
3. `revents == 0` 的条目直接丢弃，不计入 `max`，也不回填。
4. `revents != 0` 时返回 `(fd, revents)`。
5. `ONESHOT` 项交付后设置 `disabled=true`，不回填。
6. 非 `ET` 项按返回次序记录，在全部弹出结束后按同一返回次序追加到链尾。
7. `ET` 项成功交付后不回填，等待后续新上升沿。

因此同一次 `Wait` 不会返回同一项两次；`max` 截断时，尚未弹出的旧链尾条目仍位于本次回填项之前。

## Close

`Close(fd)` 原子删除所有实例中以该文件为键的监视项，从各自就绪链摘除，将 `state[fd]` 置为 `0`，并返回删除数量。该操作只扫描该文件在 `byFile` 中的至多 `E` 个槽位，与全局监视项总数无关。对不存在或先前已关闭的文件返回 `0`。

## 查询

- `State(fd)`：返回共享状态；缺省为 `0`。
- `Queue(ep)`：按 FIFO 次序返回就绪链中的文件编号。
- `Watches(ep)`：按文件编号升序返回该实例全部监视项，包括 `Interest`、`Flags`、`Eff`、`Queued` 与 `Disabled`。

## 复杂度与计数器

- `Add`、`Mod`、`Del` 都是 O(1)；链中摘除通过双向链表指针完成。
- `SetState` 与 `Close` 只检查指定文件的至多 `E` 个监视项。
- `Wait` 只遍历实际弹出的链条目。非导出计数器 `examined` 按弹出条目递增，因此检查数量严格等于“返回事件数 + 过期丢弃数”，空闲队列上的 `Wait` 不会扫描任何监视项。
