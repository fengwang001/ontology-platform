# agg：两阶段本地→全局预聚合

`agg` 包把分批到达的行先在本地做部分聚合，再把部分聚合并入全局状态。
全局阶段**只**接收 `*Partial`，不接收原始行。

## 指标

每个组维护四个指标：

| 指标 | 存储方式 | 合并方式 |
| --- | --- | --- |
| 分组求和 `Sum` | 单组单个 `int64` | 各批 `SumDelta` 直接相加 |
| 计数 `Count` | 单组单个 `int64` | 各批 `CountDelta` 直接相加 |
| 平均值 `Avg` | **不存储**，查询时计算 | 必须先合并和与计数两项，再用 `Sum / Count` 相除，禁止跨批平均平均值 |
| 去重计数 `DistinctCount` | `map[value]现存行数` | **不可拆成标量**；按值下推净增减行数，合并后按值行数为 0 即删除该值，剩余不同值个数即去重计数 |

`Amount` 使用 `int64`：求和与计数在任意切批下都是整数精确运算，
平均值只在查询时做一次浮点除法，因此同一串行无论怎样切批，
`Sum`、`Count`、`Avg`、`DistinctCount` 都逐位一致、可复现。

## 本地阶段：`LocalAggregate(rows []Row) (*Partial, error)`

- 逐行扫描，按组累加：
  - `add`：`SumDelta += Amount`、`CountDelta += 1`、`ValueDeltas[Value] += 1`；
  - `withdraw`：对应三项取负。
- 本地阶段是可交换的净增减计算，**不**判断撤回的行是否存在
  （存在性只能由持有全局状态的一方判断，否则 `add` 与 `withdraw`
  被切到不同批次时会被误拒）。
- 本地仅做两类校验：非法操作、空组名。任一行失败则整批拒绝、不产出部分聚合。
- **全零组不发送**：某组 `SumDelta == 0 && CountDelta == 0`
  且所有值净增减均为 0（如批内 add/withdraw 完全对冲）时，
  该组不进入 `Partial`；非全零组中净增减为 0 的单个值条目也会被剔除。

## 全局阶段：`New(maxGroups)` / `(*Global).Submit(*Partial)`

1. **先投影后提交**：以当前状态为底复制出投影，对每个部分组
   累加和与计数，并把 `ValueDeltas` 下推到值→行数映射。
2. 任一校验失败立即返回，投影被丢弃，**全局状态与已发送计数均不变**（失败不留痕）。
3. 某值合并后行数为负 → `ErrWithdrawBeforeAdd`；行数归零 → 删除该值。
4. 组计数归零 → 整个组（连同值映射）从结果删除；之后该组可被重新创建，旧值不残留。
5. 删除归零组后统计存活组数，超过 `maxGroups` → `ErrTooManyGroups`。
6. 全部合法才用投影替换状态，并累加已接收提交数与已接收部分组数。

查询：`Results()` 返回按组名排序的快照，`Avg = float64(Sum)/float64(Count)`。
`AcceptedSubmits()` 与 `SentPartialGroups()` 可观察已发送计数，被拒提交不计数。

## 并发

`Global` 内部使用 `sync.RWMutex`：`Submit` 持写锁（投影+提交为原子区间），
`Results` 及计数读取持读锁。多个执行体可并发提交与查询，
建议以 `go test -race` 验证。

## 边界与错误类别

四类错误互不相同（哨兵错误，用 `errors.Is` 判定），按以下优先级返回：

| 错误 | 触发条件 |
| --- | --- |
| `ErrInvalidOperation` | 行操作不是 `add`/`withdraw`；或部分聚合携带值净增减为 0 的非法载荷条目 |
| `ErrEmptyGroup` | 行或部分聚合中的组名为空或全空白 |
| `ErrWithdrawBeforeAdd` | 合并后某值行数为负，或组计数为负（撤回不存在的行 / 撤回超量） |
| `ErrTooManyGroups` | 合并并删除归零组后，存活组数超过上限 |

其他边界：

- `nil` 部分聚合与无任何组的部分聚合视为空批，正常接受、不改变状态。
- 任何拒绝都是**整批拒绝**：即使部分组合法，也不会部分生效。
- 组数上限在删除归零组之后判定，因此删除组会释放名额、允许重建。

## 日志

本地与全局阶段均通过标准 `log` 包打印：

- 每批输入行；
- 产出的部分聚合（组、和增量、计数增量、按值净增减映射，键按字典序输出）；
- 接受/拒绝判定及具体依据（含现存行数、净增减、合并结果、上限等）。

## 本地验证

```bash
# 常规测试
go test ./...

# 竞态检测 + 详细日志（可看到每批输入、部分聚合与判定依据）
go test -race -v ./agg

# 覆盖率
go test -cover ./...

go vet ./...
gofmt -l .
```

测试覆盖：四指标的分批正确合并、全零组过滤、按值去重计数维护、
组计数归零删除后重建、四类非法输入及拒绝后状态/已发送计数不变、
组数超限的整体拒绝、固定切点与 100 组随机切点下与整批重算
（`referenceRecompute`）逐位一致，以及 32 执行体并发提交/查询。
