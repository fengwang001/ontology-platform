# numalock：NUMA 感知的相位公平读写组队锁

`numalock.Lock` 是一个可精确复现的相位公平（phase-fair）读写锁：

- **读者成批进入**：读相位中，只要没有写者等待，新读者直接随当前读批进入；一旦有写者等待，新读者进入全局读等待队列 `Qr`，等当前写阶段结束后整批授予。
- **写者按 NUMA 节点组队**：每个节点有独立的写等待队列 `Qw[n]`，另有节点轮转队列 `G`。写相位中，持有者所在节点（`gown`）不占 `G`，其队列是“本地队列”；其余非空节点按 FIFO 排在 `G` 中。
- **本地传递次数受限**：写者解锁时若本地队列仍有人，且 `p < B`（或 `G` 为空），直接本地交接并 `p++`；达到上限后 `gown` 追加回 `G` 尾，交给队首节点，跨节点公平得到保证。
- **写锁降级 / 读者升级**：`Downgrade` 把写持有转成读持有并一并授予 `Qr`；`Upgrade` 仅在读集合恰为 `{t}` 时成功，成为写者并把自己的节点从 `G` 移出（其 `Qw` 保留为本地队列）。
- **可撤销**：`Cancel` 可撤销读/写等待；撤销使节点写队列为空时该节点离开 `G`；读相位中最后一个写等待者被撤销时，`Qr` 全体立即并入读集合。

## 相位与全局状态

相位只有空闲 / 读 / 写三种：

- 写相位 ⇔ 写持有者 `w` 非空且读集合 `R` 为空；
- 读相位 ⇔ `R` 非空；
- 空闲 ⇔ `R`、`w`、`Qr`、所有 `Qw[n]`、`G` 全为空。

不变量（测试逐条校验）：

- `G` 无重复；写相位中恰含“除 `gown` 外所有非空 `Qw` 节点”，其他相位恰含全部非空 `Qw` 节点。
- `Qr` 非空 ⇒ 处于写相位，或处于读相位且存在写者等待。
- 每个读等待者必在其入队后的第一个写阶段结束（`WUnlock` / `Downgrade`）或写者全部撤销时被授予。
- 连续本地传递不超过 `B` 次；`G` 为空时本地传递不受 `B` 限制（此时不可能有跨节点饥饿）。

## 调用语义与拒绝顺序

| 调用 | 授予 / 排队 | 要求状态 |
| --- | --- | --- |
| `RLock(t)` | 空闲授予；读相位且无写者等待授予；否则入 `Qr` | 空闲 |
| `RUnlock(t)` | 离开 `R`；`R` 空则结束读相位并“起写” | 读持有 |
| `WLock(t)` | 空闲授予（`gown=nodeOf[t], p=0`）；否则入 `Qw[node]`，必要时节点入 `G` 尾 | 空闲 |
| `WUnlock(t)` | ① `Qr` 非空先授读批；② 本地传递（`p<B` 或 `G` 空）；③ `gown` 重入 `G` 尾后起写 | 写持有 |
| `Downgrade(t)` | 转读持有，`R = [t] + Qr`，必要时 `gown` 入 `G` 尾 | 写持有 |
| `Upgrade(t)` | 仅当 `R == {t}`：转写持有，节点移出 `G`，`p=0` | 读持有 |
| `Cancel(t)` | 从 `Qr` / `Qw[node]` 移除；节点清空则移出 `G`；最后写者撤销时放行读者 | 读等待 / 写等待 |

拒绝原因按以下顺序只报第一个，且被拒绝的调用不改变任何状态：

1. 线程号越界；
2. 状态不符；
3. 仅 `Upgrade`：`R` 不恰为 `{t}`（升级冲突）。

构造参数 `M ∈ [1,8]`、`T ∈ [1,32]`、`B ∈ [1,16]`、`len(nodeOf)==T` 且每项属于 `[0,M-1]`；任一不合法则整体拒绝（`ErrBadConfig`）。

`Result.Granted` 返回本次调用授予的线程集合（`WLock`/`RLock` 的直接授予、读批授予、本地/跨节点交接、降级、撤销放行），`Result.Reason` 给出判定依据；`Snapshot()` 返回相位、`R`、`w`、`gown`、`p`、`Qr`、全部 `Qw`、`G` 与每线程状态的深拷贝。相同调用序列重放得到完全相同的授予集合与队列。

## 复杂度

全部队列（`Qr`、每个 `Qw[n]`、`G`）均为以线程号/节点号索引的侵入式双向链表：入队、队首出队、按线程撤销均为常数次链接操作。每次调用触及的队列操作数为 **常数 + 本次授予人数**。

## 本地验证

```bash
# 全量测试（含 2000 组随机序列与朴素模拟对照、并发竞态）
GOCACHE=/tmp/gocache go test -race -v ./numalock/

# 仅跑随机对照 / 规格示例
GOCACHE=/tmp/gocache go test -run TestRandomDifferential -v ./numalock/
GOCACHE=/tmp/gocache go test -run TestSpecExample -v ./numalock/

go vet ./...
```

测试说明：

- `naive_test.go` 是严格按规则文字逐步抄写的朴素参考模型（切片队列）。
- `TestRandomDifferential` 生成 2000 组随机配置（`M/T/B/nodeOf`）与 20–79 个随机调用，每步都对比真实锁与朴素模型的 `OK`、授予集合与完整快照，并校验全部不变量；`-v` 日志打印每组输入、两侧输出与判定依据。
- `TestSpecExample` 复现题目给出的完整交接示例；`TestScenario*` 覆盖：读者因写者等待而排队、`p` 恰等于 `B` 与小于 `B`、`G` 空时不受 `B` 限制、读者先于本地传递、`gown` 重入 `G` 尾的位置、降级授予 `Qr`、唯一读者升级并移出 `G`、撤销最后写者放行读者、节点移出 `G` 后重新排尾。
- `TestReplayDeterminism` 用同一调用序列重放两次，逐拍比较快照；`TestConcurrentRace` 在 `-race` 下并发敲击全部操作并最终排空到空闲。
