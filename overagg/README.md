# overagg：事件时间 OVER 范围聚合器

`overagg` 按水位线推进把缓冲的行按事件时间顺序释放，并为每个释放的
行输出其所属键在范围帧 `[ts-R, ts]` 内的求和、计数与最大值。构造参数：
范围宽度 `R ∈ [0, 1e15]`、允许迟到 `AL ∈ [0, 1e15]`、缓冲容量
`Cap ∈ [1, 1e6]`。状态为水位线 `wm`（初值 −1）、缓冲、已释放行集合与
全局到达序号 `seq`（初值 0）。

## Insert 的判定顺序

`Insert(键, ts, val)` 按以下顺序判定，只落一类，被拒绝（参数非法、缓冲
已满）的操作不改变水位线、缓冲、已释放行、`seq` 与迟到、补发计数：

1. **参数非法**：键为空、`ts ∉ [0, 1e15]` 或 `val ∉ [-1e9, 1e9]`，整体拒绝。
2. **丢弃**：`ts ≤ wm − AL`。迟到计数加一，其余状态不变。`AL=0` 时
   `ts == wm` 也丢弃——该时间戳的行已在水位线推进时释放过。
3. **补发**：`wm − AL < ts ≤ wm`。立即用当时的保留行求帧
   `[ts−R, ts]`（含此前的补发行），加上本行后输出
   `(键, ts, val, sum, cnt, max)`；本行并入已释放行。不占缓冲、不占
   序号、不受 Cap 限制，且不更正此前已输出的任何行。
4. **缓冲已满**：`ts > wm` 且缓冲行数已达 `Cap`，拒绝。丢弃行与补发行
   永远先于此判定，因此缓冲已满时它们不受影响。
5. **入缓冲**：分配 `seq`（预增，首行为 1），等待释放。

## 释放次序与范围帧口径

`Advance(w)`：`w` 越界报参数非法，`w < wm` 报水位线回退（只报第一个原
因），`w == wm` 是空操作。否则取出缓冲中 `ts ≤ w` 的全部行，按
`(ts, seq)` 升序释放：

- 每行的帧是同键已释放行（含本次 Advance 已释放的、含本行以及与本行
  时间戳相同的**全部并列行**，无论并列行在输出次序上的先后）中满足
  `ts−R ≤ ts′ ≤ ts` 者。因此同键同 ts 的并列行输出的
  `sum/cnt/max` 完全相同；`R=0` 时帧只含并列行。
- 同一次 Advance 内较早时间戳的行先释放，进入较晚时间戳行的帧；跨键
  并列按 `seq` 排序，各键的帧互不混入。
- 全部输出产生之后令 `wm = w`，再清理已释放行。Advance 是原子步骤，
  任何观察者看不到只释放了一部分行的中间状态。

## 清理边界 w−R−AL 的推导

Advance 到 `w` 之后，任何被接受的行都满足 `ts > w − AL`（更早的会被丢
弃）。其帧下界为 `ts − R > w − AL − R`。因此 `ts′ ≤ w − R − AL` 的已释
放行不可能再出现在任何未来帧中（无论是 Advance 释放的帧还是补发的
帧），可以安全清理。`Retained()` 返回清理后保留的已释放行数。边界是
闭的：`ts′ == w − R − AL` 被清理，`ts′ == w − R − AL + 1` 保留（`AL=0`
时即 `w − R`）。

## 增量维护与撤回

每个键的保留行按时间戳合并为有序桶（每桶存 `sum/cnt/max`）：

- **Advance 路径**维护一个滑动窗口累加器，覆盖 `[curHi−R, curHi]`：
  帧前移时，下界之外的桶整体离开（`sum/cnt` 做减法撤回），新进入的
  桶整体加入；最大值用懒删除最大堆维护，桶离窗或桶最大值被补发改写
  后旧堆项失效，在查询时弹出。每行至多进入、离开累加器各一次，堆入
  队、出队各一次，故 `frameWork ≤ 4 × 已释放行累计数`，与 `R` 及帧内
  行数无关。
- **补发路径**直接在桶序列上二分定位帧下界、向后扫描到帧上界，只访
  问帧内（加一个终止）桶，故每次补发的 `lateWork` 不超过帧内不同时
  间戳个数加 2，与保留行总数及帧外行数无关。
- **清理**按 `w − R − AL` 截断桶序列前缀；仍在窗口内的桶先从累加器
  撤回再删除，窗口指针随之前移。

## 并发与可复现性

所有方法在同一把互斥锁下线性化：并发调用的结果等价于某个串行顺序；
`wm` 单调不减；任一时刻缓冲行数不超过 `Cap`；每个键任一时刻的帧内聚
合等于对其保留行重新扫描所得；相同操作序列重放得到完全相同的输出、
`wm`、缓冲、`Retained` 与迟到计数。
