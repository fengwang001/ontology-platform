# scoreboard：基于选择确认的发送端记分板

序号为字节偏移，从 0 起。构造参数：

- `M`：最大段长（发送长度必须在 `[1, M]`）；
- `D`：判丢阈值（`D >= 2`）；
- `W`：在途上限（`W >= M`）。

## API

```go
sb, err := scoreboard.New(M, D, W, logWriter) // 构造；logWriter 为 nil 时丢弃日志
start, err := sb.Send(length)                 // 按序追加段，返回起点
err = sb.Acknowledge(c, []Block{{a, b}, ...}) // 累计点 c + SACK 半开区间块
start, err := sb.Retransmit()                 // 重传起点最小的丢失段
inFlight := sb.InFlight()                     // 查询在途字节（按定义重算）
```

## 记录模型

- 段按发送顺序追加，段边界 = 某段起点或已发送末端；
- 确认块为半开区间 `[Start, End)`，可重叠或相邻，统一取并集记录（相邻合并）；
- 累计点 `c` 表示小于 `c` 的字节全部收到；累计点推进时清除被越过的 SACK 记录，
  仅部分越过的旧记录在边界 `c` 处截断（起点恰为 `c` 的记录保留）。

## 判丢条件

对一个**未确认且未被选择确认覆盖**的段，考察**高于它**（区间起点 `>= 该段终点`）
的已选择确认并集区间，当且仅当满足以下任一条件时判丢失：

1. 其中不相交的连续片段数不少于 `D` 个；或
2. 其中已选择确认字节数不少于 `(D-1) * M`。

两个条件相互独立，满足其一即可（例如 `D` 个小片段但总字节不足，或
`1` 个大区间但字节达到阈值，都会判丢）。

## 在途字节

在途字节是**全部未确认且未被选择确认覆盖的段**中，满足「未判丢失 **或** 已重传」
者的长度之和。即：判丢后该段立即移出在途，重传成功后重新计入在途。

重传规则：取起点最小的「已判丢失且未重传」段；仅当
`在途字节 + 该段长度 <= W` 时允许，成功后标记已重传。无可重传段的拒绝
（`ErrNothingToRetransmit`）先于在途已满（`ErrWindowFull`），二者可区分。

## 拒绝规则（均整体生效，被拒绝不改变任何状态）

- 构造：`M <= 0` → `ErrInvalidM`；`D < 2` → `ErrInvalidD`；`W < M` → `ErrInvalidW`。
- 发送：长度不在 `[1, M]` → `ErrInvalidLength`。
- 确认，按顺序只报第一个：
  1. 累计点小于已收到的最大累计点 → `ErrCumulativeRevert`；
  2. 累计点大于已发送末端 → `ErrCumulativeTooFar`；
  3. 累计点不在段边界 → `ErrCumulativeBoundary`；
  4. 无块 → `ErrNoBlocks`；
  5. 块按给出顺序逐块检查：空或倒置 → `ErrBlockReversed`；
     起点不大于累计点 → `ErrBlockStartAtCum`；终点大于已发送末端 → `ErrBlockEndTooFar`；
     任一端点不在段边界 → `ErrBlockBoundary`。

## 并发与确定性

所有操作经同一把互斥锁串行化，校验与状态应用在同一次临界区内完成，因此
`InFlight()` 在任何调用交错时刻都等于按上述定义即时重算的值；操作无随机因素，
相同调用序列（含拒绝顺序）重放到新实例，最终状态与各操作结果完全相同。

每次操作都会在日志中打印输入、输出/拒绝原因；确认后逐段打印判丢依据
（高于它的片段数与字节数、阈值、是否丢失、是否已重传）。

## 本地验证

```bash
# 全量测试（带日志输入/输出与判定依据）
go test -v ./scoreboard

# 竞态检测 + 重复运行
go test -race -count=5 ./scoreboard

# 全仓库
go test -race ./...

# 格式与静态检查
gofmt -l .
go vet ./...
```

主要测试覆盖：恰好 `D` 个片段与恰好 `(D-1)*M` 字节的判丢边界（差 1 不判丢）、
两个条件各自单独成立、重传前后在途变化、在途恰好放下（`+1` 拒绝）、
累计点吞并/截断 SACK 记录、相邻与重叠块取并集、全部非法输入的拒绝顺序与
整体生效性，以及并发不变量巡检与线性化顺序重放。
