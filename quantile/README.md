# quantile — 有界质心近似分位数维护器

`quantile.Maintainer` 用不超过预算个数的**质心（centroid）**近似一批数值的分位数，
同时保留真实值多重集合，使撤回可从真实数据完整重算、误差可用精确值复核。

## 数据结构

- 质心 `Centroid`：`Mean()` 为所代表数值的算术均值，`Weight()` 为所代表数值的个数。
- 质心列表恒按均值升序排列；所有质心权重之和恒等于 `Count()`，也恒等于真实集合的元素总数。
- 真实集合以 `map[float64]int64`（值 → 出现次数）保存，只用于撤回重算与误差审计，
  不参与日常查询。

## 插入与质心合并

1. `Add(v)` 把 `v` 作为权重 1、均值 `v` 的新质心，按均值升序插入列表（相等均值先并列保留）。
2. 当质心数超过预算 `budget`（必须为正整数）时反复压缩，直到不超过预算：
   - 计算每对相邻质心的权重和 `w[i] + w[i+1]`；
   - 选择权重和**最小**的一对；权重和相同取**最靠左**的一对（确定性打破平局）；
   - 合并为一个质心，权重取两者权重之和，均值取加权平均
     `(m1*w1 + m2*w2) / (w1+w2)`。
3. 加权平均恒介于两个原均值之间，因此合并后列表仍然升序，无需重新排序。

## 分位点查询与线性插值

设总数为 `N`，质心依次为 `c0, c1, ...`，累计权重前缀和为 `S_i`。

- 目标秩 `r = q * (N-1)`（`q ∈ [0,1]`，即 q=0 对齐最小端、q=1 对齐最大端）。
- 每个质心的锚点秩为其代表秩区间的中点：`a_i = S_{i-1} + (w_i-1)/2`。
- `r` 落在某锚点上（含 q=0/q=1 的端点钳制）时直接返回该质心均值；
- `r` 落在相邻两锚点之间时，在两质心均值之间做线性插值：
  `q̂ = m_{i-1} + (r-a_{i-1})/(a_i-a_{i-1}) * (m_i-m_{i-1})`。

查询为纯读操作，多 goroutine 并发调用 `Quantile` / `Count` / `Check` / `Centroids`
使用同一把 `sync.RWMutex` 的读锁；运算全部基于整数权重与确定顺序的浮点运算，
因此同一实例的并发分位数结果逐位相同。

## 合并另一个实例

`Merge(other)`：

1. 在读锁下复制 `other` 的全部质心与真实计数（被合并方**不发生任何改变**）；
2. 把两份质心按均值归并（均值相同的先合一），再按上面的合并规则压缩到接收方预算；
3. 真实计数按值相加；合并后总数严格等于两实例计数之和。

`Merge(nil)` 返回 `ErrNilMaintainer`；把实例合并进自身是空操作。

## 撤回与从真实集合重算

`Retract(v)` 必须整体校验、整体生效：

1. `v` 为 NaN/±Inf → 返回 `ErrInvalidValue`；真实集合中不存在该值 → 返回 `ErrValueNotFound`。
2. 校验通过后，先在临时副本上从剩余真实集合重建：去重值升序排列，每个值生成
   `(均值=该值, 权重=出现次数)` 的质心，再按同样的最小相邻权重和规则压缩。
3. 只有重建完成后才一次性替换质心列表、真实集合与计数。任何一步失败都不会改变
   质心、真实集合与计数（失败原子性）。

撤回到空集合后，查询返回 `ErrEmpty`。

## 可区分的拒绝原因

| 错误哨兵 | 触发场景 |
| --- | --- |
| `ErrInvalidBudget` | `New(budget)` 预算 ≤ 0 |
| `ErrEmpty` | 空实例上查询分位数 |
| `ErrInvalidQ` | 分位点为 NaN 或不在 `[0,1]` |
| `ErrValueNotFound` | 撤回一个从未观测到的值 |
| `ErrInvalidValue` | 插入/撤回的值为 NaN 或 ±Inf |
| `ErrNilMaintainer` | `Merge(nil)` |

均可用 `errors.Is` 精确区分；非法操作在校验阶段即返回，状态保持不变。

`Check()` 自检不变量：质心数不超预算、权重为正、均值有限且升序、质心权重和、
真实集合总数与 `Count()` 三者一致、加权均值和与真实值加权和一致（浮点容差）。

## 误差上界与本地精确核对

估计值在相邻质心锚点之间插值，锚点与目标秩的秩偏差不超过约一个最大质心权重
`wmax`；由于估计点可能跨过相邻质心取值，**秩质量（CDF mass）偏差的安全包络**为

```
| F(x̂) - q | <= 2 * wmax / N
```

其中 `F(x̂)` 是真实集合中小于等于估计值的元素占比。该界只依赖可直接观测的
`wmax` 与 `N`，不依赖任何分布假设；预算越大，`wmax` 越小，界越紧。

用保留的真实集合在本地精确核对（无需外部数据或依赖）：

```bash
# 竞态检测 + 详细日志（日志含操作、质心列表、总数与判定依据）
go test -race -v ./quantile/

# 只跑精确误差上界审计
go test -run TestErrorBoundAgainstExactQuantiles -v ./quantile/
```

`TestErrorBoundAgainstExactQuantiles` 构造 50000 个确定性伪随机值，同时维护近似
维护器与排序后的精确数组，对 201 个分位点逐一计算精确 CDF 质量并断言其与 `q`
的偏差不超过 `2*wmax/N`，日志打印实测最差偏差、上界与 `wmax`；另对 0.1/0.5/0.9
与精确最近秩分位数做值域包络核对。
