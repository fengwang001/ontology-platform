# 动态最小生成森林

`dynamicforest` 在无向带权多重图上维护按边键 `(weight, id)` 全序唯一确定的最小生成森林。

## 顺序与唯一性

- 边先比较整数权重；权重相同则比较编号，编号小者更小。
- 任意两条存活边的键不同，因此对同一图按 `(weight, id)` 升序执行 Kruskal 会得到唯一森林。
- 平行边与普通边使用相同规则，不会被特殊合并。

## 更新与报告

- `AddEdge`：若新边连接两个森林分量，直接进入；若成环，则仅当新边小于森林路径上的最大边时替换该最大边。
- `SetWeight`：非森林边按更新后的键与路径最大边比较；森林边增权时暂时断开并在跨越该割的存活边中选择最小者，候选可以是其他边、平行边或该边自己。
- `RemoveEdge`：删除非森林边不改变森林；删除森林边时选择最小跨割边，若不存在则连通分量数加一。
- `Entered` 与 `Left` 升序排列；没有变化时为空切片。被删除且原本在森林中的边出现在 `Left`。
- 每次被接受的更新（包括把权重设置为原值）都使版本号加一；被拒绝的操作不消耗编号、不升版本且不改变历史。

## 入森林历史

`TreeSince(id)` 返回该边最近一次进入森林时的版本号：

- 持续在森林中时，改权重不会重置；
- 森林边增权后仍由自己作为最小跨割候选时，也不重置；
- 当前不在森林、编号从未分配或边已删除时按相应语义返回 `0` 或边不存在错误。

## 一致性与复杂度

所有更新和查询使用同一把互斥锁，结果等价于某个串行顺序，查询不会看到替换中间态。

链接切分树支持森林连通性、路径最大边与链路维护。删除森林边或森林边增权时，服务只遍历断开后较小的森林分量来识别跨割候选。非导出计数器 `scanned` 用于统计扫描量；若较小侧有 `s` 个节点，该次扫描增量不超过 `2s+2`。在 `n=100000` 长链端点边断开且较小侧只有一个节点时，增量不超过 `4`。

## 本地验证

```bash
# 常规测试
GOCACHE=/tmp/go-cache-ontology go test ./...

# 竞态检测
GOCACHE=/tmp/go-cache-race go test -race ./...

# 打印 2000 组随机更新的输入、输出与判定依据
GOCACHE=/tmp/go-cache-ontology go test -run TestRandomSequencesAgainstKruskal -v ./dynamicforest
```

随机测试对每组、每次更新都独立重算全图 Kruskal，并比对：

- `Entered`、`Left`、版本号；
- 森林边集合、总权重、连通分量数；
- 每条边的 `TreeSince`；
- 森林边数恒为 `N-components`；
- 非森林边的环性质与森林边的割性质。
