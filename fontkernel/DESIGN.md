# 设计说明（fontkernel）

1. 模块切分：`registry.go`（登记/校验/重复拒绝）、`tree.go`（字符覆盖索引）、
   `match.go`（宽度→倾斜→字重匹配）、`engine.go`（时钟、加载状态期、回退、整形）、
   `types.go`/`errors.go`/`doc.go`。
2. 并发：单把 `sync.Mutex` 串行全部公开操作，直接给出“等价于某串行顺序”的强保证；
   放弃细粒度锁，因为整形会触发状态迁移，读写集合高度重叠，锁拆分收益小、易错。
3. 字符覆盖：静态质心区间树，质心取端点中位数；覆盖质心的区间挂在节点两侧并按端点
   排序，点查询每层只沿一个孩子下降并做一次二分前缀，复杂度 O(log N + k)。
4. 匹配只在区间树筛出的覆盖候选上进行，故单字符工作量只随“覆盖该字符的人脸数”
   而非族内人脸总数增长；匹配键为 (宽度距离,宽度偏向侧,倾斜层,字重层,字重距离,登记序)
   的字典序，并列由登记序兜底，保证无歧义。
5. 字重中段按“先向上到上阈值 → 再向下（统一按距离，越过下阈值同层）→ 再向上越过
   上阈值”编码；两阈值恰等时中段退化为阈值点，上方区间全部归“先向上”。
6. 加载期：阻塞/交换/完成/永久回退由 `(triggerAt, policy)` 惰性重算，
   `Advance` 与“时钟之后的首次触发/报告”都会调用同一 `sweepFace`，
   避免“推进时脸尚未触发”漏掉边界转换；期边界左闭右开。
7. 每张人脸首次被胜出匹配触发时写入 `triggerAt` 并幂等；只触发胜者。
   回退族只接受 `Loaded` 人脸，永不被回退整形触发。
8. 放弃方案：动态 interval tree（登记后不再增删人脸，静态树更简单且只读免锁）；
   位图码点索引（码点空间 1.1M、区间稀疏，位图内存浪费且不能证明区间数无关）；
   用 channel/actor 做串行化（增加调度不确定性，单锁已足够且可测）。
9. 错误六类用独立哨兵值，拒绝次序在校验代码中按 参数→时钟→族→人脸→重复→加载态
   排列；被拒操作在校验通过前不触碰任何可变状态。
10. 本地验证：`go test -race ./...`；`go test -run TestNaiveDifferentialRandom`
    （2000 组随机族/策略/时钟/报告/整形序列与独立朴素模型逐字段对照）；
    `go test -run TestCoverageLookupSublinear -v`（区间数倍增，比较计数仅 +1）；
    `go test -bench=.`；`go vet ./... && gofmt -l .`。
