# regex：带回溯预算与封禁升级的正则执行器

`regex` 包实现一个按固定指令语义运行的回溯正则执行器：注册模式后在输入上搜索首个匹配，
匹配区间、步数、预算余量与封禁状态均可精确复现。

## 接口

```go
e, err := regex.NewEngine(L, E, G, K, D, P) // 构造参数全部有界，越界返回 ErrInvalidArgs
err = e.Register(id, pattern, memoize)      // 注册模式
r, err := e.Match(id, input, now)           // 搜索首个匹配
s, err := e.Status(id, now)                 // 查询 c、b、u 与是否封禁中
```

所有方法可并发调用，效果等价于某个串行顺序（内部以互斥锁串行化）。

## 模式语法（按字节处理）

- 字面字节；`\` 加任一字节表示该字节字面。
- `.` 匹配除换行 `\n` 外的任意字节。
- 字符集 `[abc]`、`[a-c]`、`[^a]`：集合内无转义，`]` 直接结束集合，
  范围 `lo-hi` 要求 `lo <= hi`，空集合为语法错误。
- `|` 选择；`( )` 不捕获分组；`^` 与 `$` 分别断言输入起点与终点。
- 量词 `*`、`+`、`?`、`{m,n}`、`{m,}`（`0 <= m <= n <= 100` 且 `n >= 1`，
  `{m,}` 要求 `m <= 100`），量词后可再跟一个 `?` 表示懒惰。
- 量词只作用于前一个原子（字面、`.`、字符集或分组）；`^` 与 `$` 后不得紧跟量词；
  连续两个量词（除懒惰后缀）为语法错误。
- 任一量词作用于"可匹配空串"的原子或分组判为**可空重复**（空选择支、纯断言、
  `{0,n}` / `*` / `?` 子项等均使分组可空）。
- 约定：`{` 在原子位置视为字面字节；紧跟原子之后时必须构成合法量词，否则语法错误。

## 指令语义与计步规则

模式编译为指令序列（下标从 0 起）：

| 构造 | 指令 |
| --- | --- |
| 字面 / `.` / 字符集 | 各 1 条，消耗一个字节 |
| `^` / `$` | 各 1 条断言 |
| 末尾 | 1 条 `Match` |
| `x\|y` | `Split(下一条, y 的起点)`、`x`、`Jmp(出口)`、`y`；多分支向右嵌套 |
| `e*` | `L0: Split(L1, 出口)`、`e`、`Jmp L0` |
| `e+` | `e` 后接 `e*` |
| `e?` | `Split(L1, 出口)`、`e` |
| `e{m,n}` | `m` 份 `e` 后接嵌套的 `n−m` 个可选，每个可选的 `Split` 跳过时直达整个构造的出口；指令数 `m×\|e\|+(n−m)×(\|e\|+1)` |
| `e{m,}` | `m` 份 `e` 后接 `e*` |
| 懒惰 | 把每个 `Split` 的两个目标的优先次序对调 |

指令总数超过 `P` 拒绝为程序过大。

执行时起点 `s` 从 `0` 到 `n`（含）依次尝试，从 `(pc=0, pos=s)` 起用显式栈做优先序回溯，
全程共用一个步数计数 `steps`（初 0）：

1. 记忆化开启时，调度 `(pc,pos)` 前若该状态已被调度过，则视为失败且**不计步**；
   否则标记（已调度集合跨起点共享）。
2. 若 `steps` 已等于有效上限 `λ` 则立即以超限结束。
3. 否则 `steps` 加一并执行：字符类指令越界或不符则失败；`Split(x,y)` 把 `(y,pos)`
   压栈后跳 `x`；`Jmp` 无条件跳；断言按位置判定；`Match` 成功返回 `[s,pos)`。
4. 失败时弹栈继续；栈空换下一个起点；全部起点失败为无匹配。

性质：`steps <= λ`；记忆化时 `steps <= 指令数 × (n+1)`；无超限时记忆化开关的
匹配结果与区间一致。

## 三层预算与封禁升级

- **本地步数上限 L**：一次 Match 的步数上限基准。
- **纪元全局预算**：纪元编号为 `now / E` 向下取整；全局余量 `rem` 初为 `G`，
  被接受的 Match 若进入新纪元则先把 `rem` 重置为 `G`，执行后 `rem` 减去实际步数
  （超限时即 `λ`）。记本次视角余量 `rem'`（纪元相同取 `rem`，否则取 `G`）：
  `rem' = 0` 拒绝；`rem' >= L` 时 `λ = L`（超限归类**本地超限**），
  否则 `λ = rem'`（归类**全局超限**）。
- **封禁升级**：每个模式维护连续本地超限计数 `c`、累计封禁次数 `b` 与封禁截止时刻 `u`。
  匹配与无匹配使 `c` 归 0；全局超限不改 `c`；本地超限使 `c` 加一，
  若 `c >= K` 则 `b` 加一、`u = now + D × min(2^(b−1), 8)`（`b` 为加一后的值，
  即时长 `D/2D/4D/8D` 封顶）、`c` 归 0。`now < u` 时模式处于封禁中。

## 拒绝次序（只报第一个）

- `Match`：参数非法（id 为空或超 64 字节、输入超 65536 字节、`now` 越出 `[0, 10^15]`）
  → 模式未注册 → 时钟回退（`now` 小于已被接受的 Match 见过的最大 `now`）→
  模式封禁中 → 全局余量为 0。
- `Register`：参数非法（id 为空或超 64 字节、模式为空或超 200 字节）→ id 已存在 →
  语法错误 → 可空重复 → 程序过大。

被拒绝的操作不改变任何状态；只有被接受的 Match 才推进最大 `now`、纪元与 `rem`。
