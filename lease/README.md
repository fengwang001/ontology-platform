# lease — 租赁转租链与责任传递服务

主租约 → 多级次租约的链管理、房东同意、期限/租金/深度约束、欠费沿链连带与追偿、
终止级联与独立承认提升。

## 包结构

- `errors.go`：错误码与固定报告次序（非法参数 → 时钟回退 → 租约不存在/已终止 →
  未同意 → 期限越界 → 租金超限 → 深度超限 → 状态不允许）。
- `types.go`：租约、欠费、清偿、追偿、同意、操作与 `Snapshot` 数据结构。
- `consent.go`：一次性同意（按次租约 id 命名、用一次即消费）与概括性同意
  （最新未撤回者有效；撤回不影响已成立转租）。
- `chain.go`：建链、唯一有效下级、祖先链、终止级联与承认提升。
- `billing.go`：30 天月模型、账单日、宽限 G 天出欠费、连带清偿与等额追偿。
- `world.go` / `service.go`：深拷贝工作副本（拒绝操作不留痕）、单调时钟、
  单互斥的串行化入口、时间惰性结算。
- `naivemodel/`：独立重写的朴素参考实现（全表扫描、平铺数据）。
- `DESIGN.txt`：≤40 行设计说明（取舍、放弃方案、验证方法）。

## 关键语义

- 时间按整数日；月 m 为 `[30m,30m+30)`，账单日 `30m+payDay`，账单日严格落在
  租约 `[start,end)` 内才计费；`now >= 账单日 + G` 产生欠费，边界取等。
- 次租约期限必须包含于上级（终止日可取等）；`subRent*100 <= parentRent*P`；
  链深度不得超过 D。
- 上级终止时：未承认（或未起租、已到期）的下级同时终止，终止日取上级终止日；
  已取得房东独立承认且仍在租的下级升为与房东的直接租约，期限租金不变，
  其再下级随之上提一级。
- 承租人退出时若有未获承认的有效下级则拒绝；退出不消灭欠费与既有追偿权。
- 欠费在生成时冻结责任链；任一上级清偿即解除其下各级对同一笔欠费的责任，
  并恰好形成一条金额等于清偿额、指向实际欠费承租人的追偿权。

## 并发

所有方法经同一把互斥执行；并发转租至多一份有效下级，并发清偿同一笔欠费只成功一次
（见 `TestConcurrentSubleases`、`TestConcurrentPaymentsNoDoubleSettle`）。

## 责任查询复杂度

`LiableParty` / `ReimbursableParties` 先以 `arrearsByID` 定位欠费，再只遍历该欠费
冻结链（长度 = 所在链深度），与系统租约总数无关：

```bash
go test ./lease/ -bench BenchmarkLiableParty -run '^$' -benchtime=100000x
```

## 测试

```bash
go test -race ./...                                   # 全量 + 竞态
go test ./lease/ -run TestRandomDifferential -v       # 随机序列对拍（带逐步日志）
go test ./lease/ -bench . -run '^$'                   # O(depth) 基准
```

随机对拍：40 个种子 × 400 步，操作同时送入正式服务与朴素模型，每步打印输入、
双方结果与判定依据，随后全量比较 `Snapshot`（链、欠费、清偿、追偿、同意、时钟）。
日志在失败时完整输出，成功时输出尾部摘要。
