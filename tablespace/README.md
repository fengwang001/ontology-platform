# tablespace：带区段状态与段碎片页的表空间页分配器

`tablespace` 包实现一个并发安全的页分配器。页空间被划分为等长区段，每个段
先在多个段**共享的碎片区段**内分配前若干页，达到阈值后改为在**独占整区**内
分配。所有操作由一把互斥锁串行化，结果等价于某个合法的串行顺序，相同操作序列
重放必然得到相同的页号序列与区段状态。

## 构造参数

`New(X, F, E)`：

- `X`：每区段页数，范围 `2..1024`
- `F`：碎片阈值，范围 `1..X`
- `E`：区段数，范围 `1..100000`

页号范围 `0 .. E*X-1`；区段 `i` 含页 `i*X .. i*X+X-1`。参数越界返回
`ErrInvalidArgument`。

## 段与查询

- `NewSegment()`：创建段，段号从 `1` 起递增，释放后不复用。
- `Used(s)`：段 `s` 拥有的全部页数（碎片页 + 独占区段内的页）。
- `PageOwner(p)`：页 `p` 当前归属段号，空闲返回 `0`。
- `ExtentStates()`：全部区段状态快照（编号、状态、独占 owner、已用页数）。

## 四种区段状态及迁移条件

| 状态 | 含义 | 已用页数 |
| --- | --- | --- |
| `FREE` | 全空、无主 | `0` |
| `FRAG` | 碎片区段，被多个段的碎片页共用 | `1 .. X-1` |
| `FULLFRAG` | 碎片区段且全部用满 | `X` |
| `SEG(s)` | 归段 `s` 独占，页只属于 `s` | `1 .. X` |

迁移按固定选取次序发生：

- `FREE -> FRAG`：碎片分配找不到任何 `FRAG` 区段时，取编号最小的 `FREE` 区段。
- `FRAG -> FULLFRAG`：某次碎片分配恰好把该区段用满。
- `FULLFRAG -> FRAG`：释放其中一页后不再用满。
- `FRAG/FULLFRAG -> FREE`：释放后已用页数变为 `0`。
- `FREE -> SEG(s)`：段 `s` 整区分配且非满队列为空时，取编号最小的 `FREE` 区段。
- `SEG(s) -> FREE`：独占区段内页全部释放（单页释放到空，或 `FreeSegment` 整段归还）。

## 分配选取次序

`AllocPage(s, hint)` 根据**分配前** `used(s)` 与 `F` 的关系分两种情形
（`hint` 为 `-1` 或合法页号）：

**碎片分配（`used(s) < F`，忽略 hint）**

1. 选编号最小的 `FRAG` 区段，取其编号最小的空闲页；
2. 没有 `FRAG` 则取编号最小的 `FREE` 区段，转 `FRAG`，取其最小页；
3. 两者皆无则返回 `ErrNoSpace`，且不预先转换任何区段。

碎片分配**不会**借用任何 `SEG` 区段内的空闲页。

**整区分配（`used(s) >= F`）**

1. `hint` 落在 `s` 已独占的区段内且该页空闲：分配 `hint` 页；
   hint 落在他段区段、已占页或非独占区段时均被忽略。
2. 否则取 `s` 的**非满队列**队首区段，分配其中编号最小的空闲页。
3. 队列为空时取编号最小的 `FREE` 区段转 `SEG(s)` 并入队尾，取其最小页
   （此时不看 hint）；没有 `FREE` 区段则返回 `ErrNoSpace`。

整区分配**不会**借用 `FRAG` 区段内的空闲页。

## 非满队列

每个段维护一条独占区段队列（按加入次序）：

- **入队尾**：`FREE -> SEG(s)` 新建独占区段时；原本用满（已不在队列中）的
  独占区段因释放一页而重新有空位时。
- **出队**：独占区段被用满时立即移出；独占区段释放到全空转 `FREE` 时移除
  （`FreeSegment` 整段归还的区段不经队列直接归 `FREE`）。
- 不变量：队列恰含该段所有未用满的独占区段，且无重复。

## 释放

- `FreePage(s, p)`：`p` 必须已分配且归 `s`（`SEG(s)` 区段内的**空闲页并不归
  `s` 所有**，释放同样拒绝）。碎片区段按 `FULLFRAG -> FRAG -> FREE` 回转；
  独占区段按上述队列规则迁移。
- `FreeSegment(s)`：释放 `s` 的全部碎片页与独占区段并使段号失效。

## 拒绝原因（按此顺序只报第一个）

1. `ErrInvalidArgument`：构造参数非法；页号或 `hint` 越界；`hint < -1`。
2. `ErrNoSuchSegment`：段不存在（含已释放段号）。
3. `ErrPageNotOwned`：`FreePage` 的页未分配或不归该段。
4. `ErrNoSpace`：`AllocPage` 无空间。

被拒绝的操作不改变任何区段状态、队列与页归属；无空间时不会先转换区段再失败。

## 本地验证

```bash
# 全部测试（规则用例 + 2000 组随机序列与朴素模型对照 + 并发）
go test ./tablespace/ -v

# 竞态检测（重复多轮）
go test -race -count=3 ./tablespace/

# 静态检查与格式
go vet ./...
gofmt -l .
```

随机对照测试（`TestRandomAgainstNaive`）逐组、逐步打印输入、两侧输出与
`判定:一致/不一致`，并在每步后核对区段状态、各段 `used`、非满队列内容与次序
以及全局不变量（每页至多一个归属、各状态已用页数约束、`已用页+空闲页=E*X` 等）；
失败时转储该组完整操作日志。朴素模型 `naiveModel` 严格按规则线性扫描实现，
不做任何索引优化，作为独立参考。
