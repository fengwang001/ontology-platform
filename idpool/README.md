# idpool —— 带隔离期与短命抖动加长的编号池

编号池管理编号 `1..N`，每个编号在任一时刻处于三种状态之一：
**使用中（in-use）**、**隔离中（quarantined）**、**空闲（free）**。
所有时刻均为调用方提供的整数毫秒时间戳；池拒绝任何早于此前已见过
时刻的操作（时钟回拨）。

## 创建参数

`New(n, Q, Qmax, R)`：

- `n`：编号上界（编号 `1..n`），必须为正；
- `Q`：基础隔离期（毫秒），必须为正；
- `Qmax`：隔离期上限（毫秒），必须满足 `Qmax >= Q`；
- `R`：短命阈值（毫秒整数），必须为正。

## 分配规则

- `Allocate(now)`：先把所有隔离在 `now`（含）之前到期的编号转为空闲，
  然后返回当前**空闲编号中的最小者**，并记录分配时刻。
- 编号在 `释放时刻 + 隔离期` 起变为空闲；**恰在该解除时刻即可分配**，
  绝不提前借出仍在隔离中的编号。
- 没有空闲编号时分配失败，返回 `*AllocError`：
  - 若存在隔离中的编号：`Exhausted=false`，并给出其中**最早解除时刻**
    及该时刻解除编号中的**最小者**（`NextFreeAt` / `NextFreeID`）；
  - 否则 `Exhausted=true`，表示池已被全部占用。

## 释放：隔离期的加倍与重置

`Release(id, now)` 只能释放使用中的编号。令
`存活时间 = now − 该编号的分配时刻`：

- `存活时间 < R`（短命）：本次隔离期 =
  `min(2 × 该编号上一次隔离期, Qmax)`；
- `存活时间 >= R`（正常寿命）：本次隔离期 = `Q`。

细则：

- **恰好等于 `R` 的存活时间算正常寿命**，隔离期取 `Q`（不翻倍）。
- 每个编号的“上一次隔离期”初值为 `Q`，因此**第一次短命释放即得到
  `2Q`**（若 `2Q > Qmax` 则取 `Qmax`）。
- “上一次隔离期”指该编号**最近一次释放所用的隔离期**；一次正常寿命
  的释放会把它重置为 `Q`，此后再次短命从 `Q` 重新开始翻倍。
- 编号进入隔离状态后，在 `now + 本次隔离期` 时刻转为空闲。

## 错误与拒绝顺序（原因可区分）

- 构造参数：`ErrInvalidN` / `ErrInvalidQ` / `ErrInvalidQmax` /
  `ErrInvalidR`。
- 释放与分配/查询的时间错误：`ErrClockRollback`（时刻早于此前见过的
  任一时刻）。
- 释放编号：校验顺序为**时钟回拨优先**，随后按
  **越界（`ErrIDOutOfRange`）→ 空闲（`ErrIDFree`）→
  隔离中（`ErrIDQuarantined`）** 只报第一个。
- 被拒绝的操作不改变任何编号状态、隔离期记录与已见时刻。

## 并发语义

`Allocate` / `Release` / `Query` 由互斥锁保护，可被并发调用，
结果等价于某个串行顺序。任意时刻均有
`使用中 + 隔离中 + 空闲 = N`；同一编号相邻两次成功分配的时刻差
不小于其间那次释放所用的隔离期。给定相同操作序列（含时间戳）重放，
得到完全相同的编号序列。

## 本地验证

```bash
# 全量测试
go test ./...

# 竞态检测 + 详细日志（含每个用例的输入、输出与判定依据）
go test -race -v ./idpool

# 重复执行排查偶发问题
go test -race -count=10 ./idpool

# 覆盖率
go test -coverprofile=coverage.out ./idpool
go tool cover -html=coverage.out

# 代码检查
gofmt -l .
go vet ./...
```

若环境默认的 `GOCACHE` 位于只读文件系统，可指定
`GOCACHE=/tmp/gocache` 后再执行上述命令。
