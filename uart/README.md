# uart — 16 倍过采样 UART 接收状态机

`uart.Receiver` 从逐采样点的线路电平流（每个采样点取值 `0`/`1`）中恢复
UART 帧。帧格式固定为 **1 起始位 + 8 数据位（LSB 在前）+ 可选校验位 +
1 停止位**，每位占 **16 个采样点**。

## 采样序号与起始位对齐

- 采样点序号从 **0** 开始：第 1 个成功送入的采样点序号为 0，之后每送一个
  采样点序号加 1。`SampleIndex()` 恒等于成功送入的采样点总数；被拒绝的
  调用不改变序号。
- 空闲态下任何低电平采样都作为**起始候选**，记其序号为 `s`，随后进入
  起始确认态。序号 `s+1 … s+6` 的采样点不做任何处理。
- 在序号 **`s+7`**（起始位中点）处：
  - 线上为**高** → 判为毛刺：`GlitchCount()` 加 1，立即回到空闲态；该
    高电平采样**不**作为新的起始候选。
  - 线上为**低** → 起始位成立，进入逐位接收。
- 各采样点序号（均为“中点”，相邻位相差 16）：

| 内容 | 采样序号 |
| --- | --- |
| 数据位 i（i = 0…7，LSB 在前） | `s + 7 + 16·(i+1)` |
| 校验位（若有） | `s + 7 + 16·9` |
| 停止位（无校验，q=0） | `s + 7 + 16·(9+0) = s+7+16·9` |
| 停止位（有校验，q=1） | `s + 7 + 16·(9+1) = s+7+16·10` |

## 帧的判定

在停止位采样点处帧结束，产出一个 `Frame{Data, ParityError, FrameError,
Break, EndIndex}`，其中 `EndIndex` 即停止位采样点的序号。

- **校验错误**：统计所有已采样位（8 个数据位 + 校验位；不含起始位与
  停止位）中 `1` 的个数。偶校验要求偶数、奇校验要求奇数，不符则置位；
  无校验模式恒不置位。
- **帧错误**：停止位采到低电平即置位。
- **中止（Break）**：停止位为低，**且** 8 个数据位与校验位（如有）全部
  为 0。中止帧必然同时带帧错误；其校验错误仍按上面的计数规则独立判定，
  因此奇校验下的全零中止帧（0 个 `1`）同时带校验错误。

停止位为低时进入**等待态**：必须再见到一个高电平采样才回到空闲态，该
高电平采样不作为起始候选；等待期间的低电平也不作为起始候选。停止位为
高时直接回到空闲态，因此下一采样点若为低电平立即成为新的 `s`。

## 接收队列与溢出

- 构造时给定深度 `D >= 1`。帧产出时若队列已满，该帧被**丢弃**且
  `OverrunCount()` 加 1，队列中已有帧保持不变；否则入队。`Pop()` 取
  队首。
- `ProducedCount()` 为产出帧总数，恒等于 **入队数 + 溢出数**。

## 拒绝规则（整体拒绝，状态与序号不变）

- `New`：校验模式不是无/偶/奇 → `ErrInvalidParity`；`D < 1` →
  `ErrInvalidDepth`。
- `Feed`：电平不是 `0` 或 `1` → `ErrInvalidLevel`。
- `FeedAll`：先整批校验，任一电平非法 → `ErrInvalidLevel`，此前的采样点
  也不会送入。
- `Pop`：队列为空 → `ErrQueueEmpty`。

`FeedAll(levels)` 与按序逐个 `Feed` 完全等价；同一段电平流任意切分成
多批送入，得到的帧序列、毛刺数与溢出数完全相同。

## 并发

`Feed`、`FeedAll`、`Pop` 与各查询方法均以互斥锁串行化，可被并发调用，
结果等价于某个串行顺序。

## 本地验证

```bash
# 常规测试（含 300 组随机波形与独立朴素解码器对照、全切分点一致性）
go test -v ./uart

# 竞态检测
go test -race -count=1 ./...

# 覆盖率
go test -coverprofile=/tmp/cover.out ./...
go tool cover -html=/tmp/cover.out

# 格式与静态检查
gofmt -l .
go vet ./...
```

测试日志中会打印输入电平流（`0`/`1` 串）、产出帧的字节与三个错误标志、
`EndIndex` 以及每条判定依据。
