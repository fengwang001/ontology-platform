# reachability — 有向图可达性增量维护

在有向边的增删过程中实时维护**全量可达点对**。删边时先移除所有可能受影响
的点对，再对仍可达的点对重新推导加回，保证删边后可达集合**既不过删
（有替代路径的点对一定恢复）也不漏算（只靠被删边成立的点对一定消失）**。

## 可达定义

- 节点 `u` 可达节点 `v`，当且仅当图中存在一条**长度至少为 1** 的有向路径
  `u → … → v`。
- 允许自环：没有自环/环时 `u` 不可达 `u`；存在自环或回到自身的环时
  `u` 可达 `u`，环消失后该可达性同步消失。
- 可达点对集合始终与“对当前边集做朴素 DFS/BFS 遍历”得到的结果完全一致
  （测试以独立的朴素实现做全量比对）。

## 边与重数

- 每条有向边带一个 64 位重数；**边存在当且仅当重数为正**。
- `AddEdge / AddEdgeN`：增加重数。只有重数从 0 变为正时才真正“加入边”
  并增量并入新的可达点对；重复加边只累加重数，可达集合不变。
- `RemoveEdge / RemoveEdgeN`：减少重数。只有减量使重数归零时才真正
  “删除边”并触发可达关系重算；重数仍为正时仅降重数。
- 单条边重数上限为 `MaxEdgeMultiplicity`（2³²），超限拒绝。

### 加边规则

设新边为 `x → y`，旧图中：

- `A = {u | u 可达 x} ∪ {x}`
- `B = {v | v 可从 y 到达} ∪ {y}`

则新出现的可达点对恰为 `A × B` 中此前尚未记录的点对，每个点对给出
形如“旧图路径 + 新边 + 旧图路径”的见证路径。

### 删边规则（先移除、再推导）

设被删边为 `x → y`：

1. 在删除前的图上求 `Pred(x) = {u | u 可达 x} ∪ {x}` 与
   `Succ(y) = {v | v 可从 y 到达} ∪ {y}`。任何经过被删边的路径，其起点
   必在 `Pred(x)`、终点必在 `Succ(y)`，所以**可能受影响的点对不超出
   `Pred(x) × Succ(y)`**。
2. 先把该矩形内的可达点对**全部移除**（宁可过删）。
3. 在删除后的图上对每个节点做**朴素遍历**，把仍然可达的点对连同新的
   见证路径**重新加回**。

最终未恢复的点对才是真正消失的可达性。每次成功操作返回的
`ChangeResult` 分别列出新增（`AddedPairs`）、恢复（`RestoredPairs`）、
消失（`RemovedPairs`）的点对。

## 被拒绝的操作（可区分原因）

非法操作在触碰任何状态之前返回 `*OpError`，用 `errors.Is` 判别类别；
**被拒绝的操作不会改变重数、可达集合或任何索引**。

| 错误类别（`ErrorKind`） | 哨兵错误 | 触发条件 |
| --- | --- | --- |
| `empty_node_name` | `ErrEmptyNodeName` | `from` 或 `to` 为空字符串 |
| `invalid_argument` | `ErrInvalidArgument` | 增/删数量为 0 |
| `edge_not_found` | `ErrEdgeNotFound` | 删除重数为 0 的边，或减量大于当前重数 |
| `multiplicity_overflow` | `ErrMultiplicityOverflow` | 增边会使重数超过 `MaxEdgeMultiplicity` |

## 并发与一致性

- 一把互斥锁串行化所有增删与版本指针切换。
- 可达关系以**不可变快照**（`Snapshot`）发布：读取方只取一次快照指针，
  之后无锁遍历。因此读者看到的永远是某个已提交版本的完整点对集合
  （逐点对一致），绝不会读到半成品；早先取得的快照也不受后续增删影响。
- 测试包含多写者 + 多读者的 `-race` 场景，结束后与朴素遍历全量比对。

## 确定性

输出不使用时间戳、只使用单调序号，集合一律按字典序打印；见证路径取自
字典序 BFS 的最短路径。同一输入序列重复执行产生**完全相同**的日志与
可达集合（见 `TestDeterministicReplay`）。

开启日志（`WithLogger(io.Writer)`）后会打印：每次操作的**输入**、
新增/恢复/消失点对及**判定依据**（见证路径）、操作后的**完整可达集合**，
以及每次可达查询的结论与路径依据。

## API 速览

```go
g := reachability.New(reachability.WithLogger(os.Stdout))

res, err := g.AddEdge("a", "b")        // 重数 +1
res, err = g.AddEdgeN("a", "b", 3)     // 重数 +3
res, err = g.RemoveEdge("a", "b")      // 重数 -1，归零时删边
res, err = g.RemoveEdgeN("a", "b", 2) // 重数 -2

ok, err := g.Reachable("a", "b")       // 长度 >= 1 的路径是否存在
snap := g.Snapshot()                   // 不可变、可并发读取的快照
pairs := snap.Pairs()                  // 字典序全部可达点对

errors.Is(err, reachability.ErrEdgeNotFound) // 判别拒绝原因
```
